## 1. なぜ「技術」ではなく「経済（コスト）」が問題なのか？

これまで、ネット上の匿名アカウントから本名を特定する（デ・アノニマイズ）には、多大な労力と時間、そして数万〜数十万円の費用が必要でした。

しかし、AI（LLMや高精度画像認識）の登場でゲームのルールが変わりました。

```
【従来の特定プロセス】
怪しい書き込みを見つける ➔ 過去ログを手動で漁る ➔ 写真の背景から場所を割り出す（職人技） ➔ 探偵を雇う ＝ 数日〜数週間（コスト：数十万円）

【現代のAI特定プロセス】
写真をAI顔認識（PimEyes等）に通す ➔ SNSの過去投稿と紐付け ➔ AIが住所・本名を数秒で推測 ＝ 数秒（コスト：数十円）
```

つまり、**「技術的に特定できるか」ではなく、「誰でもお小遣い程度のコストで、嫌がらせ感覚で特定できるようになったこと」**が真の恐怖なのです。

SNSの何気ない自撮り写真、背景の景色、過去の呟きの「文体（AIによる文体分析）」から、あなたのアカウントは数秒で現実のあなたと結びつけられます。
