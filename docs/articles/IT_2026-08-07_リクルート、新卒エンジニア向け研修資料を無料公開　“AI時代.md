## 2. AI時代を生き抜く「AIコーディングツール」3社徹底比較

資料内でも言及されている「AIとの協働」。では、私たちは具体的にどのツールを使うべきでしょうか？
現在、エンジニアの間で覇権を争う3つのAIツール（**GitHub Copilot、Cursor、ChatGPT Plus**）を徹底比較しました。

| ツール名 | **Cursor** (カーソル) | **GitHub Copilot** | **ChatGPT Plus** (GPT-4o) |
| :--- | :--- | :--- | :--- |
| **特徴** | 次世代のAI特化型コードエディタ。VS Codeから移行可能。 | Microsoft/GitHub公式。コード補完のデファクトスタンダード。 | 汎用AI。コード作成からバグの原因究明、設計の相談まで。 |
| **月額料金** | 無料プランあり / Pro: $20/月 | 個人: $10/月 / ビジネス: $19/月 | $20/月 |
| **コード補完精度**| ★★★★★ (文脈理解が極めて高い) | ★★★★☆ (行・関数単位の補完が超高速) | ★★★★☆ (プロンプト次第で神コード) |
| **導入のしやすさ**| ★★★★☆ (エディタの乗り換えが必要) | ★★★★★ (既存のVS Code等にプラグイン) | ★★★★★ (ブラウザだけで完結) |
| **こんな人におすすめ** | 最新AIで爆速開発したい先進層 | 既存の開発環境を壊したくない人 | ノンプログラマー・設計の相談重視 |

### 比較のポイント
* **コスパ重視なら**：まずは無料枠のある**Cursor**が最強です。VS Codeの拡張機能をそのまま引き継げるため、乗り換えのハードルも低いです。
* **チーム開発・安定性重視なら**：実績十分の**GitHub Copilot**が一択。
* **開発以外（ドキュメント作成やアイデア出し）も並行するなら**：**ChatGPT Plus**を契約し、API連携で活用するのがベストです。
