# 日本の国富を育てる「遊び部屋」とは？ 登大遊氏基調講演レポート【CEDEC 2026】

$$\text{【イノベーション】} = \text{【役に立たない無駄な試行錯誤（遊び）】} \times \text{【規制のない自由なインフラ】}$$

2026年のCEDECにおいて、登大遊氏は「日本が再び国際的な競争力を持ち、国富を増大させるためには、**組織内に『遊び部屋（サンドボックス）』を作ること**が不可欠である」と強く訴えました。

### 登氏の主張：なぜ今「遊び部屋」が必要なのか？
1. **「正しさ」と「セキュリティ」の過剰追求がイノベーションを殺した**
   現在の日本のIT環境は、セキュリティやコンプライアンス（法令順守）の名のもとに、社員や学生が「自由に実験できる環境」を奪っています。
2. **インチキで怪しいプロトタイプから国富は生まれる**
   SoftEther（ソフトイーサー）や、現在の生成AIの多くは、企業の正式なプロジェクトではなく、個人の「面白そうだからやってみた」という無駄な遊びから誕生しました。
3. **「インチキLAN環境」を構築せよ**
   登氏は、既存のルールに縛られない「独自の実験用ネットワークやローカルAI環境」を組織内、あるいは自宅に構築することを推奨しています。

> **「仕事に役立つか分からない無駄なシステムを、夜な夜な構築して遊ぶこと。これこそが、最強のエンジニアを育て、国の富となる。」（登大遊氏）**
