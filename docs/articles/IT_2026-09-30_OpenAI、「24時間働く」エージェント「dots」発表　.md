## 1. OpenAI「dots」とは？3つの革命的特徴

「dots」は、高度なマルチモーダル処理能力を持つ**「Astra」**を搭載し、クラウド上で常時稼働する自律型AIエージェントです。これまでのAIと何が違うのか、ポイントを3つに絞って解説します。

```
【dotsの基本コンセプト】
ユーザーの指示 ──> [ dots (クラウド常時起動) ] ──> 24時間自律実行
                                            │──> 市場監視・データ収集
                                            │──> コード生成・デバッグ
                                            │──> SNS自動運用・顧客対応
```

### ① 24時間ノンストップの常時稼働（Cloud-Native）
PCの電源を切っても、スマホを閉じても、dotsはクラウド上で動き続けます。例えば「毎朝競合サイトの価格をチェックしてスプレッドシートにまとめ、異常値があればSlackで通知する」といったタスクを、あなたが寝ている間も実行し続けます。

### ② Astra搭載による「超リアルタイム・マルチモーダル」
GoogleのProject Astraでも話題になった「高度な認識・即時応答」の技術を内包。テキストだけでなく、画面上のデザインの変化、リアルタイムに変動するグラフ、さらには音声データまでを遅延なく理解し、アクションを起こします。

### ③ 「ツール使用」の完全自律化
API経由でSlack、Notion、GitHub、各種クラウドツールと連携。エラーが発生した際も、自らコードを修正（自己デバッグ）しながらゴールまでタスクを完遂します。

## 2. 徹底比較！「dots」vs 競合AIエージェント

現在、AIエージェント市場は戦国時代。先行する「Claude 3.5 Sonnet (Computer Use)」や、エンジニア特化型AI「Devin」とdotsの性能・価格を比較しました。

| 項目 | **OpenAI「dots」** | **Claude 3.5 (Computer Use)** | **Devin (Cognition)** |
| :--- | :--- | :--- | :--- |
| **開発元** | OpenAI | Anthropic | Cognition |
| **主な特徴** | **24時間クラウド常時稼働・汎用型** | ローカルPC画面の直接操作 | エンジニア・開発特化 |
| **稼働環境** | 完全クラウド（サーバー不要） | ローカル（環境構築が必要） | クラウド（サンドボックス） |
| **価格（目安）** | 月額 $30〜（従量課金プランあり） | API使用量に応じた従量課金 | 月額 $500〜（プロ向け） |
| **得意タスク** | ルーティン自動化、監視、SNS運用 | UIテスト、デザイン確認 | システム開発、バグ修正 |
| **導入難易度** | ★☆☆ (ブラウザから即設定可能) | ★★★ (APIとコード知識が必要) | ★★☆ (開発者向け) |

### 比較から見える「dots」の強み
ClaudeのComputer Useは強力ですが、基本的には「自分のPC画面をAIに乗っ取らせて動かす」ため、実行中はPCが使えなくなるデメリットがありました。
一方、**dotsは完全クラウド稼働**。あなたのPCスペックに依存せず、ブラウザを閉じても稼働し続ける点が圧倒的なアドバンテージです。

## 3. サクラなし！ネット上のリアルな口コミ・評判

SNSやエンジニアコミュニティ（X、Reddit、5chなど）から、PRやサクラ目的の投稿を徹底排除した**「本音の口コミ」**をまとめました。

### ◯ 肯定的なリアル評価
> **「朝起きたらタスクが終わってる感動」**
> 「dotsに『特定の海外Techニュースを要約して、自分のブログの下書きに入れといて』と指示して就寝。朝起きたら完璧にWordPressの下書きに入ってた。これ、本当にアシスタント雇う必要なくなるわ。」（30代・Webディレクター）

> **「エラーの自己解決能力が異常に高い」**
> 「APIの仕様変更でスクレイピングがエラー吐いてたんだけど、dotsが自分でStack Overflow調べてコード修正して完遂してた。恐ろしい時代になったな。」（20代・個人開発者）

> **「セキュリティがちょっと怖い」**
