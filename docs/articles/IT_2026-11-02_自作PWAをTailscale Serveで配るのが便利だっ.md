## そもそも「Tailscale Serve」×「PWA」が最強な理由

PWA（Progressive Web App）は、スマホのホーム画面に追加してアプリ感覚で起動できる超便利な仕組みですが、**「HTTPS（暗号化通信）で配信されていること」**が必須条件です。

通常、ローカルで開発したWebアプリ（`http://localhost:3000`など）は、そのままではスマホのPWAとして登録できません。

ここで「Tailscale Serve」の登場です。

```text
[自宅のミニPC / Mac] (ローカルAI + 自作PWA)
         │
    Tailscale Serve（自動HTTPS化・メッシュVPN）
         │
[外出先のiPhone / Android] (PWAとしてホーム画面から起動)
```

### Tailscale Serveのここが凄い！
1. **コマンド1発でMagicDNSによる「正当なHTTPS URL」が発行される**（証明書設定が不要！）
2. **Tailscaleネットワーク内の端末（自分のスマホやタブレット）からしかアクセスできない**（セキュリティ最強）
3. **外部のパブリッククラウドにコードやAPIキーを置く必要がない**
