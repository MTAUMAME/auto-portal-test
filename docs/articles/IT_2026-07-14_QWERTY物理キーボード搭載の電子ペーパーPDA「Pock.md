PocketMageは、一言で言えば**「Androidベースの超小型電子ペーパーPDA」**です。


## 2. 徹底比較：PocketMage vs ライバル機

「テキスト入力特化型デバイス」として競合する、キングジムの「ポメラ DM250」および超小型スマホ「Unihertz Titan Pocket」と比較してみましょう。

| 項目 | **PocketMage** (本作) | **ポメラ DM250** | **Unihertz Titan Pocket** |
| :--- | :--- | :--- | :--- |
| **画面** | 5.2型 E-Ink (モノクロ) | 7.0型 TFT液晶 | 3.1型 液晶 (カラー) |
| **キーボード** | QWERTY（親指打ち） | QWERTY（折りたたみ・両手打ち）| QWERTY（親指打ち） |
| **OS** | Androidベース (APK追加可) | 独自OS (アプリ追加不可) | Android 11 (フル機能) |
| **重量** | **約195g** (超軽量) | 約560g | 約216g |
| **電池持ち** | **約7日間** | 約24時間 | 約1〜2日 |
| **通信** | Wi-Fi / Bluetooth | Wi-Fi (アップロード用) | 4G LTE (SIMフリー) |
| **実売価格** | **約32,800円〜** | 約50,000円〜 | 約35,000円〜 |

**【比較の結論】**
* 机に置いて「長文をガッツリ書きたい」なら、キーボードが大きい**ポメラ**。
* 通話や一般アプリ（SNS等）も1台で済ませたいなら、**Titan Pocket**。
* **「いつでもどこでも、思いついた時に片手〜両手でメモを取り、電池切れを一切気にしたくない」なら、圧倒的に「PocketMage」が最強です。**
