## 1. `understand-mode` とは？（概要と魅力）

`understand-mode` は、fkubota氏（[@fkubota](https://github.com/fkubota)）が開発・公開しているオープンソースのClaude Code用スキルです。

リポジトリ：[GitHub - fkubota/understand-mode](https://github.com/fkubota/understand-mode)

### 💡 なぜ今、これが注目されているのか？
通常のAIコーディングアシスタントは「指示通りにコードを書く（あるいは解説する）」のが得意ですが、受け手側の脳のキャパシティを超えた情報が来ると「読解疲れ」を起こします。

`understand-mode`を導入すると、AIが**「付箋を使ったホワイトボード」**のように情報を整理し、インタラクティブにコードや構造を解説してくれます。

### ✨ 主な特徴
1. **「寄り道（Detour）」ができる**：全体像を見つつ、「この関数どういうこと？」と気になった部分を深掘りし、終わったら元の解説に戻れる。
2. **ホワイトボード型の思考整理**：テキストの羅列ではなく、付箋で構造化されたような視覚的な理解をサポート。
3. **PRや巨大なコードベースに最適**：他人が書いた謎のコードや、Claude自身が生成した複雑なPRの解読速度が飛躍的に向上。

## 2. 費用・パフォーマンス比較

`understand-mode` の導入コストや、他のコーディング支援手法とのパフォーマンスを比較しました。

### 💰 コスト面
* **ツール自体**：**無料（オープンソース / MITライセンス）**
* **ランニングコスト**：Claude Codeの実行に伴う **Anthropic API利用料（Claude 3.7 Sonnet等のトークン消費）**

※`/understand`モードは思考プロセスを可視化するため、通常対話よりも**トークン消費量がやや多くなる**傾向があります。しかし、「コード理解にかかるエンジニアの人件費（時間）」を考えると、費用対効果は絶大です。

### 📊 性能・UX比較表

| 項目 | 単体Claude Code (CLI) | Cursor / GitHub Copilot | **Claude Code + understand-mode** |
| :--- | :--- | :--- | :--- |
| **コードの自動生成** | ◎ 非常に対話的で強力 | ◎ エディタ一体型で快適 | ◎ 非常に強力 |
| **複雑なコードの理解度** | ◯ テキスト中心で埋もれがち | ◯ サイドバーで解説 | **◎ 付箋・図解的アプローチで最高** |
| **思考の寄り道・深掘り** | △ 文脈が脱線しやすい | △ エディタを往復する必要あり | **◎ 脱線しても元の文脈へ戻れる設計** |
| **導入ハードル** | 中（CLI操作が必要） | 低（VSCode拡張など） | 中（Claude Code設定が必要） |
| **コスト（時間短縮効果）** | 高い | 中〜高 | **極めて高い（理解コスト大幅削減）** |

## 4. 導入方法（サクッと3ステップ）

1. **Claude Codeをセットアップ**（まだの方はAnthropic公式から導入）
2. **リポジトリからスキルをクローンまたはダウンロード**
   ```bash
   git clone https://github.com/fkubota/understand-mode.git
   ```
3. **Claude Codeのカスタムコマンド/Promptとして組み込む**（詳細は公式README参照）
4. ターミナルで `/understand` と入力して起動！
