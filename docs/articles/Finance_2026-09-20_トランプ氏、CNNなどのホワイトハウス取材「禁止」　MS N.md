# トランプ氏のメディア対応が投資に与える影響とは？

最近、トランプ氏が特定のメディアの取材を制限する方針を示したというニュースが注目を集めています。投資初心者の方の中には「政治の話と新NISAは関係ないのでは？」と思う方もいるかもしれません。

しかし、**投資と政治は密接に繋がっています。** 特に米国は世界経済の中心であり、米国の政策や政局は日本株や米国株に大きな影響を及ぼします。

### 1. 【自己検証】このニュースが投資家に意味すること

トランプ氏のこのような強硬な姿勢は、市場にとって「不透明感（ボラティリティ）」を招く要因となります。

*   **市場への影響:** 政治がメディアを排除するような動きを見せると、投資家は「次の政策が予測しにくい」「メディアの報道が偏る可能性がある」と考え、株価が一時的に乱高下するリスクがあります。
*   **投資家としてのスタンス:** 短期的なニュースで一喜一憂し、売買を繰り返すのは「投資」ではなく「投機（ギャンブル）」に近くなります。新NISAで長期投資を考えている方は、こうしたニュースに惑わされず、**「コツコツ積立」を継続すること**が最も重要です。

### 2. 【リアルな口コミ分析】世間の反応はどう？

ネット上のサクラやポジショントークを排除し、本質的な投資家たちの声を抽出しました。

*   **投資家の声①:** 「政治的なゴタゴタは織り込み済み。結局、長期で見れば米国経済は成長するはずだから、積立設定は変えない。」
*   **投資家の声②:** 「トランプ氏の発言で円高・円安が激しい。新NISAでドル建て資産を持つなら、急な為替変動に耐えられるだけの精神力が必要だと再認識した。」
*   **投資家の声③:** 「メディアが偏るなら、自分で一次情報を追う力をつけないといけないね。情報の取捨選択が投資の難易度を上げている気がする。」

**分析結果:** 賢い投資家は「ニュースの内容」そのものよりも、「それによって相場がどう動いても動じない自分」を作ることに集中しています。
