## 1. 「AIレビューループ」とは？

AIレビューループとは、**「人間がデザインを作成 ➔ AIが即座に多角的な視点（UX/美しさ/視認性）でレビュー ➔ 人間が修正」**というプロセスを、デザインの初期段階から超高速で回すワークフローのことです。

```
[デザイン作成] ➔ [AIによるマルチモーダル解析] ➔ [客観的なフィードバック] ➔ [微修正] ➔ (ループ)
```

### なぜAIレビューが必要なのか？
1. **主観からの脱却：** 自分のデザインは目が慣れてしまい、欠点に気づきにくくなります。
2. **時間の節約：** クライアントや上司に見せる前に、一般的なUI/UXのバグを90%潰せます。
3. **アクセシビリティの確保：** 色覚多様性（カラーユニバーサルデザイン）や、テキストの読みやすさを一瞬で判定してくれます。

## 4. 今日からできる！「AIレビューループ」実践プロンプト

これを使って、手持ちのAI（ChatGPTやClaude）にデザイン画像をアップロードしてみてください。驚くほど的確なフィードバックが返ってきます。

```text
【ロール】
あなたはシニアUI/UXデザイナー、およびWebアクセシビリティの専門家です。

【依頼】
添付されたデザイン画像（Webサイト/アプリ/バナー）をレビューしてください。

【評価軸】
1. 視覚的ヒエラルキー（ユーザーの目が最初にどこに行くべきか、それが達成できているか）
2. コントラストと視認性（テキストが背景に対して読みやすいか）
3. レイアウトと余白（一貫性があり、情報が整理されているか）
4. 改善のための具体的なアクションプラン（色、フォントサイズ、配置の修正提案）

辛口かつ客観的に、改善点を箇条書きで指摘してください。
```
