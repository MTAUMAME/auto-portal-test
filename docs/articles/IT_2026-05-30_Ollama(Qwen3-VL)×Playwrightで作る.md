## 1. なぜ「Qwen-VL × Playwright」なのか？システムの仕組み

これまでのWebスクレイピングや自動化ツールは、Webサイトの「HTML構造（セレクタやXPath）」が変わるたびにコードが壊れ、メンテナンスが地獄でした。

しかし、今回構築する**「VLM（ビジョンLMM）エージェント」**は人間と同じように動きます。

```
【エージェントの動作フロー】
1. Playwrightがブラウザを開き、画面のスクリーンショットを撮影
2. Ollama上の「Qwen-VL」に画像を送り、「検索窓はどこ？」「次にするべき操作は？」と質問
3. Qwen-VLが画面を認識し、「(x: 350, y: 120) をクリックして『グラボ 特価』と入力せよ」と回答
4. Playwrightがその座標を正確に操作
5. 目的の情報を回収するまで1〜4を自動ループ！
```

HTMLの構造が変わっても、**「画面を目で見て判断している」**ため、エラーで止まることがほとんどありません。これを「完全ローカル（無料）」で実現できるのが、このシステムの最大の強みです。

## 4. 【クイック実装】10分で動かすローカルWebエージェント

ここでは、Pythonを使ったシンプルな実装の流れを紹介します。

### 事前準備
1. **Ollamaのインストール**: [Ollama公式サイト](https://ollama.com/)からダウンロード。
2. **モデルのプル**: コマンドラインでQwenのビジョンモデルをダウンロード。
   ```bash
   ollama run qwen2.5-vl:7b
   # ※スペックに余裕がある方は qwen2.5-vl:72b や次世代の qwen3-vl シリーズをお試しください。
   ```
3. **ライブラリのインストール**:
   ```bash
   pip install playwright ollama pillow
   playwright install
   ```

### 簡易コード例（Python）
以下は、サイトのスクリーンショットを撮り、Ollamaに「次にクリックすべき座標」を答えさせて自動操作するコアロジックです。

```python
import asyncio
from playwright.async_api import async_playwright
import ollama
from PIL import Image
import io

async def main():
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=False)
        page = await browser.new_page()
        await page.goto("https://example.com") # 調査したいサイト

        # 1. スクリーンショットを撮影
        screenshot_bytes = await page.screenshot()
        
        # 2. Ollama (Qwen-VL) に画像を入力し、次のアクションを聞く
        response = ollama.chat(
            model='qwen2.5-vl:7b',
            messages=[{
                'role': 'user',
                'content': 'この画面から「詳細」ボタンを探し、その中心座標 [x, y] を1000x1000の比率で答えてください。',
                'images': [screenshot_bytes]
            }]
        )
        
        print("Qwen-VLの解析結果:", response['message']['content'])
        
        # 3. 座標を解析してPlaywrightでクリック（※実際は正規表現などで座標を抽出）
        # await page.mouse.click(x, y)
        
        await browser.close()

asyncio.run(main())
```
