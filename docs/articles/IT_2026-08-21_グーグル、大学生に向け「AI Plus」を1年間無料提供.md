## 1. キャンペーン概要：何が無料で使えるの？

今回のキャンペーンで提供されるのは、Googleの最上位AIサービスを含む**「Google One AI Premium」プラン**です。

| 項目 | 詳細 |
| :--- | :--- |
| **対象者** | 高等教育機関（大学、専門学校など）に在籍する学生（SheerIDによる認証あり） |
| **無料期間** | **1年間（12ヶ月間）** ※期間終了後は自動更新（キャンセル可能） |
| **通常料金** | 月額 2,900円（年間 34,800円相当） |
| **主な特典** | ① 最先端AI「Gemini Advanced（Gemini 1.5 Pro）」の利用<br>② GmailやGoogleドキュメント内でのAIアシスタント機能<br>③ **Googleドライブ等の容量が「2TB」にアップグレード** |

特に**「2TBのクラウドストレージ」**が付いてくるのが、レポートや研究データ、写真・動画を多く保存する学生にとって神すぎるポイントです。

## 2. 【徹底比較】Gemini Advanced vs ChatGPT vs Claude

「無料なのは嬉しいけど、性能はどうなの？」と疑問に思う方のために、現在AIの3大巨頭である**「Gemini Advanced（Google）」「ChatGPT Plus（OpenAI）」「Claude 3.5 Sonnet（Anthropic）」**を比較しました。

| 機能・項目 | **Gemini Advanced** (本プラン) | **ChatGPT Plus** | **Claude Pro** |
| :--- | :--- | :--- | :--- |
| **月額料金** | **0円**（通常2,900円/月） | 約3,000円 ($20/月) | 約3,000円 ($20/月) |
| **搭載モデル** | Gemini 1.5 Pro | GPT-4o / o1-preview | Claude 3.5 Sonnet |
| **一度に読める量**<br>(コンテキスト窓) | **約100万トークン** (本1冊分) | 約12.8万トークン | 約20万トークン |
| **Google連携** | **最強** (Gmail, ドキュメント等) | なし（サードパーティ製） | なし |
| **追加特典** | **2TBのクラウド容量** | なし | なし |
| **得意分野** | 長大データの分析、予定管理、動画要約 | プログラミング、アイデア出し、画像生成 | 論文執筆、自然な日本語、コーディング |

### 比較から見える「Gemini Advanced」の強み
* **圧倒的なインプット量：** 教科書一冊、PDF論文数本を丸ごとアップロードして「この中から重要ポイントをまとめて」と指示できます。これはChatGPTにはできません。
* **圧倒的なコスパ：** 他の2社が月3,000円かかる中、**学生なら1年間無料**。比較になりません。
