# 1. なぜGMOは嫌われるのか？「Wiki状態」になった3つの要因

ネット上の声を分析すると、批判は「技術力」そのものではなく、主に**「マーケティング手法」「UX設計」「顧客対応」**に集中しています。

### ① ダークパターン（意図的な誤解を招くUI設計）
GMO関連サービス（特に「お名前.com」など）で最も批判を浴びるのが、**「ダークパターン」**と呼ばれるユーザーを誘導・困惑させる画面設計です。

> **【集まった主な反応・悪評】**
> * 「ドメイン更新時、デフォルトでチェックが入っている有料オプションを外し忘れて無駄金を払わされた」
> * 「解約ボタンがどこにあるか全く分からない。迷路のようなページ遷移をさせられる」
> * 「『緊急』『重要』といった不安を煽るメールが大量に届き、開くとただの広告だった」

AI時代の現代において、直感的でクリアなUI/UXが求められる中、こうした「間違えて契約させるような設計」がエンジニアやガジェットクラスタから強く忌避されています。

### ② カスタマーサポートの質の低さと対応の悪さ
規模が大きいが故に、トラブル時のサポート対応に対する不満も根強く存在します。

> **【集まった主な反応・悪評】**
> * 「問い合わせても定型文しか返ってこない。たらい回しにされる」
> * 「電話がつながらない。サポートに繋がるまでに有料ナビダイヤルで待たされる」
> * 「解約手続きをしたはずなのに請求が続いており、問い合わせ対応も高圧的だった」

### ③ 同業者・Web業界からの悪評（アフィリエイトと買収戦略）
GMOは強力なアフィリエイト報酬を背景に、検索上位を自社・提携メディアで独占する手法を得意としています。また、他社の優秀なサービスを買収した後、GMO流の「アフィリエイト＋ダークパターン」仕様に変更してしまうケースが見られ、古くからのWeb業界人から嫌われる要因となっています。

# 2. 性能は本当に悪いの？サクラを弾いたリアルな口コミ

「評判は悪いけど、実際の性能はどうなの？」という疑問に答えるため、サクラレビューやステルスマーケティングを排除したリアルな口コミを分析しました。

### ✕ リアルな悪評（Cons）
* **隠れコストが多い:** 初年度は激安だが、2年目からの更新費用やオプション費用で結局高くつく。
* **管理画面（コントロールパネル）が重く、使いづらい:** 広告が多く、本来やりたい設定にたどり着くのに時間がかかる。
* **通知メールのスパム化:** 必要なシステム通知と広告メールが混ざって届くためノイズが多い。

### ◯ リアルな好評（Pros）
* **サーバーの処理速度（表示速度）自体はトップクラス:** 特に「ConoHa WING」や「GMOとくとくBB（v6プラス）」の回線速度・サーバー応答速度はベンチマーク的にも非常に優秀。
* **キャンペーン時の初期費用が圧倒的に安い:** 1年目の導入コストを極限まで下げたい場合には選択肢に入る。
