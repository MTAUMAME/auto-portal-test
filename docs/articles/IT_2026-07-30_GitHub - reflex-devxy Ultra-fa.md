## 4. Reflex XYを動かしてみよう！簡単サンプルコード

どれだけシンプルに書けるか、基本の折れ線グラフのコードを見てみましょう。

```python
import reflex as rx
import reflex_xy as xy

# テストデータ
data = [
    {"name": "1月", "sales": 4000, "profit": 2400},
    {"name": "2月", "sales": 3000, "profit": 1398},
    {"name": "3月", "sales": 9800, "profit": 2000},
]

def index():
    return rx.vstack(
        rx.heading("月間売上ダッシュボード", size="lg"),
        xy.line_chart(
            data=data,
            data_key="name",
            series=[
                {"data_key": "sales", "stroke": "#8884d8", "name": "売上"},
                {"data_key": "profit", "stroke": "#82ca9d", "name": "利益"},
            ],
            grid=True,
            tooltip=True,
        ),
        padding="2em",
    )

app = rx.App()
app.add_page(index)
```
これだけのPythonコードで、ツールチップ付きの超美麗なインタラクティブ・チャートが爆速で立ち上がります！
