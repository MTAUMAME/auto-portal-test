## 1. 「日本の全法令をGitにする」とは何が起きているのか？

日本の法令データ（e-Gov等で公開されているXML/HTML）をテキスト（Markdown等）に変換し、法令の「制定」「改正」をGitの**コミット履歴**として再現する取り組みです。

これによって、エンジニアやAI開発者には以下のメリットが生まれます。

*   **`git diff` で改正前後の差分が一目瞭然**（「どこがどう変わったか」を赤と緑のハイライトで一発確認）
*   **`git blame` や `git log` で施行日・改正履歴をトラッキング可能**（○年○月○日時点の法律を即座に復元）
*   **LLM（大型言語モデル）やRAG（検索拡張生成）との相性が抜群**（軽量なMarkdown構造のため、AIが誤誤認しにくい）

つまり、**「過去〜現在のあらゆる法律を、AIが最も読み取りやすい形でバージョン管理できる」**ようになったのです。
