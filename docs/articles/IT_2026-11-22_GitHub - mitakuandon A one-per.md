## 1. 5分でわかる「mitaku/andon」とは？

- **GitHubリポジトリ:** [mitaku/andon](https://github.com/mitaku/andon)
- **コンセプト:** 「ワンマン・ソフトウェア・ファクトリー（一人ソフトウェア工場）」

`andon`（アンドン：トヨタ生産方式の「行灯」が由来）は、AIコーディングエージェントを活用した全自動開発パイプラインシステムです。

### 従来のAIツールとの根本的な違い

| 項目 | 従来のAI（Cursor, Copilot等） | mitaku/andon |
| :--- | :--- | :--- |
| **人間の役割** | AIに指示を出し、コードを修正・承認する | タスクを定義し、判断を求められた時だけ答える |
| **AIの役割** | ペアプログラミングの「助手」 | 自律的に動く「開発チーム」 |
| **開発フロー** | 人間が主導 | Ledger（台帳）管理による完全非同期オートメーション |

### 動作の仕組み
1. **タスク投入:** 人間が「Ledger（タスク台帳）」にやりたいことを登録。
2. **自動実装:** AIエージェントがタスクをピックアップし、コードを記述。
3. **自動レビュー:** 別のAIエージェントがコードをレビューし、マージ（結合）まで実施。
4. **人間の呼び出し:** アーキテクチャの変更や仕様の曖昧さなど、**「人間にしかできない決定」が必要な時だけ**通知が来ます。

自律型AI開発ツールが増える中、`andon`の位置付けを明確にするため、他の有名ツールと比較しました。

### 性能・コスト比較表

| サービス名 | タイプ | 月額費用目安 | 自律性（放置度） | 導入難易度 | 最適なユーザー |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **mitaku/andon** | オープンソース（Self-Hosted） | API従量課金（約$10〜$50/月） | ★★★★★ (超高) | ★★★★☆ (高) | 個人Dev、エンジニア起業家 |

### パフォーマンス比較のポイント

- **パフォーマンス:** 1つのタスクに対して「実装エージェント」と「レビューエージェント」を分離させているため、生成されるコードの品質（バグの少なさ）は単独のChatプロンプトより遥かに高いです。

## 4. このツールを使いこなすための最適環境（ガジェット＆インフラ）

`andon`のような自律型AIエージェントを24時間フル稼働させるには、適切なハードウェアと開発インフラが必要です。

### ① 24時間稼働させる「クラウドVPS」
ローカルPCをつけっぱなしにするより、信頼できるクラウドサーバー（VPS）上でエージェントを常時実行させるのがベストです。

- **おすすめ:** **さくらのVPS** / **ConoHa VPS** / **Linode**
  - AIのタスク処理とCI/CD連携を止めることなく、安定して自動化を回せます。

### ② 大小モデルをローカルで試すなら「M3/M4 Mac」
コスト削減のために一部の処理をローカルLLM（Ollama等）に投げたい場合、ユニファイドメモリを大量に積んだMacが必須になります。

- **おすすめ構成:** **Mac mini (M4 Pro) メモリ36GB以上** または **MacBook Pro (M3/M4 Max)**
