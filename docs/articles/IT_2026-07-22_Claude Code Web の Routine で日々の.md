## 1. Claude Webの「Routine（ルーティン）自動化」とは？

従来のAIチャットは「質問して、返答を得る」という一問一答形式でした。
しかし、ClaudeのWeb版（Project機能）やClaude Codeを組み合わせることで、**「一度指示すれば、裏で自律的にタスクを完了させるルーティン化」**が可能になりました。

### 自動化できる日々の開発ルーティン例
*   **デイリーコードレビュー:** コミットされたコードのバグや脆弱性を自動検知
*   **テストコードの自動生成:** 実装コードに対して、JestやPyTestのコードを自動作成・実行
*   **仕様書・READMEの自動更新:** コードの変更を検知し、ドキュメントを最新状態に同期
*   **リファクタリング＆クリーンアップ:** 冗長なコードを検知し、より綺麗なコードを提案

これらは、Web版の「カスタム指示（Custom Instructions）」と「Project機能」を組み合わせることで、**「毎朝の定型業務」**としてボタン一つ、またはコマンド一つで実行できます。

| 比較項目 | **Claude (Web Pro / API)** | **Cursor (Pro)** | **GitHub Copilot** |

## 4. Claudeで「開発ルーティン」を構築する3ステップ

今すぐできる、Claude Web（Project機能）を使った自動化ルーティンの作り方です。

1.  **「Project」を作成する**
    Claude Web（Proプラン）の画面から「Projects」を選択し、新規プロジェクトを作成します。
2.  **コンテキスト（仕様書・コード）をアップロード**
    プロジェクト内に、あなたのアプリの「設計書」「API仕様書」「既存の主要コード」をドラッグ＆ドロップで読み込ませます。
3.  **「Custom Instructions（指示）」にルーティンを登録**
    プロジェクトの指示欄に、以下のようなプロンプトを記述します。

```text
【毎日の開発ルーティン指示】
あなたがコードの変更提案を行う際は、必ず以下のステップを自律的に実行してください。
1. 変更対象のコードに脆弱性やパフォーマンスのボトルネックがないか検証する。
2. 変更に伴い、影響を受ける既存機能のリストアップする。
3. 変更に合わせたJest用テストコードを自動生成する。
4. 最後に、日本語で「コミットメッセージ（推奨）」を出力する。
```

これで、あなたが新しいコードを貼り付けるだけで、**テスト作成からコミットメッセージの用意までが全自動で実行**されます。
