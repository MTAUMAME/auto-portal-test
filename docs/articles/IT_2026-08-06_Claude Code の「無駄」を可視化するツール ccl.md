## 1. 『cclens』とは？Claude Codeの「ブラックボックス」を解消するツール

`cclens`は、Claude Codeの実行ログやトークン消費量を解析し、**「どのファイルが、いつ、どれだけのトークン（＝お金）を消費したか」をビジュアルで可視化するオープンソースの分析ツール**です。

### 💡 主な特徴とメリット
* **ファイル別のトークン消費量をグラフ化**：不要に巨大なファイル（ビルド成果物やログファイルなど）がClaudeに読み込まれていないかを一目で特定。
* **プロンプトキャッシュのヒット率を可視化**：Claude 3.5 Sonnetの強力な機能である「プロンプトキャッシュ」が、正しく効いているかをパーセンテージで表示。
* **コスト削減のアドバイス機能**：「`.gitignore` や `.claudecoderc` にこのファイルを追加すべき」といった具体的な節約アクションを提案。

これを使うだけで、Claude Codeの利用料金を**30%〜50%削減**できたという報告が相次いでいます。
