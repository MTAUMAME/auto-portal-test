## 1. ニュースの要約：何が義務化され、何が危険なのか？

```
【ニュースのポイント】
● EUの「AI法（AI Act）」により、AI生成画像・動画への「識別表示（ラベル）」が義務化。
● 目的は、ディープフェイクや偽情報の拡散防止。
● 違反企業・個人には、最大27億円（または年間売上高の3%）の超巨額の制裁金。
● 今後、YouTubeやSNSでも「AI生成ラベル」がないコンテンツは排除・アカウントBANされるリスクが急増。
```

これからの時代、**「ただ綺麗な画像を生成するAI」は使えなくなります。** 
C2PA（コンテンツの作成元や履歴を証明する技術規格）などの**「メタデータ埋め込みに対応した安全なAIツール」**を選ぶことが必須条件となります。
