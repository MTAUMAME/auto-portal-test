## 1. Microsoft Skill Recorderとは？概要をサクッと解説

**「パソコンの画面を録画するだけで、AIがその手順を理解し、自動実行プログラム（スキル）を作ってくれる」**

これを実現するのが、Microsoftが公開した**「Skill Recorder」**です。

### 仕組みは驚くほどシンプル
1. **録画（Record）：** デスクトップ上で行う作業（ブラウザ操作、アプリの立ち上げ、テキスト入力など）をアプリで録画します。
2. **AI解析（Reconstruct）：** 録画データを「GitHub Copilot CLI」に送信。AIがユーザーの「意図（何をしたかったか）」と「順序立てた手順」を分析・テキスト化します。
3. **自動化（Build）：** Microsoftの次世代AIエージェントプラットフォームである**「Microsoft Scout」**や**「Microsoft Copilot Coworker」**で再利用可能な「スキル（Automation）」を自動生成します。

これまでは、自動化ツール（RPA）を作るために「どのボタンをクリックして、どのテキストを入力して…」と人間が細かく設定する必要がありましたが、これからは**「実際にやってみせるだけ」**でAIが勝手に作ってくれる時代になります。
