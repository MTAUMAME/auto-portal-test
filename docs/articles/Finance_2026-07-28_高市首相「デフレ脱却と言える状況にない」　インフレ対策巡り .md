### 3. 【比較表】手数料と利回りで見る「選ぶべき証券口座」
インフレ対策で最も重要なのは**「手数料を抑えること」**です。コストが高いと、インフレ以上の利益を出すハードルが上がってしまいます。

| 項目 | ネット証券大手（楽天・SBI） | 銀行窓口 |
| :--- | :--- | :--- |
| **購入時手数料** | **無料（ノーロード）** | 高い（数％かかる場合も） |
| **投資信託の品揃え** | 非常に豊富 | 限られている |
| **口座管理維持費** | 無料 | 無料だが高コスト商品が多い |
| **利回り期待値** | インデックスに連動 | 運用次第だが手数料分マイナス |

※ネット証券は、インフレに打ち勝つための「低コスト・世界分散投資」がスマホ一つで完結するため、圧倒的におすすめです。
