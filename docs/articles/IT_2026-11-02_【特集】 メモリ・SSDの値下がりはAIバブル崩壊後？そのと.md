## 1. なぜ2028年まで安くならない？AIブームが半導体を呑み込む構造

現在、Samsung、SK Hynix、Micronといった主要半導体メーカーは、**「HBM（高帯域幅メモリ）」**や**超大容量エンタープライズSSD**の生産に全力を注いでいます。

```
【従来の生産構造】
一般向けDRAM / NAND ───────────＞ 80%
サーバー / 産業用    ───────────＞ 20%

【現在の生産構造（AI特需）】
HBM / 生成AI用超高速メモリ ───＞ 60% ↑（利益率が圧倒的）
一般向けDRAM / NAND        ───＞ 40% ↓（生産ラインが削られる）
```

AIサーバー（NVIDIA H100/B200など）に使われるHBMは、従来のDRAMの数倍のダイ（シリコンウェハ）領域を消費します。つまり、**「AI向けメモリを1個作ると、PC向けメモリが数個作れなくなる」**のです。

### 「AIバブル崩壊待ち」が危険な理由

「じゃあAIバブルが崩壊したら安くなる？」と思いがちですが、専門家の見解は悲観的です。

1. **AIバブル崩壊＝IT産業全体の壊滅**  
   万が一、現在のAI投資が失敗に終わりバブルが弾けた場合、Big Tech（Microsoft, Google, Meta等）の株価が暴落し、世界的な深刻な景気後退（リセッション）に突入します。その時、個人の購買力も落ちているため「安くなっても買えない」状態になります。
2. **AI以外の構造的需要（エッジAI・PCのAI化）**  
   Windows Copilot+ PCに代表されるように、デバイス側でAIを動かすために「PC1台あたりの最低メモリ容量」が16GBから32GB/64GBへと引き上げられています。需要の底上げが起きているため、価格が暴落する理由はどこにもありません。
