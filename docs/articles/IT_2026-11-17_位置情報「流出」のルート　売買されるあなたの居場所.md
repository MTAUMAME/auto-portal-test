## 1. なぜバレる？位置情報が売買される「3つの流出ルート」

スマホのGPSをOFFにしていれば安全…大間違いです。現代のデータ収集AIはもっと賢く、巧妙です。

```
【流出ルートの構造】
[あなたのスマホ] 
  ├─ 1. 無料アプリ内の「SDK」（位置情報収集プログラム）
  ├─ 2. フリーWi-Fi接続時の「IPアドレス・BSSID（ルーター識別子）」
  └─ 3. Bluetoothビーコン（店舗や街頭のセンサー）
        │
        ▼
[データブローカー（データ売買業者）]
        │
        ▼ 【最新AIによる高精度なプロファイリング・特定】
[広告代理店 / 不動産 / 最悪の場合、ストーカー・犯罪組織へ]
```

1. **アプリに埋め込まれたSDK（開発キット）**
   一見無害なゲームやポイ活アプリに、位置収集コード（SDK）が仕込まれており、バックグラウンドで24時間データを出荷しています。
2. **Wi-Fi＆Bluetoothの三角測量**
   GPSがOFFでも、周辺のWi-Fi電波や街中のBluetoothビーコンを検知し、AIが現在地を特定します。
3. **「匿名データ」のAI再特定**
   「特定のIDが夜間にいつも同じ一軒家に留まり、昼間に〇〇ビルにいる」というAI解析だけで、氏名がなくても**自宅と職場が完全に特定**されます。
