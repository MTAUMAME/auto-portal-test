## 1. そもそも「Claude Code」と「`.claude/skills`」とは？

### Claude Codeとは？
Anthropicが開発した、ターミナル（コマンドライン）上で動作するAIエンジニアリングアシスタントです。ブラウザを開くことなく、コンパイルエラーの修正、テストの実行、Gitコミット、リファクタリングなどを自動で行ってくれます。

### `.claude/skills`とは？
Claude Codeの挙動をプロジェクトごとにカスタマイズするための**システムプロンプトや命令定義ファイル**です。
これを作成・調整（チューニング）することで、Claude Codeは「そのプロジェクトの専属シニアエンジニア」に進化します。

今、国内外のトップエンジニアたちが「俺の考えた最強の`.claude/skills`」をGitHubやXに投稿し、ノウハウを共有し合う「公開ラッシュ」が起きています。

## 2. 有名エンジニアの公開テンプレートから学ぶ「良いSkills」の書き方

一流エンジニアが公開している`.claude/skills`を分析すると、以下の**4つの黄金原則**が見えてきました。

### ① 振る舞い（ペルソナ）の厳密な定義
良いSkillは、Claudeに対して「余計な雑談をしない」「コード変更は最小限にする」といった行動規範を1行目で指定しています。

> **記述例:**
> `You are a pragmatist senior developer. Focus on clean, maintainable TypeScript. Do not explain obvious things. Keep responses minimal.`

### ② プロジェクト特有のルールの明文化
「ディレクトリ構成」「使用しているライブラリ」「テストの実行コマンド」を明記することで、Claudeの迷いをなくします。

> **記述例:**
> `- Test command: npm run test`
> `- CSS Framework: Tailwind CSS (Do not write raw CSS)`
> `- Branch naming convention: feature/issue-xxx`

### ③ 「やってはいけないこと（Don'ts）」の指定
AIが暴走してファイルを書き換えすぎるのを防ぐため、禁止事項を明確に書くのがトレンドです。

> **記述例:**
> `NEVER delete existing comments unless explicitly requested.`
> `Do not upgrade major package versions without asking first.`

### ④ ワークフローの自動化指示
Gitコミットメッセージのフォーマットや、エラー時の再試行回数をあらかじめ設定しておきます。これにより、1コマンドで「テスト実行 ➜ エラー修正 ➜ コミット」までを完結させられます。

## 3. 【比較】Claude Code vs 競合AIツール

Claude Code（Claude 3.7 Sonnet）の実力はどれほどなのか？
人気ツールの「Cursor」「GitHub Copilot」と徹底比較しました。

| 項目 | **Claude Code** (3.7 Sonnet) | **Cursor** (Pro) | **GitHub Copilot** |
| :--- | :--- | :--- | :--- |
| **主な形態** | CLIツール（ターミナル専用） | エディタ（VS Codeフォーク） | IDEプラグイン |
| **料金システム** | **従量課金制** (API利用料)<br>※目安：$10〜$100/月（使用量による） | **定額制** ($20/月〜) | **定額制** ($10/月〜) |
| **最大の特徴** | ターミナル内での高い自律性、テスト実行と修正のループ | 優れたGUI、チャットからコード生成、プロジェクト全体の参照 | 予測補完が非常に高速、エディタとの一体感 |
| **コードの質** | **最強（ハイブリッド思考モデル）** | 高い（モデル選択可能） | 普通〜高（コンテキストによる） |
| **設定の柔軟性** | **極めて高い (`.claude/skills`)** | 普通 (`.cursorrules`) | 低い |

### 比較の結論：
* **「とにかく賢く、自動でデバッグまで完結させたい」** ➜ **Claude Code**の一択。
* **「毎月の出費を固定にして、エディタで直感的に書きたい」** ➜ **Cursor**がおすすめ。
