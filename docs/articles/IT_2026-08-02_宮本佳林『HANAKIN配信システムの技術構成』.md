## 1. 宮本佳林『HANAKIN配信システム』の想定技術構成

宮本佳林さんの配信は、単なるスマホ配信ではなく、PCベースの本格的な配信システム（エンコーダー配信）が組まれていると推測されます。その構成要素を4つのセクションに分解しました。

```
【配信構成イメージ図】
[高画質ミラーレスカメラ] ──(HDMI)──> [キャプチャボード] ──> [高性能配信PC (OBS + AI処理)]
                                                                    ▲
[高音質マイク] ──(XLR)──> [オーディオインターフェース] ───────┘
```

### ① 【映像】「瞳の輝き」と「美肌」を伝える超高画質カメラ
配信で最も重要な「表情」をノイズレスで届けるため、大型センサー搭載のミラーレス一眼をWebカメラ化していると考えられます。また、最新の**「AI瞳AF（オートフォーカス）」**が彼女の激しい動きにも追従します。

### ② 【音声】スタジオクオリティのクリアな「声」
アイドルの命である「声」を届けるため、周囲の雑音（エアコンやファンの音）を拾いにくい単一指向性のダイナミックマイク、または高感度なコンデンサーマイクと、定番のミキサーを使用。

### ③ 【AI処理】環境音の完全排除とリアルタイム補正
最新の配信システムでは、**「NVIDIA Broadcast」**などのAIエフェクトを活用し、リアルタイムで背景ノイズの除去や、カメラの自動フレーミングを行っているケースが増えています。
