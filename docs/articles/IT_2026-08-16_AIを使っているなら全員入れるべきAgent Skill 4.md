## そもそも「Agent Skill（エージェント・スキル）」とは？

Agent Skillとは、AIモデル（LLM）が外部環境とやり取りするための**「道具（ツール・API・プロトコル）」**のことです。
これらを導入することで、AIは単に文章を返すだけでなく、**「自らネットで最新情報を調べ、プログラムを書き、デバッグし、スプレッドシートに書き込む」**といった自律的なタスク遂行が可能になります。

### 1. Model Context Protocol (MCP)
*〜Claude Code / Cursorユーザー必須の次世代デベロッパー・スキル〜*

```
【概要】 Anthropic社が提唱した、AIとローカルデータ/外部ツールを繋ぐオープン規格。
【対象】 開発者、ヘビーAIユーザー、Claude Code / Cursor利用者
```

*   **何ができるか？**
    *   Claude CodeやCursorなどのAIエージェントに、PC内のローカルファイル、GitHub、Brave Search、PostgreSQLデータベースなどを直接「読み書き・操作」させるスキル群。
    *   「〇〇のバグを直して、ローカルでテストを実行し、エラーがあれば修正してGitにコミットして」という指示が1行で完結します。
*   **ここが凄い：**
    規格がオープンのため、世界中の開発者が毎日新しい「スキル（MCPサーバー）」を公開しており、拡張性が無限大。
