# 築古物件の相続は「負債」か「資産」か？専門家が読み解く「実家じまい」の現実

今回話題になっている「築127年の空き家」というケースは、決して他人事ではありません。2030年には日本の住宅の3戸に1戸が空き家になると予測されており、多くのご家庭が直面するリスクです。

## 1. 【自己検証】なぜ実家じまいは「地獄」になるのか？

最新の不動産動向に基づくと、実家じまいが難航する理由は主に3つです。

*   **「負動産」化の加速:** 築年数が古い場合、耐震基準を満たさないことが多く、買い手が見つかりません。解体費だけで200万〜500万円かかることもザラです。
*   **相続放棄の落とし穴:** 「空き家がいらないから相続放棄」をしても、管理責任が残るケースがあり、法的トラブルに発展しやすいのが現状です。
*   **管理コストの増大:** 特定空き家に指定されると、固定資産税の優遇措置が解除され、税額が最大6倍になります。

## 3. 【比較】資産運用における「現金化」の重要性

不動産を抱え続けるリスクと、売却して金融資産（新NISA）に切り替えた場合の比較表です。

| 項目 | 築古空き家の保持 | 現金化→新NISA運用 |
| :--- | :--- | :--- |
| **維持費用** | 固定資産税・管理費・修繕費 | 0円（管理不要） |
| **流動性** | 非常に低い（売却に数年） | 高い（いつでも売却可能） |
| **期待リターン** | ほぼマイナス（維持費分） | 年利3〜5%（世界経済成長） |
| **手間・ストレス** | 非常に大きい | ほぼ無し |
