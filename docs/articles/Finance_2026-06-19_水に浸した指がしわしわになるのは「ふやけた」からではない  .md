# 指がしわしわになるのは「ふやけ」ではない？投資家が学ぶべき「思い込みを捨てる力」

最近、Forbes JAPANで「指がしわしわになるのはふやけたからではない（神経系による適応反応である）」という記事が話題になりました。これまで私たちは「皮膚が水を吸って膨張するからだ」と信じてきましたが、実は**「濡れた場所で物を掴みやすくするための、自律神経による能動的な反応」**だったのです。

### 1. なぜ投資家がこの現象に注目すべきか（自己検証）
多くの初心者は、投資において「みんながそう言っているから」という情報を鵜呑みにします。
*   **思い込み：**「株は危険だ」「投資はギャンブルだ」「銀行預金が一番安全だ」
*   **現実：** インフレ下での現金保有こそが、資産価値を「浸食」させているリスク。

このForbesの記事は、**「常識だと思っていたことは、実は全く別のメカニズムで動いている」**という教訓を教えてくれます。新NISAを始める際も、表面的な情報に惑わされず、数字と仕組み（利回りや手数料）という本質を見る力が不可欠です。

### 3. 【比較表】手数料と利回りの重要性
投資初心者の方がまず選ぶべき「インデックス投資」における、コストの重要性を比較します。

| 項目 | A社（手数料高め・対面） | B社（ネット証券・低コスト） |
| :--- | :--- | :--- |
| **信託報酬（年率）** | 1.5%程度 | **0.1%以下** |
| **購入手数料** | 数％かかる場合あり | **0円** |
| **利回り（期待値）** | 市場平均を下回る傾向 | 市場平均を享受できる |
| **重要性** | コストが利益を食い潰す | 利益を最大化しやすい |

※上記は一般的なネット証券（SBI証券や楽天証券など）のインデックスファンドを想定した比較です。長期運用では、この0.1%と1.5%の差が、数十年後には**数百万円の差**となって現れます。
