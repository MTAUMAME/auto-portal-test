## 1. REALFORCE RS1の主な特徴と基本スペック

「REALFORCE RS1」は、東プレが長年培ってきた「静電容量無接点方式」の技術を、エルゴノミクス（人間工学）に基づいた左右分割型ボディに落とし込んだ有線キーボードです。

| 項目 | スペック・仕様 |
| :--- | :--- |
| **キー配列** | 79キー 日本語配列（JIS） |
| **キースイッチ** | 静電容量無接点方式（東プレスイッチ） |
| **接続方式** | 有線接続（USB Type-C - 左右接続およびPC接続） |
| **キー荷重** | 変荷重 または 30g/45g（モデル展開予定） |
| **APC機能** | 搭載（アクチュエーションポイントチェンジャー） |
| **静音仕様** | あり |
| **対応OS** | Windows / macOS |

### 注目ポイント：
- **「日本語配列（79キー）」の分割モデル**：英語配列が多い分割キーボード市場において、無変換・変換キーやEnterキーが押しやすい日本語配列を採用。
- **安心の有線接続**：チャタリングや遅延、バッテリー切れの心配が一切ない安定の有線仕様。
- **APC（アクチュエーションポイント）搭載**：キーの反応深さをカスタマイズ可能。AIライティングや高速コーディングなど、用途に合わせて最適化できます。
