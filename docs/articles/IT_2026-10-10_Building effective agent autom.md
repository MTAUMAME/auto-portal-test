# 【完全解説】Anthropic公式「効果的なAIエージェント構築ガイド」要点まとめ

Anthropicが提唱するAIエージェント構築の核心は、**「不必要に複雑化させず、シンプルな設計から始めよ」**という極めて実用的なアドバイスです。

### 1. 「ワークフロー」と「エージェント」の違い
*   **ワークフロー（Workflows）：** 事前に定義されたコードとLLMのパス（処理手順）に沿って動作するシステム。**（予測可能性が高く、コスト効率が良い）**
*   **エージェント（Agents）：** LLM自身が状況を判断し、使用するツールや手順を動的に決定するシステム。**（柔軟性が高いが、制御が難しくコストがかかる）**

### 2. 成功する5つの基本パターン
1.  **プロンプトチェイニング（Prompt Chaining）：** タスクを順番に分解して処理。
2.  **ルーティング（Routing）：** 入力内容に応じて、最適な専門プロンプトやモデルへ分岐。
3.  **パラレライゼーション（Parallelization）：** 複数のタスクを並列処理してスピードアップ（または多数決で精度向上）。
4.  **オーケストレーター・ワーカー（Orchestrator-Workers）：** 親AIがタスクを分割し、子AI（ワーカー）に振って集計する。
5.  **エバリュエーター・オプティマイザー（Evaluator-Optimizer）：** 1つのAIが生成し、別のAIが評価・修正を繰り返して品質を高める。

### 3. Claude 3.5 Sonnetの強み「Computer Use」
Anthropicのエージェント戦略の目玉が、画面を見てマウス操作やキー入力を行う**「Computer Use」**機能です。これにより、APIが用意されていないレガシーなシステムでもAIが自動操作できるようになります。
