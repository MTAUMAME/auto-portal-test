## 1. Claude Codeの「Agent view」と「セッション間通信」とは？

「おうちで学ぶ」なら、まずはツールの核心を理解しましょう。Claude Codeが他のAIエディタと一線を画す理由は、以下の2つの機能にあります。

### ① Agent view（エージェント・ビュー）
Agent viewは、Claudeが「今、裏で何を考え、どのコマンドを実行し、どのファイルを書き換えているか」をリアルタイムで視覚的に監視・制御できる画面（UI）です。

*   **何が凄いの？**：従来のAIは、指示を出したら「結果が出るまでブラックボックス」でした。Agent viewを使えば、Claudeが間違った方向に進みそうな時に、**実行を一時停止（Pause）して人間が介入・修正**できます。
*   **メリット**：APIトークンの無駄遣いを防ぎ、おうちでの学習時も「AIがどう思考してコードを書いているか」プロセスを完璧に追体験できます。

### ② セッション間通信（Inter-session communication）
複数のターミナルウィンドウや、異なる開発セッション間で、**Claudeがコンテキスト（文脈や作業状態）を共有・通信し合える機能**です。

*   **何が凄いの？**：例えば、ウィンドウAで「サーバーのデバッグ」をさせながら、ウィンドウBで「フロントエンドの実装」をさせる際、AとBのClaudeがお互いの状況を理解して連携します。
*   **メリット**：手動で「さっき別の画面でこう言ったんだけど…」と説明する手間がゼロになります。
