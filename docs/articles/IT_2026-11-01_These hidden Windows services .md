## 🛑 CPUを爆食いしている「隠れたWindowsサービス」4選

Windowsには、ユーザーの利便性を高めるためにプリセットされているものの、実際にはスペックを無駄消費しているサービスが多数存在します。特に影響が大きいのが以下の4つです。

| サービス名 (英語表記) | 概要とCPUに与える影響 | 停止しても大丈夫？ |
| :--- | :--- | :--- |
| **SysMain (旧 Superfetch)** | アプリの起動を速くするためメモリやCPUを常時使用 | **停止OK**（SSD搭載PCなら不要） |
| **Windows Search** | ファイル検索用のインデックス作成でCPU/Diskを圧迫 | **条件付きOK**（検索を多用しないなら） |
| **Connected User Experiences and Telemetry** | 診断データや使用状況をMicrosoftに送信 | **停止推奨**（プライバシー保護にも） |
| **Windows Update (配信の最適化)** | 他のPCへ更新プログラムを送信（P2P動作） | **オフ推奨**（ローカルネットワークのみにする） |

---

## 🛠️ 3分でできる！隠れたサービスを安全に停止する手順

### 1. 「SysMain」と「Telemetry」を停止する（サービス管理から）

1. キーボードの `Win + R` を押し、`services.msc` と入力してEnter。
2. 一覧から **「SysMain」** を探してダブルクリック。
3. スタートアップの種類を**「無効」**に変更し、サービスの状態を**「停止」**にして「適用」。
4. 同様に **「Connected User Experiences and Telemetry」** も探して「無効＋停止」にする。

> ⚠️ **注意**: どのサービスを止めていいか分からない場合は、無闇に他のシステムファイルを触らないようにしましょう。
