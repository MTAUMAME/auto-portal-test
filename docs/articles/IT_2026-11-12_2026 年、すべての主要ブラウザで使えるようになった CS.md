## 1. 2026年、全ブラウザで解禁された神CSS機能 5選

まず、現在のWeb開発で標準となった強力なCSS機能を厳選して紹介します。

### ① コンテナクエリ（`@container`）
画面幅（ビューポート）ではなく、**親要素の大きさに応じてスタイルを変更**できる機能。コンポーネント指向の現代Web開発において必須の機能となりました。

```css
/* 親要素がカード形式になったらレイアウトを変更 */
@container sidebar (min-width: 400px) {
  .card { display: flex; }
}
```

### ② `:has()` 疑似クラス（親要素セレクタ）
「特定の小要素を持つ親要素」を指定できる、長年望まれていた夢のセレクタ。JavaScriptによるDOM操作なしでスタイルを切り替えられます。

```css
/* 画像が含まれているカードだけ背景を変更 */
.card:has(img) {
  background-color: #f0f0f0;
}
```

### ③ スクロール駆動アニメーション（Scroll-driven Animations）
ページスクロールに連動したアニメーションを、**JavaScriptゼロでヌルヌル動かす**ことが可能になりました。パフォーマンスが劇的に向上します。

### ④ ネイティブCSS Nesting（入れ子記述）
SASSなどのCSSプリプロセッサを使わず、標準のCSSだけでCSSをネスト記述できるようになりました。

### ⑤ `@starting-style`（登場アニメーション）
要素が画面に表示された瞬間（`display: none` から `block` に変わる際など）のフェードインアニメーションをCSSだけで完結できます。
