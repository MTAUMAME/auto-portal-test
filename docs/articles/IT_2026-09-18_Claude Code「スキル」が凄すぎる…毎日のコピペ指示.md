## 2. コピペを絶滅させる「Claude Code 神スキル5選」

Claude Codeでは、複雑な処理を「スキル（定型コマンドやワークフロー）」として登録・実行できます。ここでは、日常のデスクワークや開発業務を劇的に効率化する神スキルを5つ厳選しました。

### ① 自動テスト＆エラー無限修正スキル
* **何ができるか：** 
  コードを変更した際、自動でテストコマンド（`npm test`など）を実行。エラーが出たら、**エラーログを自ら解析してコードを修正し、テストが通るまでこれを自動で繰り返します。**
* **プロンプト例：**
  > `claude "テストを実行し、パスするまで関連コードを自動修正して"`

### ② 差分自動コミット＆PR（プルリク）作成スキル
* **何ができるか：**
  コードの変更内容を分析し、**適切なGitコミットメッセージを自動生成してコミット**。さらに、GitHubのプルリクエスト（PR）文面まで一撃で作成・送信します。
* **プロンプト例：**
  > `claude "現在の変更点をGitにコミットして、変更理由をまとめたPRのベースを作成して"`

### ③ ドキュメント（README）自動同期スキル
* **何ができるか：**
  ソースコードを修正した際、その変更点を読み取って**README.mdや仕様書（Markdown）を自動で最新状態にアップデート**します。ドキュメントの更新漏れがゼロになります。
* **プロンプト例：**
  > `claude "最近の変更に基づいて、仕様書とREADMEを最新の情報に書き換えて"`

### ④ 一括コードリファクタ（クリーンコード化）スキル
* **何ができるか：**
  「冗長なコードの削減」「パフォーマンス改善」「セキュリティ脆弱性の修正」を指示するだけで、プロジェクト全体の複数ファイルを横断して一括で書き換えます。
* **プロンプト例：**
  > `claude "プロジェクト内の使われていない関数を削除し、可読性を高めるリファクタリングを全ファイルに適用して"`

### ⑤ APIモック＆テストデータ自動生成スキル
* **何ができるか：**
  既存のデータベース定義（Schema）やAPI仕様を読み込ませることで、テストに必要なモックデータ（ダミーデータ）を大量に、かつ整合性を保った状態で自動生成します。
* **プロンプト例：**
  > `claude "usersテーブルの定義を元に、テスト用のダミーデータ100件をJSON形式で生成して"`
