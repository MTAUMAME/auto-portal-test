今回の第2報で特に強調されていたのは、以下の3つのトレンドと脅威です。

   * 生成AIを利用した「自然な日本語のフィッシングメール」や「脆弱性探知Bot」の増加。
   * 攻撃の自動化により、中小企業や個人ブログレベルのWEBシステムも狙われる時代に。
