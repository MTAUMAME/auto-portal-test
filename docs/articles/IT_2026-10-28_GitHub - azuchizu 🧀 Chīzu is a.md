# 【macOS】ブラウザ振り分けの神ツール「Chīzu」解説！仕事とプライベートのリンク事故を防ぐ方法

![Chīzu Concept Header](https://via.placeholder.com/800x400?text=macOS+Browser+Router+Chizu) <!-- アイキャッチ画像用プレースホルダー -->

## 1. Chīzu（🧀）とは？

**Chīzu**は、macOSの「デフォルトブラウザ」として設定することで、**クリックしたURLをルールに従って特定のブラウザやプロファイルに自動転送（振り分け）してくれる軽量ユーティリティアプリ**です。

* **GitHubリポジトリ**: [azu/chizu](https://github.com/azu/chizu)
* **開発者**: azu 氏（JavaScript/TypeScript界隈で非常に有名な日本のOSSコントリビューター）
* **価格**: **無料**（オープンソース / MITライセンス）

### 主な特徴
1. **Google Chrome / Dia の「指定プロファイル」で直接開ける**
   「仕事用のURLはChromeのWorkプロファイルで、YouTubeはPersonalプロファイルで開く」といった設定が可能です。
2. **圧倒的に動作が軽い**
   無駄なUIや重い処理を削ぎ落としたミニマル設計。
3. **設定のコード管理（IaC）が可能**
   設定ファイル（JSON/設定画面等）で管理できるため、環境構築が容易です。

## 2. 競合アプリとの性能・価格比較

Macで同様の機能を持つ「ブラウザルーター・セレクター」アプリと比較しました。

| アプリ名 | 価格 | 特徴 | プロファイル指定 | 動作の軽さ | おすすめユーザー |
| :--- | :--- | :--- | :---: | :---: | :--- |
| **Chīzu** | **無料 (OSS)** | シンプル、Chrome/Diaプロファイル特化 | **○ (強力)** | **爆速** | **エンジニア、Chrome複数プロファイル運用者** |
| **Velja** | 無料 | GUIが綺麗、ショートカット連携が豊富 | △ (一部可) | 普通 | 一般ユーザー、デザイン重視の方 |
| **Choosy** | 約$10 | 老舗。極めて詳細な条件分岐ルール | ○ | 普通 | 高機能・GUIでの複雑設定を求める方 |

### Chīzuを選ぶべき理由
多くの無料アプリは「ブラウザAかブラウザBか」の選択しかできませんが、Chīzuは**「Google Chromeの『特定のプロファイル』を指定して開く」**ことに長けています。仕事とプライベートのGoogleアカウントを分離している現代のナレッジワーカーにとって、まさに「痒い所に手が届く」仕様です。

## 3. サクラなし！リアルな口コミ・評判（メリット・デメリット）

ネット上の過剰な絶賛（サクラレビュー）を排除し、GitHubのIssueやX（旧Twitter）のエンジニア界隈からの「実際の使用感」をまとめました。

### 〇 良い口コミ（メリット）
* **「仕事アカウントで間違えてYouTubeを開く事故がなくなった」**
  SlackやNotionのリンクを踏んだ際、意図したChromeプロファイルで正しく開くため、ログインの切り替えストレスがゼロに。
* **「とにかく軽くて邪魔にならない」**
  バックグラウンドで無駄なメモリを食わないため、Macのバッテリーやスペックを圧迫しない。
* **「無料かつオープンソースで安心」**
  URLという機密情報に近いデータを扱うため、ソースコードが公開されているOSSである点はセキュリティ面で高評価。

### ✕ 惜しい口コミ（デメリット）
* **「完全な非エンジニアには設定が少し難しく感じるかも」**
  一般的なMac App Storeアプリのような親切なチュートリアルがあるわけではないため、最低限の設定ファイル理解が必要。
* **「ChromeとDia以外のプロファイル指定は今後のアップデートに期待」**
  SafariやFirefoxなど、他ブラウザのプロファイル機能への対応は限定的。
