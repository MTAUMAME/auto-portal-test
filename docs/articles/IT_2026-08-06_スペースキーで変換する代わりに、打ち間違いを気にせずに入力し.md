## 1. Nospace（ノースペース）とは？ 主な3つの特徴

「Nospace」は、LLM（大規模言語モデル）のパワーを活用した、Mac専用の次世代日本語入力システムです。

### ① スペースキー不要！流れるようなタイピング
従来のIMEのように「単語や文節ごとにスペースキーで変換する」必要がありません。ローマ字をそのまま打ち続けるだけで、AIが文章の区切りを自動判別し、リアルタイムで美しい日本語に変換していきます。

### ② 打ち間違い（タイポ）をAIが自動修正
「nihonngo（にほんご）」を「nihonngo」と打ち間違えても、AIが前後の文脈から「日本語」と予測して自動で修正・変換します。キーボードの押しミスにイライラすることがなくなります。

### ③ 文脈を理解した超高精度な同音異義語の変換
「きしゃのきしゃがきしゃできしゃした（貴社の記者が汽車で帰社した）」のような、従来のIMEが苦手とする同音異義語の連続も、AIが文脈を完璧に理解して一発で変換します。

## 2. 従来IMEとの徹底比較（性能・価格）

「Nospace」は、従来の「macOS標準」「Google日本語入力」「ATOK」と何が違うのか、表で比較してみましょう。

| 項目 | **Nospace** | **macOS標準（ライブ変換）** | **Google日本語入力** | **ATOK (Passport)** |
| :--- | :--- | :--- | :--- | :--- |
| **変換エンジン** | AI / LLMベース | ルール＆統計ベース | 統計＆Webマスターデータ | 独自解析＆ディープラーニング |
| **スペースキー変換** | **不要（自動）** | 必要（ライブ変換時は自動だが精度に難あり） | 必要 | 必要 |
| **タイポ（誤入力）修正**| **極めて高い（文脈補正）** | ほぼ無し | 軽微な補正のみ | 軽微な補正のみ |
| **変換精度（文脈理解）**| **最強（LLMによる文脈把握）** | 普通 | 高い（固有名詞に強い） | 非常に高い（日本語として自然） |
| **動作スピード** | わずかに遅延あり（AI処理） | 高速 | 高速 | 高速 |
| **オフライン対応** | 基本不可（要ネット接続） | 可能 | 可能 | 可能 |
| **価格（税込）** | 月額サブスクプラン等（※要確認） | **無料** | **無料** | 月額 330円〜660円 |
| **対応OS** | macOS | macOS / iOS | Windows / macOS / Android | Windows / macOS / Android / iOS |

### 【比較から見えるNospaceの強みと弱み】
*   **圧倒的な強み：** タイポの自動修正と、長文の一気書きにおける脳のストレスフリー感。
*   **弱み：** AI処理（API経由など）を行うため、従来のIMEに比べてわずかな入力のレイテンシ（遅延）が発生する場合がある点。また、セキュリティの観点から機密情報を入力する際のオフライン動作ができない点です。
