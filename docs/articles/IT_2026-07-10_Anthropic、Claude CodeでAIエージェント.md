## 1. gihyo.jpが解説した「Claude Code」と「エージェント・ループ」の衝撃

これまでのAIコーディングアシスタント（GitHub Copilotなど）は、人間が書いたコードの「続きを予測する」か「チャットで質問に答える」ものが主流でした。

しかし、**Claude Codeは「自律型AIエージェント」**です。

gihyo.jpの記事で紹介された**「Agentic Loop（エージェント・ループ）設計」**とは、AIが単発の回答を出して終わるのではなく、以下のようなサイクルを自動で回す仕組みを指します。

```
[指示（人間）] ➔ [計画立案（AI）] ➔ [コード作成・書き換え] ➔ [テスト・ビルドの実行] ➔ [エラー検出] ➔ [修正・再テスト] ➔ [完了報告]
```

開発者が「〇〇のバグを直してテストを通して」と1行命令するだけで、Claude Codeは自らファイルを読み込み、コマンドを実行し、エラーが出たら自らコードを修正し、テストが通るまでこのループを自動で繰り返します。まさに「優秀なジュニアエンジニアがターミナルの中に常駐している」状態です。

| ツール名 | 提供形態 | 自律性（ループ能力） | 料金モデル | メリット | デメリット |

| **Claude Code** | CLI (ターミナル) | **極めて高い（自律実行）** | API従量課金 (使った分だけ) | ターミナル完結、バグ修正の自動化が最強 | API代金が嵩む可能性あり、GUIがない |
