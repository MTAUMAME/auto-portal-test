## ゼロトラストSSHとは？なぜ「AI時代」に必須なのか？

従来のSSHは「正しい鍵を持っていれば入れる」という仕組みでした。しかし、AI時代においてこの手法には限界がきています。

### ゼロトラストSSHの3大メリット

1. **ポート開放が一切不要（完全隠蔽）**
   クラウド経由またはメッシュVPN経由で接続するため、ルーターのポートを外に開く必要がありません。IPアドレスの直打ちも不要です。
2. **鍵管理からの解放（SSO / IDプロバイダ連携）**
   GoogleアカウントやGitHubアカウントでログイン（OAuth/SAML）。多要素認証（MFA）やパスキー（YubiKey等）もそのまま使えます。
3. **AIエージェントとの相性が抜群**
   Cursor、VS Code Remote、AutoGPTなどのツールから自宅のAI学習用マシン（RTX 4090搭載機など）へアクセスする際、暗号化された安全なトンネル（Tailscale等）を一本通しておくだけで、複雑なポートフォワーディングなしで即座に連携可能です。
