## 1. 「Steering Claude Code」3つの核心機能

公式ガイドで示された、Claudeを「操縦（Steer）」するための重要なコンセプトは以下の3つです。

```
[メインのClaude (脳)] 
      │
      ├─► 【Skills (手足)】：ファイル読み書き、テスト実行、コマンド操作
      ├─► 【Hooks (監視・介入)】：人間による承認、プロンプトの動的書き換え
      └─► 【Subagents (部下)】：タスクを細分化し、別のClaudeに外注
```

### ① Skills（スキル：手足を与える）
Claudeに「ファイルを読む」「コードを実行する」「Webで検索する」といった具体的なツール（関数）を与えます。これにより、Claudeは「コードを提案するだけ」から「実際に動くコードを書き、テストまで行う」フェーズに進化します。

### ② Hooks（フック：軌道修正と介入）
AIが出力したプロセスに割り込み（フック）をかけます。例えば、「デプロイコマンドを実行する前に、人間に承認を求める」「コードが特定のセキュリティルールに違反していないか自動チェックする」といった制御が可能になります。

### ③ Subagents（サブエージェント：部下を雇う）
巨大なタスクをこなす際、メインのClaudeが「サブエージェント（別のClaude）」を立ち上げ、特定の小さなタスク（例：テストコードの作成、バグの特定）を依頼します。これにより、メインAIのメモリ（コンテキスト）を節約し、精度を劇的に向上させます。
