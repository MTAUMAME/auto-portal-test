## 1. ニュース概要：Google社員による「予測市場」インサイダー事件

米司法省の発表によると、起訴されたGoogleのソフトウェアエンジニアは、同社が開発中のAI技術や提携に関する**一般公開前の機密情報（インサイダー情報）**にアクセス。その情報を基に、予測市場で巨額の賭け（ベット）を行い、約2億円の不当な利益を得たとされています。

### なぜ「予測市場」が使われたのか？
従来の株式市場ではなく、Web3やAIの発展で急成長している**「予測市場（Prediction Market）」**が舞台になった点が極めて現代的です。
予測市場は「次の大統領は誰か？」「このAIモデルはいつリリースされるか？」といった未来の出来事にお金を賭けるプラットフォーム。情報の非対称性を利用したインサイダー取引の温床として、規制当局（CFTCなど）が監視を強めています。

## 2. 徹底比較：主要な予測市場プラットフォーム

今回の事件で一躍注目を浴びた「予測市場」。現在、世界でシェアを争う2大プラットフォーム**「Polymarket（ポリマーケット）」**と**「Kalshi（カルシ）」**を比較します。

| 項目 | Polymarket（ポリマーケット） | Kalshi（カルシ） |
| :--- | :--- | :--- |
| **運営形態** | 分散型（Web3 / 仮想通貨ベース） | 中央集権型（認可された金融取引所） |
| **主な通貨** | USDC（暗号資産） | 米ドル（法定通貨） |
| **規制** | 米国居住者は原則利用不可（規制外） | 米国商品先物取引委員会（CFTC）認可 |
| **特徴** | 政治、AI、エンタメなど取扱ジャンルが膨大 | 米国で合法的に取引可能、信頼性が高い |
| **取引量** | 圧倒的に多い（数千億円規模） | 成長中だがPolymarketには及ばない |

AIの未来予測やハイテク企業の動向を追うなら、これらの市場データを追うだけでも非常に有益です。
