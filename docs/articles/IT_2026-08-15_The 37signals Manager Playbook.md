## 1. 『The 37signals Manager Playbook』とは？

『The 37signals Manager Playbook』は、37signals社が社内向けに作成したマネジメントの行動指針を無償公開したものです。彼らが提唱するプロダクト開発手法「Shape Up」の思想をベースに、**「いかに会議を減らし、メンバーの自律性を引き出すか」**に特化しています。

### 主なキーコンセプト
1. **非同期コミュニケーション（Async First）**: 基本的にチャットやドキュメントで完結させ、リアルタイムの会議は最終手段とする。
2. **1on1の再定義**: 進捗確認（それはツールで見ればいい）ではなく、メンバーのキャリアやメンタルケアに特化する。
3. **「信頼」の初期設定**: 監視ツールは一切使わず、アウトプットのみで評価する。
4. **マネージャーは「障害排除人（Sweeper）」**: 指示を出すのではなく、メンバーが作業に集中できる環境を整える。
