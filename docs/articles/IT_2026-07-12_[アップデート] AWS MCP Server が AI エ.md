## 1. そもそも何が変わった？アップデートの概要

これまでの「AWS MCP Server」を使ってClaude DesktopからAWSを操作する場合、**ローカル環境にAWSのアクセスキー（Credentials）を生で保存し、それを読み込ませる必要**がありました。これは万が一PCがハッキングされたり、設定ファイルを誤って共有したりした際の**情報漏洩リスク（セキュリティ懸念）**が非常に高い状態でした。

しかし、今回のアップデートにより、業界標準の認可プロトコルである**「OAuth 2.1（AWS Sign-In経由）」**がサポートされました！

### 💡 アップデートによる最大のメリット
* **アクセスキーの管理が不要：** ブラウザが立ち上がり、いつものAWSログイン画面（AWS Builder IDやIAM Identity Center）で認証するだけで接続可能。
* **期限付きトークンで安全：** 認証後は一時的なセッショントークンが発行されるため、万が一PC内の設定が漏れても被害を最小限に抑えられます。
* **複数アカウントの切り替えが容易：** ブラウザ経由でのサインインなので、プロジェクトごとの切り替えがスムーズに。
