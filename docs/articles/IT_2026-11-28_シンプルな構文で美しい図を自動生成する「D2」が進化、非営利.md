## 1. そもそも「D2」とは？何が変わったのか？

### D2の基本機能
D2（Diagrams 2）は、シンプルなテキスト（コード）を書くだけで、プロデザイナーが作ったかのような美しい図（構成図、フローチャート、シーケンス図など）を自動生成してくれるツールです。

```d2
# これだけで美しい図が完成！
x -> y: コール
y -> z: レスポンス
```

### 🚨 今回の二大ニュース：非営利化と「TALA」の完全OSS化

1. **非営利団体（NPO）への移行**
   開発元のTerrastruct社は、D2を特定の企業利益に左右されない「永続的なパブリックグッド（公共財）」とするため、非営利組織に移行しました。これにより、**将来的な突然の有料化やサービス終了のリスクが激減**しました。
2. **独自レイアウトエンジン「TALA」のオープンソース化**
   これまでD2の最大の強みでありながら一部制限があった強力な自動レイアウトエンジン「TALA」が、完全にオープンソース化（Apache 2.0などのライセンス）されました。これにより、**誰でも無料で、複雑な図でも一瞬で美しく配置する最強の環境**が手に入ります。

## 4. 【実践】AI（ChatGPT / Claude）× D2 で図形描画を爆速化する方法

D2の真価は**「生成AI」**と組み合わせた時に発揮されます。以下のプロンプトをChatGPTやClaudeに入力してみてください。

### AI用プロンプト例
```text
以下のシステム構成をD2のコード形式で出力してください。
装飾や解説は不要で、コードブロックのみ出力してください。

【構成要素】
・ユーザー（スマホアプリ）
・Cloudflare（CDN）
・Next.js（フロントエンド/Vercel）
・Go言語API（AWS ECS）
・PostgreSQL（AWS RDS）

【接続関係】
ユーザー -> Cloudflare -> Next.js -> Go API -> PostgreSQL
```

これを公式の「[D2 Playground](https://play.d2lang.com/)」やVS CodeのD2拡張機能に貼り付けるだけで、**わずか5秒でプレゼン資料レベルの構成図が完成**します。
