## 1. 最強コマンド `git log --graph --oneline --decorate --all` とは？

このコマンドは、Gitの履歴を「視覚的に」「1行で」「すべてのブランチを含めて」「タグやヘッドの位置付きで」表示する、エンジニア必須のコマンドです。

まずは、それぞれのオプションが持つ意味をサクッと理解しましょう。

```
* 7a2f3b1 (HEAD -> main, origin/main) feat: AIによるコミットメッセージ自動生成機能を追加
* 91c8d4e (tag: v1.0.0) fix: 軽微なバグ修正
| * 3a8b2c4 (origin/feature/ai-integration) feat: Cursor APIとの連携実装
|/
* 5e9d1a0 chore: 初期コミット
```

### 各オプションの役割

*   **`--graph`**：ブランチの分岐や合流（マージ）をアスキーアート（`*` や `|`、`/`）で視覚的に表現します。
*   **`--oneline`**：1つのコミットを1行に凝縮して表示します（コミットハッシュの短縮版＋コミットメッセージ）。
*   **`--decorate`**：`HEAD`の位置、ローカルブランチ名、リモートブランチ名（`origin/main`など）、タグ名（`v1.0.0`など）を色付きで分かりやすく表示します。
*   **`--all`**：現在チェックアウトしているブランチだけでなく、**すべてのローカル・リモートブランチの履歴を網羅**して表示します。

### 💡 読み方のポイント
1.  **「星（`*`）」はコミットを指す**：縦に並ぶ `*` は同じブランチの歴史。枝分かれしている部分は並行開発されているブランチ。
2.  **「（括弧内）」で現在地を知る**：`(HEAD -> main)` は、あなたが今 `main` ブランチの最新コミットにいることを示します。
3.  **エイリアス（ショートカット）登録推奨**：毎回打つのは面倒なので、`.bashrc` や `.zshrc` に `alias glog="git log --graph --oneline --decorate --all"` と登録しておきましょう。
