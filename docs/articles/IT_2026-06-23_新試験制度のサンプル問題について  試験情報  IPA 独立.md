## 1. IPA「新試験制度」とサンプル問題のポイント

まず、IPAが発表している新試験制度とサンプル問題の要点を、テック視点でシンプルにまとめます。

```
【主な変更点と特徴】
・試験時間の短縮と出題数のスリム化（例：基本情報技術者は科目A・科目Bに再編）
・プログラミング言語の「擬似言語」への統一
・数理・データサイエンス・AI（ディープラーニングなど）に関する出題の強化
・CBT（PC画面での受験）への完全移行
```

### なぜ「サンプル問題」の分析が必須なのか？
新制度では過去問がそのまま出題されるケースが減り、**「本質的な理解」と「問題解決能力」**が問われます。IPAが公開しているサンプル問題は、**「新傾向の難易度や出題パターンを教えてくれる唯一の公式コンパス」**なのです。
