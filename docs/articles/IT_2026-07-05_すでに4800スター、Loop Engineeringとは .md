## 1. Loop Engineeringとは？「プロンプト」から「自律ループ」へ

これまで、ChatGPTなどのAIを使いこなすには「プロンプト（指示文）」を工夫する技術（プロンプトエンジニアリング）が必要でした。

しかし、**Loop Engineering**は全く異なるアプローチです。

### 「思考のループ」を設計する技術
Loop Engineeringとは、**AIエージェントに「計画→実行→評価→修正」というループ（繰り返し処理）を自律的に行わせるシステムを設計する技術**です。

```
[指示（ゴール）]
   ↓
┌→ [1. 計画 (Plan)]
│      ↓
│  [2. 実行 (Act)]
│      ↓
│  [3. 評価/テスト (Reflect)]
│      ↓
└─ [4. 修正 (Loop)] (ゴールを達成するまで自動で繰り返す)
```

人間が「1コードずつ指示」を出すのではなく、**「目標に到達するまで、AI自身がエラーを自己修正しながらループを回し続ける仕組み」**を作ること。これこそが、これからのエンジニアやクリエイターに求められるスキルになります。
