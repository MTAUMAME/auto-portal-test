## 1. 私はこうやってWaymoに乗った！乗車までの4ステップ

「英語が話せないと乗れない？」「どうやって呼ぶの？」
結論から言うと、**日本のスマホとクレジットカードがあれば、誰でも簡単に乗車できます。**

実際に私が乗車した手順がこちらです。

```
【乗車までの流れ】
①「Waymo One」アプリをダウンロード（USアカウント不要、日本のApp Store/Google PlayでOK）
② アカウント作成＆日本のクレジットカード（Visa/Masterなど）を登録
③ 目的地を設定し、料金を確認して「Request ride」をタップ
④ 到着した車両に近づき、スマホアプリから「Unlock（開錠）」をタップ
```

### 驚きの体験：運転席には誰もいない
ドアを開けると、目の前にあるのは**誰もいない運転席と、勝手にぐるぐると回るステアリングホイール**。
後部座席のモニターには、LiDAR（レーザーセンサー）がリアルタイムで検知している周囲の3Dマップ（歩行者や他の車、カラーコーンまで正確に描写）が表示されており、AIの圧倒的な認知能力に鳥肌が立ちました。

## 2. 【比較表】Waymo vs Uber vs Tesla FSD

自動運転レベル4を誇るWaymoは、従来のライドシェア（Uber）や、テスラの運転支援システム（FSD）と何が違うのか比較しました。

| 比較項目 | **Waymo（ウェイモ）** | **Uber（有人タクシー）** | **Tesla FSD（監視付き自動運転）** |
| :--- | :--- | :--- | :--- |
| **自動運転レベル** | **レベル4**（完全無人） | レベル0（人間が運転） | レベル2（ドライバーの監視が必要） |
| **乗車料金** | Uberと同等〜1.2倍程度 | 標準（時間帯で変動） | 車両購入＋月額サブスクが必要 |
| **安全性・信頼性** | **極めて高い**（事故率は有人車の85%減） | 運転手の質に依存する | 荒削りな挙動があり、監視が必要 |
| **チップ** | **不要（0円）** | 必要（15%〜20%） | なし（自家用車のため） |
| **コミュ力不要度** | 100%（一言も話さなくて良い） | 0%（挨拶やスモールトークが必要） | - |
| **サービスエリア** | サンフランシスコ、LA、フェニックス等 | 全世界 | 全世界（一般公道） |

### 性能・価格の総評
Waymoの最大のメリットは**「チップ不要」「コミュ力不要」「極めて安全でスムーズ」**という点です。
料金自体はUberと同等ですが、アメリカ名物の「チップ（15〜20%）」を払わなくて良いため、**実質的にUberより安くなるケースが多発**しています。

## 3. サクラレビュー排除！Waymoの「リアルな口コミ・評判」

ネット上の「案件記事」や「誇大広告」を排除し、実際に現地で何度も使っているユーザーの**リアルな本音（メリット・デメリット）**をまとめました。

### ⭕ リアルな高評価（サクラなし）
* **「ドライバーとの気まずい沈黙がないのが最高すぎる」**
  アメリカのUberでありがちな、無理なスモールトークや、大音量の音楽、タバコ臭さから完全に解放されます。
* **「運転がプロ。急ブレーキや急加速が一切ない」**
  人間よりも安全運転です。歩行者や自転車への譲り合いも完璧。
* **「車内が超清潔」**
  毎回清掃されているわけではないはずですが、変なゴミや匂いがなく、新車の香りがします。

### ❌ リアルな低評価・デメリット（ここがイマイチ）
* **「ピンポイントで目の前に止まってくれないことがある」**
  交通ルールを厳守するため、駐停車禁止エリアや交差点付近では、少し離れた安全な場所まで歩く必要があります。
* **「ルートが少し遠回りになる」**
  交通量の多い交差点での「左折（日本でいう右折）」を避けるアルゴリズムになっているため、人間が運転するより数分到着が遅れることがあります。
* **「雨の日や工事現場付近で、たまにフリーズして立ち往生する」**
  安全第一に設計されているため、迷ったときは道路の真ん中で停車して遠隔サポートの指示を待つことがあります。
