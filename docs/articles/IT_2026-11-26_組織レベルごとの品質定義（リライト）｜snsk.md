## 1. 「組織レベルごとの品質定義（snsk手法）」とは？

「snsk」氏が提唱する**組織レベルごとの品質定義**とは、単に「AIに文章を綺麗に書かせる」のではなく、**「誰が・どの立場（役職・部署）で・何の目的で使うか」によってAIリライトの合格基準（品質定義）を明確に分ける**という設計思想です。

従来のAI導入が失敗する原因の9割は、「全員が同じレベルのプロンプトを使い、バラバラな品質のテキストを出力してしまうこと」にあります。これを回避するため、組織を以下の3段階に分類して品質を管理します。

```
【組織レベル別・AIリライトの品質定義】

 ┌────────────────────────────────────────────────────────┐
 │ L3: エグゼクティブ・対外発信レベル (役員・広報)          │
 │  ⇒ コンプライアンス・ブランディング・戦略的整合性を厳格化 │
 ├────────────────────────────────────────────────────────┤
 │ L2: チーム・マネジメントレベル (管理職・リーダー)        │
 │  ⇒ トーン＆マナーの統一・論理構造の最適化・意思決定の明確化 │
 ├────────────────────────────────────────────────────────┤
 │ L1: メンバー・日常業務レベル (一般社員)                  │
 │  ⇒ 誤字脱字チェック・要約・メール文面作成・スピード重視    │
 └────────────────────────────────────────────────────────┘
```

この定義をAIの「システムプロンプト」や「チーム共有ナレッジ」に組み込むことで、組織全体のテキスト品質が劇的に向上します。
