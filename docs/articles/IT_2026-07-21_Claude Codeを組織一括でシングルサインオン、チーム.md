## 1. 「Claude apps gateway for AWS/Google Cloud」とは？

一言で言えば、**「Claude Codeなどの外部AIツールと、AWS（Bedrock）/ Google Cloud（Vertex AI）の強固なセキュリティを安全につなぐプロキシ（中継）システム」**です。

これまで開発者が個別にAPIキーを発行して利用していたClaude Codeを、企業のクラウドインフラ配下に置くことができます。

### 主な機能とメリット

1.  **組織一括でのシングルサインオン（SSO）**
    OktaやMicrosoft Entra ID（旧Azure AD）など、既存の社内IDプロバイダーと連携し、一元的にアクセス権を管理。
2.  **チーム・個人単位の費用上限設定（バジェット管理）**
    「Aチームは月50ドルまで」「個人は月20ドルまで」といった予算上限を設定可能。上限に達すると自動でAPIがストップするため、予期せぬ高額請求を防げます。
3.  **デフォルト設定・システムプロンプトの統制**
    社内ルールに則ったシステムプロンプト（「社外秘情報は送信しない」等）や、使用するモデル（Claude 3.5 Sonnet推奨など）を管理者側で固定できます。
4.  **ログの一元管理**
    誰が、いつ、どのようなコードを生成したかのログをすべてクラウド側に保存。監査ログとしての利用が可能です。

## 2. 【比較】直接契約 vs AWS / Google Cloud 経由

Claudeを「直接APIで使う場合」と、「AWS/Google Cloud（Gateway経由）で使う場合」の価格や性能を比較しました。

| 比較項目 | Anthropic直接（API） | AWS Bedrock / Google Cloud Vertex AI (Gateway経由) |
| :--- | :--- | :--- |
| **従量課金料金** | 標準価格（Sonnet: $3/Input, $15/Output） | 同等（クラウドベンダーの割引プラン適用可能な場合あり） |
| **SSO対応** | 基本なし（Enterpriseプランのみ） | **対応（Okta, Entra ID等と連携）** |
| **予算上限設定** | アカウント全体のみ | **チーム・個人ごとに細かく設定可能** |
| **セキュリティ・データ保護** | Anthropicの規約に準拠 | **各社のクラウドセキュリティ基準（HIPAA, SOC2等）をクリア** |
| **レイテンシ（反応速度）** | 高速 | **同等〜高速（国内リージョン使用時により安定）** |
| **導入ハードル** | 低い（クレジットカード登録のみ） | 中（AWS/GCPのインフラ知識が必要） |

**結論：**
個人開発や数人のスタートアップなら「直接契約」で十分ですが、**5人以上のチーム、中堅・大企業、または機密情報を扱う開発プロジェクトでは「AWS/Google Cloud（Gateway経由）」の一択**となります。
