### 3. 【初心者向け】手数料と利回りの比較表

資産運用で「生贄」を払わないために、まずはコスト意識を持ちましょう。

| 項目 | ネット証券（SBI・楽天など） | 銀行・対面証券 |
| :--- | :--- | :--- |
| **購入時手数料** | **無料（ノーロードが基本）** | 1%〜3%程度かかる場合あり |
| **信託報酬（維持費）** | **非常に低い（0.1%以下も多数）** | 比較的高め（1.0%前後〜） |
| **相談の有無** | なし（自己責任） | あり（担当者がつく） |
| **おすすめ度** | **★★★★★（初心者こそこちら）** | ★★☆☆☆（コスト重視なら非推奨） |

※比較は一般的な目安です。銘柄により異なります。

**ポイント：** 長期投資では「信託報酬（運用コスト）」のわずかな差が、10年後・20年後に数十万円以上の差となって現れます。
