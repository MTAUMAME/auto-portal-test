## 1. 「シャットダウン＝遮断」の衝撃。日本IBMの偉大なる「意訳」の歴史

昭和後期から平成初期、海外から入ってくる最新のコンピューター用語をどう日本語にするか、日本IBMのローカライズチームは猛烈に頭を悩ませていました。

当時、PC雑誌やマニアからは「英語のままの方がカッコいい」「無理やり日本語にするな」と叩かれたりもしましたが、彼らの訳は非常に論理的で、かつ日本語として美しいものでした。

| 英語（カタカナ） | 日本IBMなどの初期意訳 | 現代での評価・センス |
| :--- | :--- | :--- |
| **Shutdown** | **遮断（しゃだん）** | **【超秀逸】** 単に「電源を切る」ではなく、システムや電流を安全に「遮る」という本質を捉えた見事な訳。 |
| **Interrupt** | **割込み（わりこみ）** | 現在でもプログラミング用語として完全に定着。 |
| **Default** | **既定（きてい） / 初期値** | 当時は「債務不履行」のイメージが強かった言葉を、システム用語として定着させた功績。 |
| **Directory** | **目録（もくろく） / 索引** | 現在の「フォルダ」に近い概念。和風ですが本質を突いています。 |
| **Medium** | **媒体（ばいたい）** | メディアのこと。今や日常用語化しています。 |

当時は「遮断する」というメッセージが画面に出ると「なんか物々しい」「怖い」と笑われたりもしましたが、現代の目で見ると、**言葉の壁を乗り越えて日本人にテクノロジーを普及させようとした、凄まじい執念と知性**を感じざるを得ません。
