## 2. GitHub Copilot × ChatGPT「ハイブリッド効率化」メソッド

この2つをどう使い分けるのが最も効率的なのか？ 黄金のワークフローを紹介します。

```
【上流工程：ChatGPT】仕様・設計の相談、アルゴリズムの選定
      ↓
【実装工程：GitHub Copilot】エディタ上での爆速コーディング・ボイラープレート生成
      ↓
【テスト・修正：ChatGPT】複雑なエラーログの解析、コードのリファクタリング
```

### ① ChatGPT（脳）で「設計図」を作る
いきなりコードを書くのではなく、ChatGPTに「〇〇な機能を実装したい。最適なデータベース設計と、必要な関数の一覧を提案して」とプロンプトを投げます。
全体像（アーキテクチャ）をChatGPTに決めさせるのが、バグを未然に防ぐコツです。

### ② GitHub Copilot（手）で「爆速タイピング」
設計が決まったら、VS Codeを開きます。コメント欄に `// 〇〇のAPIからデータを取得する関数` と書くだけで、GitHub Copilotが次のコードを1秒で予測提案（Tabキーで決定）してくれます。
退屈なテンプレコード（ボイラープレート）を書く作業は、これでゼロになります。

### ③ エラーが起きたら ChatGPT（デバッガー）へ丸投げ
Copilotで書いて動かなかった場合や、難解なエラーが出た時は、エラーログごとChatGPTにペーストします。「このエラーの原因と修正案を教えて」と聞けば、一瞬で解決策を提示してくれます。
