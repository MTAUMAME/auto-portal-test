## 1. 「Pixel Refiner」とは？

「Pixel Refiner」は、AIが生成した「ドット絵風の画像」を、Webブラウザ上で**一瞬にして「クリーンな本物のドット絵」に変換・最適化するWebツール**です。

### 主な特徴
1. **ピクセルパーフェクト（グリッド吸着）**：ボケたピクセルを検出し、指定した解像度（32x32、64x64、128x128など）の正確なグリッドに再配置します。
2. **インテリジェント減色処理**：AI特有の「中途半端な中間色」やノイズを排除し、美しいカラーパレットに自動で制限します。
3. **輪郭線のクリア化**：ドット絵において最も重要な「アウトライン」を検出し、ハッキリとした境界線を再構築します。
4. **Webブラウザで完結**：重いソフトのインストールは不要。ドラッグ＆ドロップだけで即座に変換可能です。
