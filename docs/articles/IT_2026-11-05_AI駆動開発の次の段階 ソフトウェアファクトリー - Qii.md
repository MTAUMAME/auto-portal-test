## 1. 3分でわかる「ソフトウェアファクトリー」とは？

Qiita記事で唱えられている「ソフトウェアファクトリー」とは、簡単に言えば**「開発プロセスの完全自動化ライン」**のことです。

これまでの歴史を振り返ると、AI開発は以下のように進化しています。

*   **フェーズ1：AIアシスタント（〜2023年）**
    *   関数単位のコード自動補完（例: GitHub Copilot初期）
*   **フェーズ2：AIエージェント（2024年〜現在）**
    *   プロンプト1つでファイル作成やバグ修正を実行（例: Cursor, Devin）
*   **フェーズ3：ソフトウェアファクトリー（これからの未来）**
    *   PM（要件定義）、アーキテクト（設計）、コーダー（実装）、テスター（テスト）の**各AIエージェントが連携し、パイプライン上でソフトウェアを全自動生成する**。

人間は「工場長（監督者）」として、要件の入力と最終成果物のレビューを行うだけの時代がすぐそこまで来ています。
