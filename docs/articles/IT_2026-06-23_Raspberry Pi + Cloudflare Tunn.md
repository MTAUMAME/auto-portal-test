## そもそも「Cloudflare Tunnel」とは？なぜ安全なのか？

通常、自宅サーバーを外部公開するには以下の高いハードル（とリスク）がありました。

1.  ルーターの**ポート開放（3000番や80/443番など）**が必要 ＝ ハッカーからの格好の標的に
2.  固定IPアドレスの契約（月額数千円）またはDDNSの設定が必要
3.  プロバイダの規約（ポート開放禁止など）に引っかかる

これを一撃で解決するのが**Cloudflare Tunnel**です。

```
[自宅ラズパイ] ──(アウトバウンド接続)──> [Cloudflare] <─── [一般ユーザー]
※自宅ルーターのポートを開ける必要は一切なし！
```

仕組みはシンプル。ラズパイ側からCloudflareのサーバーへ向けて「内側から」暗号化コネクションを確立します。ユーザーはCloudflareを経由してラズパイにアクセスするため、**自宅のグローバルIPアドレスは一切露出しません。**しかも、**完全無料**で利用可能です。

## 超簡易！構築のロードマップ（3ステップ）

1.  **ラズパイをSSD起動でセットアップ**
    「Raspberry Pi Imager」を使い、SSDに「Raspberry Pi OS Lite (64-bit)」を書き込んで起動します。
2.  **Cloudflareにドメインを登録**
    取得した独自ドメインのDNSをCloudflare管理に変更します（無料）。
3.  **Cloudflare Tunnel（cloudflared）の導入**
    ラズパイのターミナルで以下のコマンドを実行するだけ。
    ```bash
    curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64 -o cloudflared
    chmod +x cloudflared
    # あとはCloudflareのダッシュボードに表示されるコマンドを貼り付けるだけ！
    ```

詳しいコマンドやDockerを使ったWordPressの立ち上げ方法は、[次回の記事]で徹底解説します！
