## 1. なぜ「Fable 5」と「Sonnet 5」の分業でコストが下がるのか？

結論から言うと、**「全てのタスクを最高知能（高単価）にやらせるのは無駄」**だからです。

*   **Fable 5（顧問役）：**
    極めて高度な論理的思考、システム設計、全体のプロット作成が得意。ただし、API価格は高価。
*   **Sonnet 5（実行役）：**
    高速かつ、指示されたテンプレートに沿ったコード生成やテキスト量産が得意。コストはFable 5の数分の一。

### 【最強の分業ワークフロー】
1.  **設計（Fable 5）：** 「こんなWebアプリを作りたい。設計書と、Sonnet 5に渡すための詳細なプロンプト（指示書）を作って」と依頼。
2.  **実行（Sonnet 5）：** Fable 5が作った精密な指示書をSonnet 5に入力し、実際のコードや文章を高速・大量に出力させる。

このアプローチにより、脳ミソを使う部分だけにお金を払い、手を動かす作業は高コスパなAIに任せることで、**性能をほぼ落とさずにAPIコストを約60%〜80%削減**することが可能になります。

## 2. 【スペック・価格比較】Fable 5 vs Sonnet 5

まずは、両モデルのスペックとAPI料金の違いを数字で見てみましょう。

| 評価項目 | **Fable 5 (最高峰・顧問モデル)** | **Sonnet 5 (高速・実行モデル)** |
| :--- | :--- | :--- |
| **役割** | 戦略立案、設計図作成、超難問解決 | コード生成、リライト、大量処理 |
| **入力(Input) / 1M tokens** | $15.00 (約2,250円) | **$3.00 (約450円)** ※1/5！ |
| **出力(Output) / 1M tokens** | $60.00 (約9,000円) | **$15.00 (約2,250円)** ※1/4！ |
| **処理スピード** | やや慎重（思考プロセスを挟むため） | **爆速（Fable 5の約3倍）** |
| **推論能力 (ベンチマーク)** | 98.2% (業界最高峰) | 88.5% (実用上十分すぎるレベル) |
| **コンテキストウィンドウ** | 200k tokens | 200k tokens |

※1ドル＝150円換算。

コスト差は一目瞭然です。
Fable 5だけで10万文字の出力を伴うデバッグやシステム開発を行うと、一瞬で莫大なコストがかかりますが、**最初の設計（数千トークン）だけをFable 5で行い、残りのコード生成（数万トークン）をSonnet 5に任せる**ことで、財布へのダメージを極限まで抑えられます。
