## 1. なぜWindows 11は重い？原因は「AI機能」と「過剰な初期サービス」

Windows 11には、バックグラウンドで動作する「サービス」が数百種類も存在します。
特に最近のアップデートでは、**AIアシスタント「Copilot」**や**システム分析（テレメトリ）**、**ウィジェット機能**などが強化され、バックグラウンドの負荷は増す一方です。

これらの「使っていない機能」を停止（ダイエット）することで、以下のような劇的なメリットが得られます。

*   **メモリ（RAM）の空き容量が1〜2GB増加**
*   **CPU使用率が下がり、PCの発熱やファン雑音が減少**
*   **ゲームのフレームレート（FPS）向上や、AI画像生成の高速化**

## 2. 【安全第一】停止しても問題ない「隠れた不要サービス」リスト

Windowsの「サービス」管理画面（`Win + R`キーを押し、`services.msc`と入力してエンター）から、以下のサービスを「手動」または「無効」に変更できます。

| サービス名（表示名） | 主な役割 | 停止して良い理由・対象者 |
| :--- | :--- | :--- |
| **Connected User Experiences and Telemetry** | Microsoftへの使用状況データの送信 | 個人情報の保護とメモリ節約のため、全員停止推奨。 |
| **Geolocation Service** | 位置情報の取得 | デスクトップPCなど、GPSやマップアプリを使わないなら不要。 |
| **Touch Keyboard and Handwriting Panel...** | タブレット用のタッチキーボード | ノートPCやデスクトップで、ペン入力や画面タッチを使わないなら不要。 |
| **Windows Image Acquisition (WIA)** | スキャナーやカメラからの画像取り込み | 外付けスキャナーやデジカメを直接PCに繋いで取り込まないなら不要。 |
| **Distributed Link Tracking Client** | ネットワーク内のNTFSファイルリンク管理 | 個人で使うPCや、一般家庭のネットワーク環境なら不要。 |
