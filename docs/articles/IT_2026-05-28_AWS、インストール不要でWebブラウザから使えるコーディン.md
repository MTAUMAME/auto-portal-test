## 1. AWS「Kiro Web」とは？3つの革命的特徴

「Kiro Web」は、AWSが提供するブラウザ完結型のAIコーディングエージェントです。最大の強みは**「インストールの壁をゼロにしたこと」**にあります。

### ① インストール不要！URLにアクセスするだけで開発スタート
従来のCursorやVS Code + Copilotのように、アプリのインストールや拡張機能の設定、APIキーの発行などは一切不要。ブラウザを開くだけで、専用のクラウド開発環境（エディタ＋プレビュー画面＋ターミナル）が立ち上がります。

### ② 自律的に動く「エージェント機能」
「〇〇なWebアプリを作って」と指示するだけで、AIが単なるコード生成にとどまらず、**「ファイル構成の作成」「エラーの自己修正」「プレビュー画面での動作確認」までを自動でループ実行**して完成させます。

### ③ AWSサービスとの超強力なシームレス連携
生成したコードを、ワンクリックでAWS（Amplify、S3、Lambdaなど）にデプロイ可能。インフラ構築の知識が浅いフロントエンドエンジニアや非エンジニアでも、一瞬でWebサイトを世界に公開できます。

## 2. 徹底比較！Kiro Web vs Cursor vs GitHub Copilot

いま最も熱いAIコーディングツール3種を、価格・性能・手軽さの観点から比較表にまとめました。

| 比較項目 | **AWS Kiro Web** (新登場) | **Cursor** (現王者) | **GitHub Copilot** (定番) |
| :--- | :--- | :--- | :--- |
| **動作環境** | **Webブラウザのみ**（インストール不要） | 専用デスクトップアプリ | VS Code / JetBrains等の拡張 |
| **初期設定** | **不要**（AWSアカウントで即起動） | 必要（アプリ導入、設定） | 必要（拡張機能の導入） |
| **主なAIモデル** | Claude 3.5 Sonnet / Amazon Nova | Claude 3.5 / GPT-4o / Gemini | GPT-4o / Claude 3.5 |
| **デプロイ連携** | **AWSへ1クリックでデプロイ** | 手動または外部連携が必要 | 手動またはGitHub Actions経由 |
| **無料プラン** | あり（月間クレジット制） | あり（月150回高速リクエスト） | なし（個人は有料のみ） |
| **有料プラン（個人）** | 月額 $19 / または従量課金 | 月額 $20 (Pro) | 月額 $10 (Individual) |

### 比較まとめ：どれを選ぶべき？
*   **Kiro Webが向いている人**：環境構築をサボりたい人、AWSにサクッとデプロイしたい人、iPadなどの軽量デバイスで開発したい人。
*   **Cursorが向いている人**：ローカルの重厚なプロジェクトをガッツリ開発したい、既存のVS Code環境を維持したいプロエンジニア。
*   **GitHub Copilotが向いている人**：使い慣れたIDE（VS CodeやIntelliJ）のまま、補完機能をメインで安く使いたい人。
