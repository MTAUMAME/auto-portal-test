## 1. AI時代のcurl「ax」とは？

「ax」は、一言で言えば**「自然言語で命令できる、LLM（大規模言語モデル）を搭載したcurl」**です。

*   **GitHubリポジトリ**: [yusukebe/ax](https://github.com/yusukebe/ax)

### これまでの方法（curl）
```bash
curl -s https://example.com/api/news | jq '.articles[0:3] | {title: .title, url: .url}'
```
これだと、APIの構造を理解し、複雑な`jq`コマンドを組み立てる必要がありました。

### axを使った方法
```bash
ax https://example.com/news "最新のニュースを3つ、タイトルとURLだけでリストアップして"
```
これだけで、AIが対象のWebページやAPIのレスポンスを読み解き、指定したフォーマットで情報を抽出してくれます。

### 主な特徴
- **マルチプラットフォーム**: Go言語製で、Mac、Linux、Windowsで軽快に動作。
- **主要LLMに対応**: OpenAI (GPT-4oなど)、Anthropic (Claude 3.5 Sonnet)、Google (Gemini)、Grokなど主要なAPIをサポート。
- **シンプルな設計**: 余計な設定をせず、環境変数にAPIキーを入れるだけで即使える。
