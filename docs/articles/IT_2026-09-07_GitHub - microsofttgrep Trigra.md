## 1. 「microsoft/tgrep」とは？

**tgrep**は、MicrosoftがGitHubで公開しているオープンソースの**Trigram（3文字組）インデックス型・正規表現検索ツール**です。

*   **GitHubリポジトリ**: [microsoft/tgrep](https://github.com/microsoft/tgrep)
*   **ライセンス**: MIT（商用利用可能・無料）
*   **開発言語**: Go

### 主な特徴：クライアント/サーバーアーキテクチャ
従来の `grep` や `ripgrep` は、検索コマンドを叩くたびにハードディスク（SSD）上のファイルを走査します。
一方、`tgrep` は**事前にコードの「インデックス（索引）」を作成してサーバー（バックグラウンドプロセス）として常駐**させます。クライアントから検索命令を送ると、そのインデックスを使って一瞬で結果を返すため、ディスクI/Oのボトルネックを完全に解消します。

## 2. 性能・スペック比較

定番の高速検索ツール「ripgrep」および「従来のGNU grep」とスペックを比較しました。

| 項目 | **microsoft/tgrep** | **ripgrep (rg)** | **GNU grep** |
| :--- | :--- | :--- | :--- |
| **方式** | **インデックス型 (C/S構造)** | スキャン型 (シングルバイナリ) | スキャン型 |
| **検索速度（2回目以降）**| **異次元（数ミリ秒〜数十ミリ秒）** | 高速（数秒〜数十秒） | 低速（数分〜） |
| **初回インデックス作成**| 必要（コード量に応じて数分） | 不要 | 不要 |
| **メモリ消費量** | 中〜大（インデックス保持のため）| 極小 | 極小 |
| **検索対象の規模** | **数GB〜数百GBの巨大コード** | 数MB〜数GBの中規模コード | 小規模コード |
| **正規表現サポート** | RE2（一部制限あり） | PCRE2 / Rust regex | POSIX / PCRE |

### なぜtgrepは圧倒的に速いのか？
`tgrep` は、テキストを3文字ずつのペア（Trigram）に分解してインデックス化します。
例えば、`search` という単語は `sea`, `ear`, `arc`, `rch` に分解され、これらがコード内のどこにあるかを事前にデータベース化しています。そのため、正規表現検索であっても、ディスクを一切スキャンせずにメモリ上のインデックスだけで候補を極限まで絞り込めるのです。
