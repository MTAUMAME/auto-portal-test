## 1. そもそも「MCP」とは？ 7月28日アップデートの破壊力

**MCP（Model Context Protocol）**とは、Anthropic社が提唱した、ClaudeなどのAIモデルとローカル環境（ファイル、データベース、GitHub、ツールなど）を安全かつシームレスに接続するための共通規格です。

これまでのMCPは、接続を維持し続ける「ステートフル（セッション維持型）」が基本でした。しかし、これには以下の問題がありました。

*   **サーバーのメモリ消費が激しい**（接続数に比例して負荷が増加）
*   **接続切れに弱い**（モバイル環境や不安定な回線でセッションが切れると再接続処理が発生）
*   **サーバーレス（Cloudflare WorkersやAWS Lambdaなど）で動かしにくい**

### 7月28日版「ステートレス接続」でここが変わる！
今回のアップデートにより、接続ごとに状態を保持しない**「ステートレスな接続」**が正式サポートされます。
Webでいう「HTTP」のような一問一答形式の通信が可能になるため、**サーバー側の負荷が極限まで下がり、接続の安定性が爆発的に向上**します。

そして、これに間髪入れず対応を表明したのが**「GitHub MCPサーバー」**です。これにより、AIによるコード生成やリポジトリの解析が、これまでとは比較にならないほど高速かつ安定して行えるようになります。

## 2. 【徹底比較】ステートフル（従来） vs ステートレス（新仕様）

今回のアップデートによる性能とコストの変化を分かりやすく表にまとめました。

| 比較項目 | 従来のステートフル接続 (〜7/27) | 新仕様：ステートレス接続 (7/28〜) |
| :--- | :--- | :--- |
| **接続の安定性** | 回線切断時にエラー・再起動が必要 | 自動復帰（リトライ）が容易で超安定 |
| **サーバーメモリ消費** | **多い**（セッション維持のためメモリを占有） | **極小**（処理時のみメモリを消費） |
| **インフラコスト** | 常時起動サーバーが必要（月額コスト高） | サーバーレス（FaaS）対応で**月額ほぼ無料も可能** |
| **GitHub連携速度** | コネクション確立のオーバーヘッドあり | 即時応答（体感速度が約1.5倍に向上） |
| **API制限・耐性** | 接続エラー時の再送処理が煩雑 | 冪等性（Idempotency）の確保により再試行が容易 |

開発者にとっては**「安く、速く、壊れにくい」**環境が手に入り、一般のAIユーザーにとっては**「ClaudeやCline（VS Code拡張）のレスポンスが爆速になる」**という恩恵があります。
