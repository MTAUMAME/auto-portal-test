## 1. 話題のQiita記事「違反できないコードを書かせる」とは？

元のQiita記事では、Anthropic社がリリースしたターミナル統合型AI**「Claude Code」**を使い、AIがバグや規約違反のコードを出力することを「構造的に防ぐ」仕組み（設計）について書かれています。

重要なポイントは**「ガイド」**と**「センサー」**という2つの概念です。

```
[開発者] ──指示──> [ Claude Code ] ──コード生成──> [ センサー (自動テスト/静的解析) ]
                           ^                                 │
                           └────────── エラーフィードバック ────┘ (違反があれば自動修正)
```

### ①「ガイド（Guide）」：守るべきルールの明文化
AIに対して「こういうコードを書いて」と指示するだけでなく、プロジェクト固有のルール（命名規則、アーキテクチャ、禁止事項）を**`CLAUDE.md`**などの設定ファイルに明文化して読み込ませます。これがAIにとっての「憲法」になります。

### ②「センサー（Sensor）」：違反を検知して自動修正させる仕組み
ガイドがあっても、AIがルールを無視することがあります。そこで、**「コードを書いた後に、自動でリンター（ESLintなど）やテストを実行し、エラーが出たらClaude自身に自己修復させる」**というループを作ります。

Claude Codeはターミナルを自律的に操作できるため、**「コード生成 ➔ テスト実行 ➔ エラー検知 ➔ コード修正」を人間を介さずに全自動で行う**ことができます。これが「違反できない（違反したままコミットできない）コード」の正体です。

## 2. Claude Code vs ライバルAI徹底比較（価格・性能）

「結局、CursorやGitHub Copilotと何が違うの？」という疑問にお答えするため、現在人気のコード生成AIツールと比較しました。

| 機能/項目 | **Claude Code** (CLI) | **Cursor** (IDE) | **GitHub Copilot** |
| :--- | :--- | :--- | :--- |
| **主な形態** | ターミナル (CLI) | 専用コードエディタ | エディタ拡張機能 |
| **最大の強み** | コマンド実行・テスト自動化 | 高度なUI、マルチファイル参照 | 高速なコード補完 (インライン) |
| **料金体系** | **従量課金制** (API使用量) | 月額 **$20** (Proプラン) | 月額 **$10** (個人プラン) |
| **搭載モデル** | Claude 3.5 Sonnet 等 | GPT-4o, Claude 3.5 Sonnet等 | Copilot専用モデル |
| **自律性** | **極めて高い** (テスト実行〜修正) | 中 (ユーザーが実行指示) | 低 (補完がメイン) |

### 💡 比較のポイント
* **コスパ重視なら「GitHub Copilot」**: 補完メインなら月額$10で使い放題。
* **総合的な開発体験なら「Cursor」**: GUIで視覚的に操作でき、初心者からプロまでおすすめ。
* **圧倒的な生産性・自律化なら「Claude Code」**: API課金のためヘビーに使うと高額になりますが、テスト自動化を含めた「エージェント（身代わり開発者）」としての能力は随一です。
