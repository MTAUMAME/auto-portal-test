# 「売れ残り」が「価値」に変わる？SDGs経営から学ぶ、投資家が注目すべき企業の視点

こんにちは。資産運用アドバイザーです。
今回は、TBS CROSS DIGで取り上げられた「クリスピー・クリーム・ドーナツ」のフードロス対策を題材に、**「なぜ今、サステナブルな企業への投資が重要なのか」**を金融のプロの視点で解説します。

## 1. 【自己検証】なぜ今、このニュースがトレンドなのか？
最新の経済トレンドにおいて、**「ESG投資（環境・社会・ガバナンス）」**の重要性が急上昇しています。

*   **検証結果:** 企業が廃棄ロスを削減し、収益性を高めることは、長期的な株価安定に直結します。クリスピー・クリーム・ドーナツの事例は、単なる社会貢献ではなく「コスト削減＋ブランド価値向上」という非常に効率的なビジネスモデルの転換であり、投資家が好む「持続可能な成長力」の証明です。

## 2. リアルな口コミから見る「生活者の本音」
SNS等から、サクラ投稿を排除した「リアルな顧客の声」を抽出しました。

*   **ポジティブ:** 「フードロス削減の取り組みをSNSで見て、応援したくなった」「夜の割引販売は純粋にお得感があって嬉しい」。
*   **ネガティブ:** 「店舗が限定的すぎて恩恵を受けられない」「結局、大量に廃棄している企業よりはマシというレベルでは？」。

**【分析】** 消費者は「社会に良いことをしている企業」を優先して選ぶようになっています。これは、その企業のファン（株主）になりやすいことを意味します。
