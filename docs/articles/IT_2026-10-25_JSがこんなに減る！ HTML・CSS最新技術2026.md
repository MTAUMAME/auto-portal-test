### JSを消し去る！最新HTML・CSS機能4選

1.  **Popover API ＋ CSS Anchor Positioning**
    *   **旧：** JSライブラリ（Popper.jsなど）で複雑な位置計算をしてツールチップやモーダルを表示。
    *   **新：** HTMLの `popover` 属性とCSSの `anchor()` だけで、画面端のめり込み防止まで自動計算。
2.  **CSS Scroll-driven Animations**
    *   **旧：** `IntersectionObserver` やJSライブラリ（GSAP）でスクロール連動アニメーションを実装。
    *   **新：** CSSの `animation-timeline: scroll()` 1行で、パララックスやプログレスバーが完成。
3.  **View Transitions API**
    *   **旧：** SPA（Single Page Application）を組み、JSでページ遷移アニメーションを自作。
    *   **新：** 普通のHTML遷移なのに、アプリのような滑らかな画面切り替えがCSS数行で可能に。
4.  **CSS `:has()` 擬似クラス**
    *   **旧：** 親要素や特定の条件に応じたスタイル変更のためにJSでクラスを付与。
    *   **新：** 「子要素に特定のエラーがある親要素」などをCSSだけで検知してデザイン変更。
