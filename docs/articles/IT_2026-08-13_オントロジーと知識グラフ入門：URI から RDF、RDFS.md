## 1. Qiita記事「オントロジーと知識グラフ入門」の要点まとめ

この記事は、一見難解なセマンティックウェブの基本技術を、ステップバイステップで非常に明快に整理しています。主要なキーワードと、その役割を以下にまとめました。

```
【知識グラフの技術スタック（下から上へ積み上がる）】
[ SPARQL ] （データの検索・クエリ）
   ▲
[ 推論 (Reasoning) ] （新しい事実の自動導出）
   ▲
[ OWL ] （より複雑な関係性・制約の定義）
   ▲
[ RDFS ] （クラスやプロパティの階層構造）
   ▲
[ RDF ] （主語・述語・目的語のトリプル構造）
   ▲
[ URI ] （インターネット上のすべてのモノを識別するID）
```

1. **URI（Uniform Resource Identifier）**
   - すべての概念やモノにユニークな「住所（ID）」を割り当てます。これにより、表記揺れを防ぎます。
2. **RDF（Resource Description Framework）**
   - 情報を**「主語（Subject）」「述語（Predicate）」「目的語（Object）」**の3つ（トリプル）で表現するデータモデルです（例：「AI」は「技術」である）。
3. **RDFS（RDF Schema）**
   - RDFに「クラス（型）」や「プロパティ（属性）」の概念を追加し、情報の階層構造（例：「リンゴ」は「果物」のサブクラス）を作ります。
4. **OWL（Web Ontology Language）**
   - RDFSよりもさらに強力な表現力を持つ言語。「同値関係（AとBは同じ）」や「対称関係（AがBの友人なら、BもAの友人）」などを定義できます。
5. **推論（Inference / Reasoning）**
   - 定義されたルールに基づき、コンピュータが自動的に「新しい知識」を導き出す仕組みです。
6. **SPARQL（スパークル）**
   - 知識グラフ（RDFデータ）を検索するための、SQLに似た専用のクエリ言語です。

### なぜ今、この記事が「神記事」と呼ばれるのか？
これまでは「Webを賢くする」という文脈で語られていたこれらの技術が、**「LLMの外部知識ベース（GraphRAG）」として完璧にフィットする**ことが判明したからです。LLMに直接RDFやSPARQLを解釈させることで、驚異的な精度のAIシステムが構築可能になります。
