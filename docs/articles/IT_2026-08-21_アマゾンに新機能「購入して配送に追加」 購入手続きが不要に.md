## 1. Amazonの新機能「購入して配送に追加」とは？

「購入して配送に追加」は、**すでに確定した注文の発送前であれば、新しい商品をワンクリックで同じ配送便（同じ箱）に追加できる機能**です。

### 従来の「買い忘れ」との違い

| 項目 | 従来の買い方 | 新機能「購入して配送に追加」 |
| :--- | :--- | :--- |
| **購入手続き** | 再度カートに入れて決済手続きが必要 | **ワンクリックで完了**（手続き不要） |
| **配送箱（梱包）** | 別々の箱で届くことが多い（ゴミが増える） | **一つの箱にまとまる**（エコ＆受け取りが1回） |
| **送料** | 注文ごとに発生する場合がある | 先の注文と同梱されるため**追加送料なし** |

### AIとスマートショッピングの融合
Amazonはこの機能の裏側で、発送センター（FC）の在庫状況やトラックの配送ルートを**AIでリアルタイムに最適化**しています。ユーザーが「追加」ボタンを押した瞬間に、AIが「既存の荷物と同じ箱に入れられるか」を瞬時に判断し、最適な配送計画を再構築しているのです。

## 2. 楽天市場・Yahoo!ショッピングとの「購入・配送性能」比較

他の大手ECサイトにも同様の機能があるのか、比較してみました。

| 比較項目 | **Amazon（新機能）** | **楽天市場** | **Yahoo!ショッピング** |
| :--- | :--- | :--- | :--- |
| **注文後の商品追加** | **可能（ワンクリック）** | 原則不可（一度キャンセルが必要） | 原則不可（ストアに要問い合わせ） |
| **同梱（まとめ配送）** | **自動で最適化** | 店舗が同じ場合のみ（要要望欄記入） | 店舗が同じ場合のみ（対応は店舗次第） |
| **購入の手軽さ** | ★★★★★（手続きなし） | ★★☆☆☆（店舗ごとの決済） | ★★★☆☆（PayPay連携でスムーズ） |
| **配送スピード** | **最短当日〜翌日** | 店舗による（数日〜1週間） | 店舗による（数日〜1週間） |

**結論：** 
楽天市場やYahoo!ショッピングは「個別の商店の集まり」であるため、注文確定後の同梱処理は非常に困難です。一方、自社で巨大な物流網とAIを抱える**Amazonだからこそ実現できた、圧倒的な技術力の勝利**と言えます。
