## 1. Claudeが導入した「LLM電子透かし（ウォーターマーキング）」の仕組みとは？

見た目は普通の日本語なのに、なぜ「AIが書いた」とバレるのでしょうか？
その裏側には、高度な確率論と暗号技術が使われています。

### 仕組み：トークン選択の「偏り（バイアス）」を作る
通常、AIは「次に来る確率が最も高い単語（トークン）」を予測して文章を作ります。

```
【例】「私は昨日、美味しい［ ？？ ］を食べた。」
［ ？？ ］に入る候補：
1. ラーメン（確率 40%）
2. カレー（確率 30%）
3. リンゴ（確率 10%）
```

電子透かしの技術（主に「Green/Red List」法など）では、事前にAIモデル内に**「秘密のルール（擬似乱数）」**を持たせます。
このルールに基づき、単語の候補をランダムに「グリーンリスト（使用推奨）」と「レッドリスト（使用制限）」に振り分けます。

*   **人間が書く場合：** グリーンもレッドも関係なく、自然に単語を選びます。
*   **透かし入りAIが書く場合：** 意味が不自然にならない範囲で、**意図的にグリーンリストの単語を多めに選択**して文章を生成します。

人間が読んでも100%自然な文章に見えますが、専用の検出器（ディテクター）にその文章を通すと、**「グリーンリストの単語が統計的にあり得ない超高確率で出現している」**ことが瞬時に分かり、AI生成文だと見破れる仕組みです。
