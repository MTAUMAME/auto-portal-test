## 1. そもそも「Agent Harness」とは？Qiita記事の要点まとめ

まずは、今回ピックアップしたQiita記事の概要と、Agent Harnessの基本についてまとめました。

> **参考元記事:** Agent Harnessを理解するために、150行ほどのPythonで自作してみた（Qiita）

### Agent Harnessの役割
「Harness（ハーネス）」とは、安全ベルトや馬具を意味する言葉です。AI文脈における**Agent Harnessとは、LLM（大規模言語モデル）に「ツール（関数やAPI）」を使わせ、目的を達成するまで自律的に思考と実行を繰り返させるための「制御フレームワーク（外枠）」**を指します。

### Qiita記事のハイライト（ここが凄い！）
LangChainなどの巨大なフレームワークを使うと、裏で何が起きているかブラックボックスになりがちです。この記事では、**あえて外部ライブラリに頼らず約150行の純粋なPythonコード（OpenAI API使用）だけでAgent Harnessを実装**しています。

**【150行のコードで実現しているコア機能】**
1. **Tool Calling（ツール呼び出し）**: LLMに「計算機」や「Web検索」などの自作関数を認識させる
2. **Execution Loop（実行ループ）**: LLMの返答が「ツール実行要求」なら実行し、その結果を再度LLMに渡す
3. **Finish Condition（終了判定）**: タスクが完了したらループを抜けてユーザーに最終回答を返す

「AIエージェントの正体は、実はシンプルな`while`ループと適切なプロンプト管理なんだ」ということが直感的に理解できる名記事です！

## 2. 【自作 vs 既存ツール】コスト・性能比較

AIエージェントを導入するにあたり、「150行のコードで自作する」のか「LangChain等のOSSを使う」のか「AutoGPTやDevinなどの有料SaaSを使う」のか、どれがベストなのでしょうか？

価格と性能を比較表にまとめました。

| 項目 | ① 完全自作 (150行Python) | ② OSS利用 (LangChain/CrewAI) | ③ 有料SaaS (Devin/Claude Projects等) |
| :--- | :--- | :--- | :--- |
| **月額コスト** | **API従量課金のみ**（数円〜数千円） | **API従量課金のみ** | 月額 $20 〜 $500+ |
| **初期学習コスト** | **低〜中**（Pythonの基礎知識でOK） | **高**（抽象度が高く学習が必要） | **ゼロ**（画面操作のみ） |
| **カスタマイズ性** | **無限大**（不要な処理を排除可能） | **高**（プラグインが豊富） | **低**（ベンダー依存） |
| **動作スピード** | **最速**（無駄なオーバーヘッドなし）| 中〜遅（依存ライブラリの処理） | ネットワーク/サーバー依存 |
| **保守・運用** | 全て自己責任 | コミュニティ依存 | ベンダーにお任せ |

### 💡 結論
- **学習・特定タスクの最適化**なら ➔ **① 完全自作**が最強（コスト最安・爆速）
- **複雑なマルチエージェント**なら ➔ **② OSS利用**
- **コードを書かずに自動化したい**なら ➔ **③ 有料SaaS**
