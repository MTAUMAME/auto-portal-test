## 1. Claudeの「Loops（インタラクティブ・ループ）」とは？

通常、AIにプログラミングを依頼すると、「コードを出力して終わり」でした。エラーが出たら再度コードをコピーして貼り付け、また修正してもらう……この往復が非常に面倒でした。

Claudeが提案する**「Loops（ループ）」**とは、以下のサイクルを**チャット画面から離れることなく瞬時に繰り返す（ループする）機能**です。

```
[指示を出す] ➔ [AIがコード生成] ➔ [右側画面で即アプリが起動（プレビュー）] 
      ▲                                           │
      └────── [「ここを赤くして」とフィードバック] ◄─────┘
```

### 誰でも始められる！ループ機能の始め方（3ステップ）

1. **Claude（Web版）にログイン**：無料プランでも利用可能です。
2. **「Artifacts」機能をONにする**：設定（Settings）の「Feature Preview」からArtifactsを有効化します。
3. **プロンプトを投げる**：「テトリスを作って」「お小遣い帳アプリをReactで作って」と日本語で指示するだけで、右側のプレビュー画面で実際に動くアプリが起動します。
