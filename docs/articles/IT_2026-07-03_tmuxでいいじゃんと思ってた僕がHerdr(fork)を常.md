## 1. そもそも「Herdr (fork)」とは？

「tmuxで十分」「Zellijもあるじゃん」と思ったそこのあなた。僕も全く同じ意見でした。

**Herdr（ハーダー）**は、Rustで書かれた次世代のターミナルセッションマネージャー/マルチプレクサです。オリジナル版の開発が停滞したことを受け、有志のコミュニティによってフォークされ、現在爆速でアップデートが重ねられているのがこの**「Herdr (fork)」**です。

### tmuxユーザーの「痒いところ」に手が届く仕様
tmuxは強力ですが、以下のような「地味なストレス」がありませんか？
*   `Prefix + [ ` からのスクロールやコピペ（OSのクリップボードとの連携）が面倒
*   `.tmux.conf` の秘伝のタレ（設定ファイル）が肥大化し、新規環境でのポータビリティが低い
*   マウス操作との親和性が微妙に悪い

Herdr(fork)は、これらの**「tmuxの不満」をすべてデフォルト（Out of the Box）で解決**してくれます。

## 2. 徹底比較：tmux vs Zellij vs Herdr (fork)

現在人気のマルチプレクサ/モダンターミナル機能と、Herdr(fork)を徹底比較しました。

| 比較項目 | **tmux** | **Zellij** | **Herdr (fork)★** | **WezTerm (内蔵マルチプレクサ)** |
| :--- | :--- | :--- | :--- | :--- |
| **開発言語** | C言語 | Rust | **Rust** | Rust |
| **ライセンス/価格**| 無料 (OSS) | 無料 (OSS) | **無料 (OSS)** | 無料 (OSS) |
| **設定の容易さ** | 難（要カスタマイズ）| 中（自動UI） | **極めて容易（直感的）**| 中（Luaによる記述） |
| **起動・動作速度** | 爆速 | 高速 | **爆速（リソース消費極小）**| 高速（GPU依存） |
| **画面分割/操作性**| キーバインド必須 | UIガイドあり | **ハイブリッド（マウス＆キー）**| Lua設定による |
| **セッション復元** | 要プラグイン | 標準対応 | **標準対応（超強力）** | やや不安定 |
| **コピペ操作** | 設定が必要 | 標準対応 | **OSクリップボードと自動同期** | 標準対応 |

### Herdr(fork)が勝るポイント：
Zellijほど画面（UI）がうるさくなく、tmuxのようにミニマル。かつ、**「セッションの永続化と自動復元」の安定性が異常に高い**点です。PCを再起動しても、作業状態がミリ秒で復元されます。
