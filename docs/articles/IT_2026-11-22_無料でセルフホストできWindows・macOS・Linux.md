## 1. WyrmRSSとは？主な特徴とメリット

WyrmRSS（ウィームRSS）は、個人サーバーやクラウドにインストールして使用する**セルフホスト型のRSSリーダー**です。

### 🌟 主な特徴

1. **完全無料＆オープンソース（OSS）**
   有料プランへの誘導や機能制限、鬱陶しい広告表示は一切ありません。データはすべて自分の手元に保存されるため、プライバシー面も安心です。
2. **クロスプラットフォーム対応（Win / macOS / Linux）**
   Webブラウザ版だけでなく、**Windows、macOS、Linux向けのネイティブデスクトップアプリ**が用意されています。動作が非常に軽量で、ショートカットキーでの爆速情報処理が可能です。
3. **YouTube動画のアプリ内再生**
   YouTubeチャンネルのRSSを登録すれば、アルゴリズムに邪魔されることなく最新動画をチェック可能。アプリ内でそのまま動画再生が完結します。
4. **Discord・Slackへのwebhook自動通知**
   「特定キーワード（例: GPT-5, Apple, 新製品）を含む記事が更新されたらDiscordやSlackに通知する」といったBotのような運用が標準機能で設定できます。

## 4. WyrmRSSの導入方法（かんたん3ステップ）

セルフホストと聞くと難しく感じますが、**Docker**を使えば数分で立ち上がります。

1. **VPS（または自宅サーバー/NAS）を用意する**
2. **`docker-compose.yml` ファイルを作成して実行**
   ```yaml
   version: '3.8'
   services:
     wyrmrss:
       image: wyrmrss/core:latest
       ports:
         - "8080:8080"
       environment:
         - DATABASE_URL=sqlite:///data/wyrm.db
       volumes:
         - ./data:/data
   ```
3. **PCアプリをダウンロードしてサーバーURLを入力・連携**
