## 1. DbGateとは？主な特徴とメリット

「DbGate」は、ElectronとSvelteで作られた、モダンかつ軽量なオープンソース（MITライセンス）のデータベース管理ツールです。

### 📌 主な特徴
1. **圧倒的な対応データベース群**
   * **SQL系**: MySQL, PostgreSQL, SQL Server, SQLite, MariaDB, CockroachDB, Oracle（プラグイン対応）
   * **NoSQL/その他**: MongoDB, Redis
2. **クロスプラットフォーム＆Webブラウザ対応**
   * Windows, macOS, Linux用のアプリに加え、**Dockerイメージ**も公開。サーバーにデプロイすれば、ブラウザ経由でどこからでもDBにアクセス可能。
3. **プラグインによる機能拡張**
   * テーマの変更や、新しいデータベースドライバーの追加が容易。
4. **強力なクエリデザイナーとグラフ化機能**
   * SQLを書かずにデータを視覚的に結合できるデザイナーや、取得データをその場でチャート化する機能を標準搭載。
