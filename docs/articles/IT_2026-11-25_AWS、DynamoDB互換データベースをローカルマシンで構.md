## 1. ExtendDB v1.0とは？開発者が狂喜乱舞する理由

ExtendDBは、AWS DynamoDBのAPIと高い互換性を持つ、ローカルマシン環境向けに設計された軽量・高速なオープンソースデータベース（OSS）です。

### 主な特徴とバージョン1.0での進化
- **完全オフライン動作**: インターネット接続なしでDynamoDB APIを呼び出し可能。
- **超軽量・爆速レスポンス**: Rust/Go等で再構築されており（※実装依存）、Javaベースの公式DynamoDB Localよりメモリ消費が少なく、レスポンスが高速。
- **AWS SDK / CLIとそのまま連携**: エンドポイントURLを`http://localhost:xxxx`に書き換えるだけで、コードの修正はゼロ。
- **v1.0での進化点**: トランザクション処理（TransactWriteItemsなど）の再現性が向上し、Secondary Indexの同期遅延シミュレーション機能などが追加され、本番環境により近いテストが可能に。

## 2. 徹底比較！「AWS DynamoDB」vs「公式Local」vs「ExtendDB v1.0」

開発者が最も気になる「コスト」「パフォーマンス」「使い勝手」を比較表にまとめました。

| 項目 | AWS DynamoDB (クラウド) | AWS公式 DynamoDB Local | **ExtendDB v1.0 (OSS)** |
| :--- | :--- | :--- | :--- |
| **月額費用** | 従量課金 (書き込み/読み込み/容量) | **0円** (ローカル) | **0円** (完全無料・OSS) |
| **動作環境** | AWSクラウド | ローカル (Java JRE必須) | ローカル (Docker / バイナリ) |
| **メモリ消費** | なし (クラウド側) | やや重い (200MB〜500MB+) | **超軽量 (数MB〜50MB程度)** |
| **テスト実行速度** | ネットワーク遅延あり (中〜遅) | 普通 (Javaのオーバーヘッド) | **爆速 (ミリ秒以下の応答)** |
| **オフライン開発**| 不可 | 可能 | **可能** |
| **環境構築の手間**| IAM・VPC等の設定が必要 | Docker等で比較的簡単 | **Dockerコマンド1発で完了** |

### 比較の総括
ExtendDB v1.0の最大のメリットは、**「CI/CDパイプラインやローカルテストの実行速度が桁違いに速くなること」**と**「開発中のAWS破産を完全に防げること」**です。
