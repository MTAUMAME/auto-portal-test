## 1. Bluesky、X、Threadsの徹底比較

まずは、主要3大SNSのスペックや特徴を分かりやすく表にまとめました。Blueskyは単なる「Twitterのクローン」ではなく、技術的にも全く新しい「分散型プロトコル（AT Protocol）」を採用している点が特徴です。

| 比較項目 | **Bluesky（ブルースカイ）** | **X（旧Twitter）** | **Threads（スレッズ）** |
| :--- | :--- | :--- | :--- |
| **運営元** | Bluesky PBSC（独立組織） | X社（イーロン・マスク） | Meta（Instagram傘下） |
| **利用料金** | **完全無料**（広告なし） | 無料（有料プランあり：月額980円〜） | **完全無料**（将来的な広告導入の噂あり） |
| **分散型/中央集権** | **分散型（AT Protocol）**<br>※サーバーを自分で選べる | 中央集権型 | 分散型（ActivityPub連携中）<br>※基本はMetaの管理 |
| **最大文字数** | 300文字 | 280文字（有料プランは25,000文字） | 500文字 |
| **カスタムフィード**| **○（好みのアルゴリズムを選べる）**| ×（おすすめ or フォロー中のみ） | ×（おすすめ or フォロー中のみ） |
| **API利用** | **無料・制限ほぼなし** | 有料（高額） | 一部公開（開発者向け） |
| **AI学習への利用** | **ユーザーの許可なしには不使用** | デフォルトでAI（Grok）学習に使用 | Meta AIの学習に使用 |

### スペック比較から見えるBlueskyの強み
Blueskyの最大のアドバンテージは、**「広告がないこと」**と**「タイムラインのアルゴリズム（カスタムフィード）を自分で選べること」**です。
Xのように「見たくないインプレゾンビ（閲覧数稼ぎのスパム）」や「過激な炎上投稿」が勝手にタイムラインに流れてくることがありません。また、AIの学習ソースに勝手に使われないため、多くのイラストレーターやクリエイターが移住しています。
