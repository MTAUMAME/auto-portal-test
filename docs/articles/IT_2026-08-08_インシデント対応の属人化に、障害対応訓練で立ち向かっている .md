# 【属人化解消】tebikiに学ぶ障害対応訓練の重要性と、運用を自動化する最新AIツール比較

## 1. tebiki Tech Blogの記事概要：何が素晴らしいのか？

まずは元記事「[インシデント対応の属人化に、障害対応訓練で立ち向かっている - tebiki Tech Blog](https://tech.tebiki.co.jp/)」のポイントをクイックにまとめます。

### 抱えていた課題
* **インシデント対応の属人化**：特定の「強いエンジニア（ベテラン）」だけが対応し、他のメンバーは見てるだけ、または対応方法がわからない状態。
* **手順書の形骸化**：せっかく作ったドキュメントが、実際の障害発生時に役に立たない。

### 取り組んだ解決策：障害対応訓練（GameDay形式）
tebiki社では、実際に本番環境に近いシミュレーションを行う「障害対応訓練」を定期実施しました。
1. **シナリオの作成**：実際に起こりうる障害を想定。
2. **役割分担の明確化**：司令塔（コマンダー）、実作業者（オペレーター）、広報（コミュニケーション）に分ける。
3. **ふりかえり（ポストモーテム）**：何が課題だったかを徹底的に洗い出す。

### 得られた成果
* メンバー全体の「心理的ハードル」の低下。
* 手順書のアップデートと、対応プロセスの標準化。
* **「誰でも初期対応ができる」**体制への一歩。
