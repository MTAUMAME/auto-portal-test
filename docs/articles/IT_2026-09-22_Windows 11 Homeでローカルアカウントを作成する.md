## 1. Windows 11 Homeでローカルアカウントを作成する新たな「抜け道」

現在、最も確実で対策されにくい「抜け道」は、**「コマンドプロンプトによるネットワーク接続プロセスのバイパス」**、または**「Rufus（ルーファス）によるインストールメディアの事前カスタマイズ」**の2つです。

ここでは、最も手軽な「コマンドプロンプト」を使用した方法を解説します。

### 【手順】OOBE（初期設定）をバイパスする方法

1. **セットアップを開始し、Wi-Fi（ネットワーク）接続画面まで進む。**
   ※ここでは絶対にWi-Fiに接続しないでください！
2. キーボードの **`Shift` + `F10`** を同時に押す。
   （ノートPCの場合は `Fn` + `Shift` + `F10` の場合があります）
3. 黒い画面（コマンドプロンプト）が起動したら、以下のコマンドを半角英数字で入力し、`Enter` を押します。
   ```text
   OOBE\BYPASSNRO
   ```
4. PCが自動的に再起動します。
5. 再び初期設定画面が進み、ネットワーク接続画面になると、前回は無かった**「インターネットに接続していません」**という選択肢が出現します。
6. これをクリックし、次の画面で**「制限された設定で続行」**を選択すれば、無事にローカルアカウント作成画面に進むことができます。

> **💡 プロのアドバイス：**
> 今後、Microsoftがこのコマンドすら対策する可能性があります。より確実にローカルアカウントでインストールしたい場合は、無料ツール「**Rufus**」を使って、Microsoftアカウント要求をあらかじめ無効化したUSBインストールメディアを作成しておく方法が最もおすすめです。

## 2. Windows 11 Home vs Pro「価格・性能・機能」比較

「毎回こんな裏技を使うのは面倒」「ビジネスでも使いたい」という方は、最初からローカルアカウント作成が容易な**「Windows 11 Pro」**の導入、またはアップグレードを検討すべきです。

HomeとProの価格と重要機能を比較しました。

| 機能・項目 | Windows 11 Home | Windows 11 Pro |
| :--- | :--- | :--- |
| **市場価格（リテール版）** | 約19,000円 | 約26,000円 |
| **初期設定時のローカルアカウント** | ❌ 原則不可（要裏技） | ⭕️ 標準で選択可能 |
| **BitLocker デバイス暗号化** | ❌（簡易版のみ） | ⭕️ フル機能（盗難時のデータ保護） |
| **リモート デスクトップ（ホスト機能）**| ❌（接続される側になれない） | ⭕️ 外部からPCを操作可能 |
| **Windows Sandbox / Hyper-V** | ❌（仮想環境の構築不可） | ⭕️ 仮想システムを安全に起動可能 |
| **最大メモリサポート** | 128 GB | 2 TB |

### どちらを選ぶべき？
* **Windows 11 Homeが向いている人：**
  とにかく予算を抑えたい、一般的なWebブラウジング、動画視聴、PCゲーム（シングルプレイ中心）がメインで、設定の裏技を調べるのが苦にならない人。
* **Windows 11 Proが向いている人：**
  ビジネスで使用する、リモートワークで自宅から会社のPC（またはその逆）を操作したい、大切なデータをBitLockerで暗号化して守りたい、ローカルアカウントでサクッと初期設定を終わらせたい人。
