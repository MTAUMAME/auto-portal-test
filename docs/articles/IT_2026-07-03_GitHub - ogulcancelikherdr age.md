# ターミナルがAIの司令塔に！複数エージェントを束ねる「herdr」とは？

*   **GitHubリポジトリ:** [ogulcancelik/herdr](https://github.com/ogulcancelik/herdr)

**herdr（ハーター）**は、ターミナル（CLI）上で動作する**AIエージェント・マルチプレクサー**です。
簡単に言えば、**「1つのプロンプトを、複数のAIエージェントに同時に投げ、並列処理させ、ターミナル上で結果を監視・制御できるツール」**です。ターミナル界の`tmux`や`screen`のAI版と考えるとイメージしやすいでしょう。

### 主な特徴：
1.  **ターミナル完結型:** 重いブラウザUIは不要。キーボード操作のみで完結。
2.  **マルチ・モデル対応:** OpenAI、Anthropic、Ollama（ローカル）、Groqなどをシームレスに連携。
3.  **並列エージェント実行:** 異なる役割（コード生成、デバッグ、ドキュメント作成など）を持つエージェントを同時に走らせ、結果をマージ可能。
