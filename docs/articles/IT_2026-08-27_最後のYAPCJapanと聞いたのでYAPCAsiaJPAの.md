## 1. YAPC::Asia / JPAと「私」の歴史：PerlからAIの時代へ

私が初めてYAPC::Asia（当時は東京工業大学や慶應義塾大学で開催）に参加したのは、まだPerlがWeb開発の主役であり、スマートフォンの普及期だった頃です。

```
【私のYAPC/JPAクロニクル】
・2010年代前半：YAPC::Asia Tokyoの圧倒的熱量に圧倒される。
　（牧大介さんをはじめとするJPAメンバーの超人的な運営力に感謝）
・LT（ライトニングトーク）の「銅鑼（ドラ）」の音にハラハラする文化。
・「Perl Mongers」たちの、技術に対する泥臭くも愛のあるアプローチ。
・その後、JPA（一般社団法人JAPAN Perl Association）体制となり、
　全国（福岡、京都、仙台、広島など）へ「YAPC::Japan」としてバトンが渡される。
```

当時は、MacBookを膝に載せ、IRCやTwitter（現X）の実況ハッシュタグを追いかけながら、必死にタイピングしてブログ記事（カンファレンスレポート）を書いていました。

しかし、時は流れ**「令和のAI時代」**。
もし、あの過酷かつエキサイティングなYAPCの現場に、**「ChatGPT」や「最新AIボイスレコーダー」**があったなら、どれほど豊かなインプットができたでしょうか？
