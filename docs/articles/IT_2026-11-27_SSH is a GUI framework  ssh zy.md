## 1. そもそも「SSH is a GUI framework | ssh zydra.sh」とは？

ターミナルを開き、以下のコマンドを打ち込むだけで体験できます。（※安全な環境でお試しください）

```bash
ssh zydra.sh
```

これを実行すると、ブラウザもローカルアプリも立ち上げていないのに、**ターミナルの中にリッチなインタラクティブ画面（ダッシュボードやUI）**が表示されます。

### なぜこれが革命的なのか？
* **ローカルインストール不要:** SSH接続ができる環境（Mac, Linux, Windows, iPhone, Raspberry Piなど）なら、一切の依存関係なしで即座にアプリが動く。
* **ANSI escape codeの進化:** ターミナルにカラーテキストだけでなく、マウス操作、ウィンドウ分割、アニメーションを描画する技術（Charm.shなどのGo言語ライブラリ）が進化。
* **「ブラウザ（Electron）重すぎ問題」の解決:** SlackやVSCodeなど、現在のアプリはメモリを数GB消費しますが、SSH GUIなら**数MBのメモリ**で爆速動作します。
