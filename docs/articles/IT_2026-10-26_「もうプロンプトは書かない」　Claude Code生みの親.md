## 1. 「ループエンジニアリング」とは？なぜプロンプトを書かなくていいのか

これまで：**プロンプトエンジニアリング**
> 人間が完璧な指示を書き、AIが1回で完璧なコード（回答）を返そうとする「一発勝負」の構造。

これから：**ループエンジニアリング**
> AIに**「目的」と「ツール（ターミナル、Git、検索など）」**を与え、AI自身が「実行 → エラー確認 → 修正」の思考ループを自立的に回す構造。

### Claude Codeが異次元な理由
Claude Code（内部モデル：Claude 3.7 Sonnet）は、単にコードを生成するだけではありません。

1. **自らコマンドを実行**（ファイル生成、テスト実行、Git操作）
2. **エラーが出たら自力でログを解析**してコードを再修正
3. **完成するまで自律的に思考ループを回し続ける**

つまり人間は「ログイン機能を実装して、テストを通しといて」とだけ言えば、AIが勝手に試行錯誤して完成させてくれるのです。人間は「指示者」から**「承認者（ループの見張り番）」**へとシフトします。

## 2. 競合AIツールとの「性能・価格」徹底比較

開発者向けAIツールの中で、Claude Codeの位置づけを主要ライバルと比較しました。

| ツール名 | **Claude Code** | **Cursor** | **GitHub Copilot** | **ChatGPT (o3-mini/o1)** |
| :--- | :--- | :--- | :--- | :--- |
| **提供元** | Anthropic | Anysphere | Microsoft/GitHub | OpenAI |
| **主な形態** | ターミナル (CLI) | エディタ (VS Code分岐) | IDE拡張機能 | Web / API |
| **主要モデル** | **Claude 3.7 Sonnet** | Claude 3.7 / GPT-4o | OpenAIモデル中心 | o1 / o3-mini / GPT-4o |
| **開発スタイル** | **完全放置型ループ** | 対話型エディタ補完 | 行単位・関数補完 | チャットベース |
| **価格** | API従量課金 / Pro（月$20〜） | 月$20 (Pro) | 月$10 (Individual) | 月$20 (Plus) |
| **自律デバッグ** | **最強（CLIで直接実行）** | 中（ターミナル連携） | 弱（手動コピー多） | 弱（環境アクセス不可） |

### 比較からわかる結論
* **「全自動でコードベース全体を書き換えてテストまでさせたい」** ➔ **Claude Code** 一択
* **「エディタ上で画面を見ながら綺麗にコーディングしたい」** ➔ **Cursor**
* **「とにかく安く、入力補助として使いたい」** ➔ **GitHub Copilot**

## 3. サクラ排除！実際に使い倒したエンジニアのリアルな口コミ

X（旧Twitter）やGitHubコミュニティ、海外Redditから、**広告・案件を除外した生の声**をピックアップして分析しました。

### 📌 良い口コミ（メリット）
> **「テストが通るまで寝て待てる」**
> 今まではエラーが出るたびにログをコピーしてChatGPTに貼っていたが、Claude Codeは自前で`npm test`を叩いてエラー原因を特定し、直すまでループしてくれる。作業効率が5倍になった。（30代・Webエンジニア）

> **「巨大なレガシーコードの解読が爆速」**
> ドキュメントのない古いコードベースを読ませて「このバグ直して」と言ったら、関連ファイルを片っ端から検索して自動修正PRまで作ってくれた。感動。（40代・SRE）

### ⚠️ 悪い口コミ（デメリット・注意点）
> **「気を抜くとAPI代が爆発する」**
> ループ処理（思考＋ツール利用）が回るため、トークン消費量が半端ない。1つのバグ修正で$10（約1,500円）飛んだことがある。設定で上限を設けるか、Claude Pro枠で賢く使う必要あり。（20代・個人開発者）

> **「黒い画面（ターミナル）アレルギーにはきつい」**
> CUIでの操作が基本なので、GUIエディタしか使ったことがない非エンジニアにはハードルが高い。（非エンジニア・マーケター）
