## 1. そもそも「🔁 ループエンジニアリング」とは？

Qiitaで話題沸騰中の「ループエンジニアリング」とは、一言で言えば**「AIに自己反省（Self-Reflection）と自己修正の『ループ（循環）』を自動で行わせる技術」**です。

従来のプロンプトエンジニアリングは「1問1答（シングルターン）」でした。これに対し、ループエンジニアリングでは以下のようなサイクルを自動で回します。

```
[指示（Input）] 
       ↓
[生成（Generation）] ────→ [評価・テスト（Evaluation）]
       ↑                            │
       └──── [修正（Refinement）] ←──┘ (NGの場合)
```

1. **生成（Generate）：** AIが成果物（コードや文章）を作る。
2. **評価（Critique/Test）：** 別のAI（またはテストコード）が、その成果物のエラーや不十分な点を検証する。
3. **修正（Refine）：** 指摘されたエラーを元に、元のAIが修正する。
4. **完成：** エラーがゼロになる、または目標基準に達するまで自動でループを繰り返す。

### なぜ今これが重要なのか？
これにより、人間の手を介さずに**「バグのないコード」「整合性の取れた長文」「精度の高いリサーチレポート」**が自動で完成します。AIエージェント（DevinやCursorなど）の裏側で動いている超重要コンセプトです。
