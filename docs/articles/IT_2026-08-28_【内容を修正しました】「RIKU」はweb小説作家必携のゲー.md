## 1. 導入：Web小説界に激震！KADOKAWAの「RIKU」とは？

現在、Web小説家やライトノベル作家の間で「創作の常識が変わる」と噂されているAIサービスがあります。それが、出版大手KADOKAWAが開発を進める創作支援AI**「RIKU（リク）」**です。

## 2. そもそも「RIKU」で何ができる？主要機能まとめ

RIKUは、単に「文章を自動生成する」だけのAIではありません。作家の「伴走者（バディ）」として機能するよう設計されています。

*   **プロット・構成の自動生成・提案**：
    アイデアの種を入力するだけで、起承転結や「Web小説でウケる黄金パターン」に沿ったプロットを提案。
*   **キャラクター・世界観設定の構築アシスト**：
    キャラクターの属性、ツンデレ度、外見などを入力すると、魅力的なキャラクターシートを自動作成。
*   **「書きあぐね」の解消（執筆アシスト）**：
    「ここでどんでん返しを起こしたいが、どうすればいい？」といった作家の具体的な悩みに、KADOKAWAの編集ノウハウを学習した（※推測）アルゴリズムが答えます。
*   **カクヨム等の投稿サイトとの親和性**：
    KADOKAWAグループならではの、Web小説のトレンド（追放もの、悪役令嬢、異世界転生など）を掴んだ出力が得意。
