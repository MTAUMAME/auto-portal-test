## 「adms」とは？ 3つの革新的ポイント

「adms」は、Go言語で開発されたオープンソースのデータベース管理・API自動生成ツールです。その最大の特徴は**「圧倒的な手軽さ」**にあります。

1. **DBに接続するだけで準備完了**
   既存のPostgreSQL、MySQL、SQLiteなどの接続情報を環境変数に渡して起動するだけで、データベースのスキーマを自動解析します。
2. **REST API（CRUD）を自動生成**
   データの取得（Get）、作成（Post）、更新（Put）、削除（Delete）を行うためのAPIエンドポイントが瞬時に生えてきます。
3. **美しい管理UIが標準搭載**
   React/Vue等で自分で画面を作らなくても、ブラウザからデータをポチポチ操作できるモダンなAdmin UIが最初から使えます。しかも、**単一の実行バイナリ（Go製）なので、インストール不要・依存関係なし**で動きます。

## 競合ツールとの価格・性能比較

「adms」のような、DBからAPIやUIを自動生成するツールはいくつか存在します。有名どころである「PocketBase」「Hasura」「NocoDB」と比較してみました。

| 項目 | **adms** | **PocketBase** | **Hasura** | **NocoDB** |
| :--- | :--- | :--- | :--- | :--- |
| **開発言語** | **Go (Golang)** | Go (Golang) | Haskell | Node.js (TypeScript) |
| **動作環境** | **単一バイナリ (超軽量)** | 単一バイナリ | Docker推奨 | Docker / Node.js |
| **対応DB** | **PostgreSQL, MySQL, SQLite** | SQLiteのみ | PostgreSQL, MySQL, SQL Server等 | PostgreSQL, MySQL, SQLite等 |
| **生成されるAPI** | **REST API** | REST API | **GraphQL** / REST | REST / GraphQL |
| **管理UIの使いやすさ** | ★★★★☆ (シンプル・高速) | ★★★★★ (美麗・多機能) | ★★★☆☆ (開発者向け) | ★★★★★ (スプレッドシート風) |
| **メモリ使用量** | **極小 (約15MB〜)** | 極小 (約15MB〜) | 中〜大 (Docker必須) | 大 |
| **価格** | **無料 (OSS)** | 無料 (OSS) | 無料枠あり (Cloudは有料) | 無料 (OSS) |

### 比較のポイント
* **SQLite縛りなら** ── 認証機能なども最初から入っている **PocketBase** が強力。
* **既存の本格的なDB（Postgre/MySQL）があるなら** ── Docker不要で一瞬で立ち上がる **adms** が圧倒的に手軽。
* **エンタープライズ・GraphQLなら** ── **Hasura** が有利ですが、学習コストとメモリ消費が重いのがネック。
