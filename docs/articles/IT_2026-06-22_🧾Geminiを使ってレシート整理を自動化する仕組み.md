## 1. Geminiを使ったレシート自動整理の「仕組み」

まずは、どうやって自動化するのか、その全体像を解説します。プログラミングの専門知識がなくても、**Google Apps Script (GAS)** と **Gemini API** を組み合わせることで、以下のような自動化ラインが無料で構築できます。

```
[スマホで撮影] 
      ↓
[Google Driveの専用フォルダに保存] 
      ↓ （GASが検知してGemini APIへ送信）
[Geminiが画像を解析・テキスト構造化] 
      ↓
[Googleスプレッドシートに自動書き出し]
```

### なぜGeminiなのか？（従来のOCRとの違い）
従来のOCRは「文字の形」を読み取るだけでした。そのため、レシートのレイアウトが変わると、どれが「合計金額」でどれが「日付」なのか判断できませんでした。

Gemini（特にマルチモーダル対応の `Gemini 1.5 Flash / Pro`）は、**画像全体の文脈を理解**します。
「これは領収書だから、この数字が税込合計金額だな」「この『マクドナルド』は店舗名だな」とAIが思考してデータを抽出するため、認識精度が桁違いに高いのです。

## 2. 徹底比較：Gemini自作 vs 既存のレシート管理サービス

「自分でGeminiを使ってシステムを作る」のと、「マネーフォワードなどの既存サービスを使う」のでは、どちらがお得で便利なのでしょうか？ 性能とコストを比較しました。

| 比較項目 | **Gemini × GAS（自作）** | **マネーフォワード クラウド** | **ScanSnap連携（クラウド保存）** |
| :--- | :--- | :--- | :--- |
| **初期費用** | **0円** | 0円（プランによる） | 約35,000円〜（スキャナー代） |
| **月額コスト** | **ほぼ無料**（API無料枠内） | 約1,000円〜3,000円 | 0円（本体代のみ） |
| **読み取り精度** | 🌟 **極めて高い**（手書き・折れもOK） | ◯（標準的） | ◯（解像度は高いがAI判断は劣る） |
| **カスタマイズ性** | 🌟 **無限大**（出力項目を自由に設定） | △（規定フォーマットのみ） | △（連携アプリに依存） |
| **導入ハードル** | 中（GASのコピペ作業が必要） | 低（アプリを入れるだけ） | 低（ハードウェアの初期設定のみ） |

### 結論：どっちを選ぶべき？
- **コストを極限まで抑え、自分好みにカスタマイズしたい人** ⇒ **Gemini × GAS自作** が最強。
- **設定が面倒で、今すぐスマホアプリだけで完結させたい人** ⇒ **マネーフォワード等** の既存サービス。
- **毎月大量（数百枚〜）のレシートを裁く必要がある人** ⇒ **ScanSnap（スキャナー） ＋ Gemini** の合わせ技。
