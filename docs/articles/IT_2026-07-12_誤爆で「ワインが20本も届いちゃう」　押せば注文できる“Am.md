## 1. Amazon Dash Buttonとは何だったのか？

まずは当時のスペックや、なぜこれほどまでに話題になったのかを整理します。

| 項目 | 詳細 |
| :--- | :--- |
| **発売時期** | 2015年（米国）、2016年（日本） |
| **サービス終了** | 2019年（新規販売終了、のちに機能も完全停止） |

| **通信方式** | Wi-Fi（2.4GHz） |
| **バッテリー** | 内蔵（電池交換不可、数千回プッシュ可能） |
| **仕組み** | 割り当てられた特定の商品（水、洗剤、おむつ、ペットフード等）を1プッシュで注文 |

### なぜ「ワイン20本誤爆」が起きたのか？
ダッシュボタンは、スマホを開く手間を省くために「確認画面なしで注文が完了する」のが最大の売りでした。一応「重複注文防止機能（商品が届くまで次の注文を受け付けない）」はあったものの、以下のような盲点がありました。

*   **子どもやペットのいたずら：** おもちゃと勘違いして連打。
*   **通知のタイムラグ：** スマホへの注文完了通知に気づかず、家族がそれぞれボタンを押してしまった。
*   **設定のミス：** 「1パック」のつもりが「1ケース（複数個入り）」を登録しており、それが複数回押されて大量配送。

結果、ネット上では「洗剤が山積みになった」「高級ワインが数十本届いて青ざめた」といった悲喜こもごものレビューが溢れました。
