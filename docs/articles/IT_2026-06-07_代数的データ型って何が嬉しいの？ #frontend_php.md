## 1. そもそも「代数的データ型（ADT）」って何？何が嬉しいの？

代数的データ型を極限までシンプルに説明すると、**「いくつかの決まったパターンの値だけを許容する、厳格な型システム」**のことです。

代表的なのは以下の2つです。

1. **和型（Union Types / Sum Types）**：「A または B または C のいずれか」を表す型。
2. **積型（Product Types）**：「A と B の組み合わせ」を表す型（一般的な構造体やオブジェクト）。

### ▼ 何がそんなに嬉しいの？（3つのメリット）

* **① 不正な状態（バグ）をコードレベルで「表現不可能」にする**
  「ローディング中なのにデータが存在する」といった、あり得ない状態を型定義の段階で排除できます。
* **② エディタの補完（インテリセンス）が神がかる**
  条件分岐（`switch`や`if`）で「すべてのパターンを網羅しているか」をコンパイラや静的解析ツールが自動でチェックしてくれます。
* **③ AI（GitHub Copilot / Cursor）の出力精度が跳ね上がる**
  **ここが最新AIブログとしての最重要ポイント！**
  型定義が厳密（ADT）であればあるほど、AIコーディングアシスタントは「文脈」を完璧に理解し、バグのない正確なコードを一瞬で生成してくれます。
