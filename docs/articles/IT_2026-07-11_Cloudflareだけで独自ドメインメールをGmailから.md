## そもそも「Cloudflareでメール送受信」とはどういう仕組み？

これまでも「Cloudflare Email Routing（無料）」を使えば、独自ドメイン宛てのメールをGmailに「転送（受信）」することは簡単にできました。

しかし、**「Gmailから独自ドメイン名義で『送信』する」**には、別途SMTPサーバーを用意する必要があり、これが初心者には高いハードルでした。

現在では、**Cloudflareの高度なDNS設定（SPF/DKIM/DMARC対応）**と**Gmailの「送信元アドレスの追加（アプリパスワード使用）」**を組み合わせることで、**完全無料・ノーコード・配信エラーなし**で双方向の送受信が可能になっています。

### この構成のメリット
1. **完全無料**（ドメイン維持費のみ）
2. **Gmailの最強スパムフィルタ**をそのまま使える
3. **SPF / DKIM / DMARCに完全対応**（受信マークやなりすまし防止もバッチリ）
4. サーバーの管理が不要（落ちる心配がない）

## 【実践】Cloudflare×Gmailで独自ドメインメールを作る3ステップ

設定は驚くほど簡単です。以下の3ステップで完了します。

### ステップ1：お名前.comやNamecheapでドメインを取得する
まずはあなたの「独自ドメイン」が必要です。ドメインの管理（DNS）をCloudflareに移転させるため、どこで取得してもOKですが、管理画面が使いやすくドメイン代が最安クラスのサービスがおすすめです。

> 📌 **おすすめのドメイン取得サービス：**
> * 国内最大手で安心：[お名前.com（アフィリエイトリンク）]
> * 圧倒的な安さとシンプルさ：[お名前.com / ムームードメイン等（アフィリエイトリンク）]

### ステップ2：Cloudflareにドメインを登録し「Email Routing」を有効化
1. Cloudflare（無料アカウント）にドメインを登録。
2. 左メニューの「Email」＞「Email Routing」を選択。
3. 受信したいアドレス（例：`info@yourdomain.com`）と、転送先の「Gmailアドレス」を入力。
4. 自動生成されるDNSレコードを「DNS」設定にワンクリックで追加。

### ステップ3：Gmail側で「送信元」として設定する
1. Googleアカウントの「セキュリティ」から「2段階認証」を有効にし、「アプリパスワード」を生成（名前は「Cloudflare Email」等）。
2. Gmailの「設定（歯車マーク）」＞「アカウントとインポート」＞「他のメールアドレスを追加」をクリック。
3. 追加したい独自ドメインメールを入力。
4. **SMTPサーバー設定:**
   * SMTPサーバー：`smtp.gmail.com`
   * ポート：`587`（TLS）
   * ユーザー名：**あなたのGmailアドレス**（独自ドメインではありません）
   * パスワード：手順1で生成した**「アプリパスワード（16桁）」**
5. Gmailに届く認証メールのコードを入力して完了！
