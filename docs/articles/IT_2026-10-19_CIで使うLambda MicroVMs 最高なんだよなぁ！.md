## なぜ「Lambda MicroVMs」× CIが最強なのか？

MicroVM（代表例：AWSが開発するオープンソースの**Firecracker**）は、**「コンテナ並みの起動速度」**と**「従来の仮想マシン（VM）並みの強いセキュリティ隔離」**を両立した技術です。

これをCI（GitHub ActionsのSelf-hosted runnerなど）に組み込むと、以下のメリットが生まれます。

1. **起動が秒速（数十ミリ秒）：** 待ち時間がほぼゼロでCIが走り出す。
2. **完全使い捨て（Ephemeral）：** 1実行ごとにVMが破棄されるため、環境汚染やセキュリティリスクが皆無。
3. **ミリ秒単位の従量課金：** 使った分しかお金がかからない。放置されたサーバー代ゼロ。
4. **圧倒的並列性能：** 100個のテストを同時に走らせても一瞬でLambdaが立ち上がる。

## 【徹底比較】価格と性能、どれくらい違う？

一般的な「GitHub Actions（標準ランナー）」、「EC2による常駐型セルフホスト」、そして「Lambda MicroVM」を比較してみました。

### 1. 性能・スペック比較

| 項目 | GitHub Actions (標準) | EC2 (常駐型セルフホスト) | **Lambda MicroVM (Firecracker等)** |
| :--- | :--- | :--- | :--- |
| **起動速度** | 普通（10秒〜1分） | 遅い（新規起動の場合） | **爆速（数十〜数百ミリ秒）** |
| **セキュリティ** | 高（Microsoft管理） | 中（環境汚染のリスクあり） | **最高（完全独立MicroVM）** |
| **並列処理能力** | 契約プランの制限あり | サーバー台数に依存 | **ほぼ無限（AWS上限まで）** |
| **環境のリセット** | 実行ごと（遅い） | 手動/スクリプト管理が必要 | **実行ごと（自動＆爆速）** |

### 2. コスト比較（月間10,000分 ビルドした場合の目安）

* **GitHub Actions Standard:** 約 **$80/月**（2コアLinux）
* **EC2（t4g.medium 常駐）:** 約 **$25/月**（使っていなくても24時間課金）
* **Lambda MicroVMs:** 約 **$5〜$12/月**（実行した秒数分のみ！圧倒的コスパ）

> **💡ポイント:**
> CIは「24時間ずっと走っているわけではない」ため、従量課金のLambda MicroVMと相性が抜群に良いのです。
