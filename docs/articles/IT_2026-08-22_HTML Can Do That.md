## 1. 「HTML Can Do That」とは？

**「HTML Can Do That（HTMLにそんなことができるのか）」**は、かつてはJavaScript（jQueryやReactなど）が必須だったアコーディオン、モーダルウィンドウ、ポップオーバー、ダークモード切り替えなどのインタラクティブな機能を、**「純粋なHTML（およびCSS）」だけで実装するコード例を集めたサイト**です。

### 主な特徴
*   **JS完全不要：** サイトの軽量化、セキュリティ向上、SEO向上に直結。
*   **セマンティックなHTML：** `<dialog>` や `<details>`、最新の `popover` 属性などを駆使。
*   **コピペで動作：** 複雑なビルド環境（Node.jsなど）がなくても、エディタに貼るだけで即動く。

## 2. 【性能・コスト比較】HTML単体 vs 他手法

「HTML Can Do That」が提案する「ピュアHTML/CSS」のアプローチと、従来の「JavaScript（React/Vue）」、および「ノーコードツール（Wix/STUDIO）」を比較しました。

| 比較項目 | ピュアHTML (HTML Can Do That) | JSフレームワーク (React/Next.js) | ノーコードツール (Wix/STUDIO) |
| :--- | :--- | :--- | :--- |
| **初期費用 / 月額** | **完全無料**（オープンソース） | 無料（ホスティング代のみ） | 月額 1,000円〜1万円程度 |
| **表示速度（LCP）** | **超高速（最速クラス）** | 低速〜中速（JSの読み込みが発生） | 中速〜低速（不要なコードが多い） |
| **学習コスト** | **極めて低い**（HTML/CSSのみ） | 高い（JS/TS、ビルドツール必須） | 低い（GUI操作） |
| **SEO・クローラ最適化**| **最強**（クローラが即座に理解） | 対策が必要（SSR/SSG必須） | 対策限界あり |
| **高度な状態管理** | 苦手（データベース連携などは不可） | **得意** | 中程度 |
| **開発スピード（AI併用時）**| **爆速**（AIへのプロンプトがシンプルに）| 中速（環境構築に時間がかかる） | 高速（ただし自由度が低い） |

**【結論】**
個人ブログ、アフィリエイトサイト、コーポレートサイトの静的ページなら、**「HTML Can Do That」のアプローチ（ピュアHTML）が、速度・コスト・SEOの面で圧倒的に最強**です。
