## 1. 「Jev（ジェブ）」とは何か？ 概要をサクッと理解する

「Jev」とは、一言で言えば**「自律的な問題解決と自己修正に特化した、超次世代型のAIエージェント・アーキテクチャ（またはフレームワーク）」**です。

従来の「質問に答えてくれるAI」から一歩進み、**「目標（ゴール）を1つ与えれば、PC操作、プログラミング、エラー解決までをすべて自律的に完遂する」**という特徴を持っています。

### Jevの3大特徴
1. **自己修正（Self-Correction）能力の高さ**：プログラムを実行してエラーが出た際、人間に聞くのではなく、エラーログを自ら解析してコードを書き直します。
2. **動的なツール利用**：Web検索、API連携、ローカル環境でのファイル操作などを、状況に応じてAI自身が「判断」して使い分けます。
3. **超効率的なトークン管理**：従来のAIエージェント（AutoGPTなど）で問題だった「無限ループによるAPI費用の爆死」を防ぐ、独自のコンテキスト制御を搭載しています。

## 2. 従来型LLMやAIエージェントとの「決定的な違い」

JevがこれまでのAIとどう違うのか、3つのステップで比較してみましょう。

```
【従来型LLM（ChatGPT等）】
「人間が1ステップずつ指示を出す」 ➔ 「AIが答える」の繰り返し

【一般的なAIエージェント（AutoGPT等）】
「ゴールを指示」 ➔ 「AIが自律動作」 ➔ 「エラーで無限ループ（API代高騰）」

【Jev（次世代エージェント）】
「ゴールを指示」 ➔ 「環境を認識・自律動作」 ➔ 「エラー検知」 ➔ 「自律修正・完遂」
```

### ① 従来型LLM（ChatGPT, Claude 3.5 Sonnet 単体など）との違い
従来型LLMは「指示待ち」です。高度な文章作成やコード生成は得意ですが、実行環境を持たないため、「動くコードを実際にテストして、バグを取り除く」という作業は人間がやる必要がありました。Jevは、この**「テスト ➔ バグ修正」のサイクルを全自動で行います。**

### ② 一般的なAIエージェント（AutoGPT, BabyAGIなど）との違い
初期のAIエージェントは「指示を自動化する」思想でしたが、予測不能なエラーが起きると、同じ行動を繰り返す「無限ループ」に陥りやすい欠点がありました。Jevは**「環境適応型フィードバックループ」**を搭載しており、アプローチが失敗したと判断すると、瞬時に別ルート（別の検索ワード、別のライブラリなど）へ切り替える柔軟性を持っています。

## 4. Jevの価格・プラン比較

Jevの導入コストは、利用形態によって異なります。個人開発者から企業導入まで、いくつかの選択肢があります。

*   **コミュニティ版（オープンソース/セルフホスト）**
    *   **価格**：無料（本体のみ）
    *   **別途コスト**：OpenAIやAnthropic、DeepSeekなどのAPI利用料（従量課金）
    *   **特徴**：自分のPC（Docker等）やクラウドに構築。APIを叩いた分だけ支払うため、節約設定が可能。
*   **Jev Cloud（マネージドプラン・想定）**
    *   **価格**：月額 約$20〜$50（プロプラン）
    *   **特徴**：環境構築が不要。ブラウザ上で動作し、一定のトークン利用枠がコミコミになっているため初心者向け。
