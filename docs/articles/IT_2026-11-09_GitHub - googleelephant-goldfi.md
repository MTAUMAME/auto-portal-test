## 1. 「elephant-goldfish-model」とは？

Googleが公開した`google/elephant-goldfish-model`は、単なるコード生成AIではありません。**ソフトウェアの「設計（Design）」と「レビュー（Review）」に特化したAIエージェント構築用のオープンソースフレームワーク/プロンプトスキル集**です。

### 名前の由来と仕組み：象と金魚

*   **Elephant（象 = 長期記憶・大局的視野）：**
    システム全体のアーキテクチャ設計、長期的な技術スタックの選定、モジュール間の整合性を担当。「象のように忘れない」深い文脈理解を提供します。
*   **Goldfish（金魚 = 短期集中・高速処理）：**
    個別のPR（プルリクエスト）チェック、特定関数のリファクタリング、短期的なバグ発見を担当。「金魚のように素早く」特定のコードブロックに集中します。

この2つの概念を組み合わせることで、**「全体設計をブレさせずに、細部のコードレビューを超高速で行う」**という、ベテランエンジニアのような動きをAIエージェントに実現させています。
