## 1. 実践：Claude Code（Fable 5）に「ローカルLLM用シェル支援CLI」を作らせてみた

今回のお題は**「ターミナルでエラーが出た際、ローカルのOllama（Llama 3等）にそのエラー内容を自動でパイプし、即座に解決策を提示してくれるCLIツール」**の開発です。

ターミナルから `claude` コマンドを起動し、一行**「ローカルのOllamaを使って、直前のコマンドエラーを解析・修正提案するRust製（またはNode.js製）のCLIツールを作って」**とだけ指示しました。

そこからのClaude Code（Fable 5搭載）の動きが、従来のAIとは一線を画していました。

### 驚愕の「仕事の進め方」3つのポイント

#### ① 勝手にローカル環境を調査し始める（自律性）
普通、従来のAIなら「Rustで書くならCargo.tomlはこうです」とコードを吐き出して終わりです。しかしClaude Codeは違いました。
> `[Claude]` 「まず、あなたのシステム環境を確認します。Ollamaが起動しているか、どのポートでリッスンしているかを確認するため、バックグラウンドで接続テストを行いますね」

私に許可を求めた上で、勝手に `curl http://localhost:11434/api/tags` を実行し、すでにローカルに入っているモデル（Llama 3, Mistralなど）の一覧を自動取得。最適なモデルを自分で選択しました。

#### ② エラーが起きても、自分でログを見て勝手にデバッグする（自己修復）
ビルド時にライブラリのバージョン競合によるコンパイルエラーが発生しました。私はただ画面を眺めていただけですが、Claude Codeはこう動きました。
> `[Claude]` 「おっと、`tokio` のバージョン互換性でエラーが出ました。Cargo.tomlを修正して、もう一度ビルドを試みます」

エラーログを自ら解析し、コードを書き換え、再テスト。**人間が「エラーが出たよ」とコピペして教える手間が「ゼロ」**なのです。

#### ③ 開発プロセスが完全に「優秀なシニアエンジニア」
仕様の曖昧な部分（例：「エラー出力をどう検知するか？」）に対して、「A：シェルのヒストリーから取得する」「B：ラッパーコマンドとして実行する」という2つのアプローチのメリット・デメリットを提示し、私に決断を仰いできました。

**「AIに指示を与えている」のではなく、「超優秀なエンジニアとペアプログラミングをしている」感覚**。これがFable 5世代のAIエージェントの真恐さです。

## 2. 徹底比較：Claude Code vs 競合AIツール

開発系AIの3大巨頭である「GitHub Copilot Workspace」「Cursor（Composer）」「Claude Code」の価格と性能を比較しました。

| 項目 | Claude Code (Fable 5) | Cursor (Composer) | GitHub Copilot Workspace |
| :--- | :--- | :--- | :--- |
| **提供形態** | ターミナル（CLIツール） | 専用IDE（VS Codeフォーク） | GitHub連携（Web/IDE） |
| **主なエンジン** | Claude 3.5 Sonnet / Fable 5 | GPT-4o / Claude 3.5 | GPT-4o / Gemini 1.5 Pro |
| **自律デバッグ能力** | ★★★★★ (異次元。コマンド自走) | ★★★★☆ (エディタ内完結) | ★★★★☆ (PR作成ベース) |
| **環境構築・調査** | ★★★★★ (ローカル環境を検知) | ★★☆☆☆ (プロジェクト内のみ) | ★★★☆☆ (クラウド環境依存) |
| **料金プラン** | **従量課金制 (API Token)**<br>※使った分だけ（1000トークン単位） | **月額 $20** (プレミアム枠あり)<br>※使い放題に近い | **月額 $10 / $19**<br>※定額制 |
| **コスパ** | 開発規模による（短期集中なら安価） | 個人開発者には最強の安定感 | 企業導入実績No.1 |

### コストに関するリアルな視点
Claude Codeは**API利用料（従量課金）**となるため、大規模なプロジェクトで丸一日自律デバッグを走らせると、**1日で$5〜$10程度**消費することもあります。しかし、月額定額のCursorで詰まるような複雑なタスクを、一瞬で自律解決してくれるタイパ（タイムパフォーマンス）を考えれば、むしろ激安と言えます。
