## 1. `jinba-consulting-pptx-skill` とは？

`jinba-consulting-pptx-skill`は、Anthropicが提供するCLIツール「Claude Code」や「Codex（Cursor等）」に対して、**「一流戦略コンサルタントのスライド作成ノウハウ」をインストールするためのプロンプト＆スキル定義集**です。

### 主な特徴
- **コンサルクオリティのロジックとデザイン**: 情報の優先順位付け、配色ルール、レイアウトの美しさが最初から計算されています。
- **完全編集可能な.pptx出力**: 画像データではなく、Microsoft PowerPointで直接テキストや図形を打ち替えられる`.pptx`ファイルとして出力されます。
- **Claude Code / Cursor等で即座に動作**: 開発者が普段使っているCLIやエディタ上で、指示を与えるだけでスライドが完成します。

### 〇 良い口コミ（メリット）
> **「AIスライド特有の『安っぽさ』がない」**（30代・ITコンサル）  
> 従来のAIツールは「ネオンカラーの謎イラスト」が入りがちだったが、これは白地ベースにアクセントカラー1色の「本当の提案書」が出てくる。手直しが圧倒的にラク。

> **「PowerPointで図形として触れるのが神」**（20代・Webディレクター）  
> 画像化されずに、ちゃんとPowerPointのオブジェクトとして書き出される。フォントサイズや微調整が普段のパワポ感覚でできるのが最高。

> **「API代が安すぎる」**（40代・フリーランス）  
> 月額3,000円のAIツールを解約した。Claude APIの従量課金なら1スライドセット作成しても数十円程度。

### ✕ 悪い口コミ・注意点（デメリット）
> **「黒い画面（CLI）に慣れてないと厳しい」**（30代・マーケター）  
> Claude CodeやCursorを触ったことがない非エンジニアにはハードルが高い。ワンクリックで動くWeb画面（GUI）が欲しい。
