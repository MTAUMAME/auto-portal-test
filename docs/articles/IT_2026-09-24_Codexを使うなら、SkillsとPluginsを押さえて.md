## 1. そもそも「Skills」と「Plugins」って何が違うの？

AIツール（特にCursor、Dify、Coze、ChatGPTなど）を触っていると、よくこの2つの言葉が出てきます。一言で言うと、**「AIの戦闘力を上げるアプローチ」**の違いです。

```
💡 ざっくり言うと…
・Skills（スキル）   ＝ AIの「頭脳・役割（プロンプト・思考プロセス）」の強化
・Plugins（プラグイン）＝ AIの「道具（外部ツール・API連携）」の拡張
```

| 項目 | Skills（スキル） | Plugins（プラグイン） |
| :--- | :--- | :--- |
| **役割** | AIに特定の役割（「Pythonのシニアエンジニア」など）や、一連の処理手順（ワークフロー）を教え込むこと。 | 外部のサービス（Web検索、Googleスプレッドシート、GitHub、API等）と接続させること。 |
| **具体例** | 「エラーコードを入力したら、即座に修正案と解説を出力する」という指示（プロンプト）の固定。 | 「現在の最新の株価情報を取得してグラフ化する」「指定のSlackチャンネルに通知を送る」。 |
| **学習難易度** | 低〜中（日本語のプロンプト作成がメイン） | 中〜高（APIキーの設定や、JSONなどのデータ連携の知識が必要） |

この2つを組み合わせることで、**「おうちにいながら、自分だけの最強のAIアシスタント（プログラマ）」**を作り出すことができるようになります。
