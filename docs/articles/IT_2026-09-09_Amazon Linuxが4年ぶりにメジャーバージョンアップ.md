## そもそも「Amazon Linux 2027」とは？何が変わった？

Amazon Linux 2027は、AWS上での実行に最適化されたLinuxオペレーティングシステムです。

### 💡 3つの重要な変更点
1. **4年ぶりのメジャー刷新**：従来のAL2（Amazon Linux 2）やAL2023から、さらにモダンなFedoraをベースに最適化。
2. **SELinuxが「デフォルトで強制（Enforcing）」に**：これまでは「許容（Permissive）」や「無効化」が主流でしたが、セキュリティファーストへ舵を切りました。
3. **最新AI・機械学習チップ（AWS Trainium/Inferentia）への最適化**：AIモデルの推論・学習スピードが大幅に向上しています。

## 【スペック比較】Amazon Linux 2 vs 2023 vs 2027

旧バージョン（AL2）、現行（AL2023）、そして最新の「AL2027（プレビュー）」を比較してみましょう。

| 項目 | Amazon Linux 2 (旧) | Amazon Linux 2023 (現行) | Amazon Linux 2027 (最新) |
| :--- | :--- | :--- | :--- |
| **ベースOS** | RHEL 7ベース | Fedoraベース | 最新Fedoraベース |
| **カーネルバージョン** | 5.10 / 5.15 | 6.1 | **6.12+ (予定)** |
| **SELinux** | デフォルト無効 | 許容 (Permissive) | **強制 (Enforcing) ※デフォルト** |
| **起動速度** | 普通 | 高速 | **極速（最小パッケージ化）** |
| **Graviton (ARM) 最適化** | 部分的 | 最適化済 | **次世代Graviton4に完全最適化** |
| **サポート期間** | 2025年6月終了予定 | 2028年まで | **リリースから5年間** |

### 💰 コスト（価格）はどう変わる？
* **OS利用料自体は「無料」**です（AWSのEC2インスタンス料金のみ）。
* **隠れたコストカット効果**：AL2027はOSの起動速度がさらに向上し、パッケージが軽量化されているため、**EC2の起動時間（課金時間）の削減**や、より低いスペック（安価なインスタンス）での動作が可能になり、実質的なインフラコスト削減に繋がります。
