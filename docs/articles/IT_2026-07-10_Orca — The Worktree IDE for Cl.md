## 1. Orcaとは？ — AIエージェント×Git Worktreeに特化した新世代IDE

**Orca**は、単なるテキストエディタではありません。**「Claude Code」「Ghostty」「Git Worktree」**を極限まで融合させ、AIコーディングエージェントのパフォーマンスを最大化するために設計された、全く新しいコンセプトの「Worktree IDE」です。

### 💡 注目すべき3つのコア特徴

1. **AI Agent & Claude Codeに完全最適化**
   Anthropicの超高速AIターミナルツール「Claude Code」や、各種自律型AIエージェントをIDE内にシームレスに統合。エージェントが自律的にファイルを書き換え、テストを実行するプロセスを安全かつスマートに管理します。
2. **「Ghostty」ターミナルのネイティブ統合**
   今、最も注目されているZig製の超高速・GPUアクセラレータ対応ターミナル「Ghostty」を内蔵。もたつかない、ミリ秒単位で応答する極上のCLI体験を提供します。
3. **「Git Worktree」ファーストの設計**
   ここが最大の革新ポイントです。Orcaは、1つのリポジトリから複数の作業ディレクトリを同時に展開する「Git Worktree」をベースにしています。
   * 「人間がコーディングするブランチ」
   * 「AI Agent Aがバグ修正を走らせるブランチ」
   * 「AI Agent Bがテストコードを書くブランチ」
   これらを**全く異なる物理フォルダとして超高速に切り替え・並行処理**できるため、環境の汚染やコンフリクトが一切発生しません。

## 2. 徹底比較：Orca vs Cursor vs Windsurf vs VS Code

AIコーディングツールの群雄割拠の中、Orcaはどのような立ち位置なのでしょうか？ 主要ツールと比較表を作成しました。

| 比較項目 | **Orca (Worktree IDE)** | **Cursor** | **Windsurf** | **VS Code (デフォルト)** |
| :--- | :--- | :--- | :--- | :--- |
| **開発コンセプト** | AIエージェント・マルチタスク | 人間主導のAIペアプロ | エージェントフロー型 | クラシックな汎用エディタ |
| **統合ターミナル** | **Ghostty (超高速/GPU駆動)** | 標準ターミナル | 標準ターミナル | 標準ターミナル |
| **AIエージェント最適化** | ⭐⭐⭐⭐⭐ (Claude Code完全対応) | ⭐⭐⭐⭐☆ (Composer機能) | ⭐⭐⭐⭐☆ (Cascade機能) | ⭐⭐☆☆☆ (プラグイン依存) |
| **Git Worktree管理** | **ネイティブ完全統合** | 手動 / 拡張機能が必要 | 手動 / 拡張機能が必要 | 手動 / 拡張機能が必要 |

### 比較から見えるOrcaの強み
CursorやWindsurfは「エディタのUI（GUI）の中にAIチャットが組み込まれている」構造です。
一方でOrcaは、**「ターミナル（CUI）とGit Worktreeという開発の『土台』そのものをAIエージェントが暴れ回れるように最適化した」**構造になっています。特に、AIエージェントをバックグラウンドで何個も並行して動かしたい本格派デベロッパーにとって、Orcaの右に出るものはありません。
