# 【物議】薬局で「家族の暗証番号を教えて」はセキュリティ崩壊？現場の混乱とIT的解決策

## 1. 事件の概要：なぜSNSで波紋を呼んだのか？

投稿者は、体調不良の家族に代わって薬局へ処方箋を出しに行きました。その際、薬局の受付で以下のようなやり取りが発生したとのことです。

*   **薬局側：**「ご本人のマイナンバーカードをお預かりします。暗証番号（4桁）も教えて（または入力して）ください」
*   **投稿者：**「暗証番号は本人以外が知るべきではないのでは？セキュリティ上、問題があるのではないか」

この投稿に対し、ネット上では「マイナンバーカードの運用原則（暗証番号は秘密にする）に反している」「セキュリティ意識が低すぎる」という批判が殺到。一方で、「代理受取時の顔認証が通らないため、現場は暗証番号を入力してもらうしかない」「厚労省のガイドラインが現場に無理を強いている」といった、薬局側に同情する声もあがり、大きな議論となりました。

### IT・ガジェットブロガーとしての見解
デジタル庁が推奨するパーソナルデータの管理において、**「暗証番号の他者共有」は最もやってはいけないアンチパターン**です。本来であれば、スマートフォンのマイナカード機能（電子証明書）や、マイナポータル上での「代理人登録機能」を活用した認証システムが完備されているべきですが、医療現場のハードウェア・ソフトウェアのアップデートが追いついていません。

# 対策：自宅でマイナポータル連携・処方箋管理をスマート化するガジェット

薬局の店頭で慌てて暗証番号を入力・開示するリスクを避けるためには、**「事前自宅手続き」**や**「マイナポータルと連携したヘルスケアアプリの活用」**が有効です。

PCやスマホを活用して、自宅で安全にマイナンバーカードを読み取り、医療費通知や処方情報を管理するための「ICカードリーダー」および関連ガジェットの導入をおすすめします。

# まとめ：行政と現場のギャップは「個人のDX防衛」で乗り越える

今回の「薬局での暗証番号要求問題」は、政府のデジタル化構想に現場の運用や国民のセキュリティリテラシーが追いついていない典型的な例です。
