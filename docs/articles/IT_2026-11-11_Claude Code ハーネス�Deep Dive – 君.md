## 1. そもそも「Claude Code」と「ハーネス（Harness）」とは？

### ターミナルから世界を動かす「Claude Code」
Claude Codeは、VS Codeなどのエディタ上ではなく、**コマンドライン（CLI）で直接動作する開発ツール**です。裏側では最新の「Claude 3.7 Sonnet（ハイブリッド推論モデル）」が動いており、複雑なアルゴリズムの思考と高速なコード生成を両立しています。

### 「ハーネス（制御機構）」がなぜ重要なのか？
Claude Codeは「ファイルを読む」「コードを書き換える」「シェルコマンドを実行する」といった強力な権限を持ちます。
ここで重要になるのが**「ハーネス（手綱）」**です。

*   **サンドボックス化（実行環境の制限）**
*   **パーミッション設定（ファイル書き換えやコマンド実行前の人間による承認）**
*   **MCP（Model Context Protocol）による外部ツール接続の制限**

「AIにどこまで全自動でやらせ、どこで人間の承認（Human-in-the-loop）を入れるか」という**ハーネス設計**こそが、Claude Codeを安全かつ最強の相棒にする鍵となります。

## 3. 君はどこまで制御する？ Claude Code「3つのハーネスレベル」

Claude Codeを使う際、開発者は以下の3つのレベルで権限を設定（ハーネス）できます。

```
[Level 1: 慎重派] ────> [Level 2: バランス派] ────> [Level 3: フルオート]
(全コマンド人間が承認)     (読み取り自動・実行は承認)      (MCP連携・完全自動化)
```

1.  **Level 1：フルガードモード（初心者・本番環境向け）**
    *   コードの変更やコマンド実行のたびに `[y/N]` の確認を求める。
    *   **メリット：** 勝手なコマンド実行やファイル破壊を防げる。
    *   **デメリット：** 頻繁にキーボードを押す必要があり、自動化の恩恵が薄れる。
2.  **Level 2：セミオート・ハーネス（推奨設定）**
    *   ファイルの読み込みや検索は完全自動。コード書き換えや `npm install` などの実行時のみ承認。
    *   **メリット：** スピードと安全性のベストバランス。
3.  **Level 3：フルアノニマス・ハーネス（上級者・ローカル検証向け）**
    *   Dockerコンテナ等に閉じ込めた状態で、全自動実行を許可。MCP経由でGitHubのPR作成まで自動完結。
    *   **メリット：** 「〇〇のバグを直してPR出しといて」の一言で寝ている間にタスク完了。

## まとめ：君はClaude Codeの手綱をどう握るか？

Claude Codeは、間違いなく**2025年最強のAIプログラミングツール**です。

しかし、その圧倒的なパワーゆえに、**「適切なハーネス（制御）」**が欠かせません。

*   最初は**Level 2（読み取り自動・実行は承認）**からスタートする
*   トークン消費を抑えるために `.claudeignore` を設定し、読み込むファイルを絞る
*   安全に暴れさせたいなら**VPSやDockerコンテナ内**で実行する

この3点を意識するだけで、あなたの開発スピードは間違いなく数倍に跳ね上がります。
