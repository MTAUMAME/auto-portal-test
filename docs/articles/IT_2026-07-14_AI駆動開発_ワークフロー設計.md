## 2. サクラレビューを弾いた！各ツールの「リアルな口コミ」と本音

ネット上の「案件記事」や「アフィリエイト目的の誇大広告」を排除し、X（旧Twitter）やエンジニアコミュニティ（Zenn, Qiita）での**リアルな不満点・改善点を含む本音の口コミ**をまとめました。

### ① Cursor（カーソル）
VS Codeから移行するユーザーが激増中の次世代AIコードエディタ。

* **リアルな高評価（本音）**
  * 「`@Web` で最新のAPIドキュメントを参照させながらコードを書けるのが神すぎる。公式ドキュメントをコピペする手間が消えた」
  * 「`Ctrl + K` でのインライン編集と `Ctrl + L` のチャットの使い分けが直感的。もうVS Codeには戻れない」
* **リアルな低評価・不満点（本音）**
  * 「無料枠の50プレミアムリクエストは一瞬で溶ける。実質、月額20ドルの課金は必須」
  * 「コードベース全体を参照（`@codebase`）させると、たまに嘘（ハルシネーション）を堂々とついてくる。結局デバッグ能力がないと詰む」

### ② GitHub Copilot
元祖にして、依然として高いシェアを誇るコード補完AI。

* **リアルな高評価（本音）**
  * 「タイピングしている先から数行先のコードを提案してくれる。この『タイピング速度の向上』という点ではCursorよりCopilotのインライン補完の方が軽快で優秀」
  * 「JetBrains系のIDEを愛用しているので、エディタをCursorに変えたくない自分にとってはCopilot一択」
* **リアルな低評価・不満点（本音）**
  * 「チャット機能（Copilot Chat）の賢さは、正直Cursor（Claude 3.5 Sonnet搭載）にボロ負けしている」
  * 「新規のファイル作成や、複数ファイルにまたがる大きなリファクタリングは苦手」

### ③ Bolt.new / v0（Web生成系AI）
プロンプトを入力するだけで、フロントエンドからバックエンド、デプロイまで自動で行う最新ツール。

* **リアルな高評価（本音）**
  * 「『こういうダッシュボード作って』と1行指示するだけで、Tailwind CSSが効いた美しい画面が30秒で動く。初期のモックアップ作成スピードは次元が違う」
* **リアルな低評価・不満点（本音）**
  * 「少し複雑なデータベース連携や、独自APIの繋ぎ込みを始めると途端にエラーを吐きまくって自滅する」
  * 「生成されたコードがブラックボックスになりがちで、後から自分で手修正するのが苦行」

## 3. 生産性を最大化する「AI駆動開発ワークフロー」設計パターン

ツールは単体で使うのではなく、**組み合わせる（ワークフロー設計する）**ことで真価を発揮します。
今、最も推奨されている2つのワークフローを紹介します。

### パターンA：【爆速モックアップ・個人開発向け】ノーコード連携ワークフロー
非エンジニアや、アイディアをすぐに形にしたい人向け。

1. **仕様定義 & データベース設計**: `Claude 3.5 Sonnet` で要件定義書とDB設計（スキーマ）を出力。
2. **UI・フロントエンド爆速生成**: `v0 (Vercel)` または `Bolt.new` に設計書をインプットし、フロント画面を自動生成。
3. **ローカル環境への移行 & カスタマイズ**: 生成されたコードを `Cursor` に取り込み、エラーの修正や細かいビジネスロジックを実装。

### パターンB：【プロ仕様】既存プロジェクト改善＆高品質開発ワークフロー
現役エンジニアが、実務で最大のパフォーマンスを出すための設計。

1. **エディタ**: `Cursor`（Proプラン）をメイン環境に。
2. **コード生成エンジン**: 基本は `Claude 3.5 Sonnet` を指定（Cursor内で切り替え可能）。
3. **バックグラウンド補完**: インラインのコード補完用に `GitHub Copilot` も併用（CursorはCopilotの補完機能を統合可能）。
4. **レビュー**: 生成されたコードを `Cursor` の `@codebase` 機能でプロジェクト全体との整合性をセルフチェック。
