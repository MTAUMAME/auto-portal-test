## 1. agent-desktop とは？

`agent-desktop` は、LLM（大規模言語モデル）のマルチモーダル機能（視覚・言語理解）を活用し、**コマンドライン（CLI）から指示を出すだけで、AIがデスクトップアプリ（ブラウザ、Slack、Excel、デザインツール等）を自律的に操作してくれるオープンソース/CLIエージェント**です。

### 主な特徴
*   **視覚ベースの操作**: スクリーンショットをリアルタイム解析し、ボタンの位置やテキストボックスを認識。
*   **自然言語での指示**: 「Chromeを開いて最新のニュースを要約し、Notionに保存して」といった指示だけで動作。
*   **クロスプラットフォーム対応**: macOS, Windows, LinuxのCLI環境で動く柔軟性。
*   **Claude 3.5 Sonnet / GPT-4o 対応**: 最先端の視覚理解モデルをバックエンドに使用可能。

## 2. 競合ツール・従来手法との性能・価格比較

デスクトップ自動化の領域には、従来のRPA（UiPathなど）や、他のAIエージェントフレームワークが存在します。それぞれを比較しました。

| 比較項目 | agent-desktop (CLI) | Anthropic Computer Use | Open Interpreter | 従来型RPA (UiPath等) |
| :--- | :--- | :--- | :--- | :--- |
| **操作対象** | GUI全般 + CLI | GUI全般 | CLI / Pythonコードメイン | 設定されたGUI要素 |
| **主なAIモデル** | Claude 3.5 / GPT-4o | Claude 3.5 Sonnet | GPT-4o / ローカルLLM | なし（ルールベース） |
| **導入難易度** | 中（CLI操作知識） | 高（API実装必要） | 初級〜中級 | 中〜高（専用知識） |
| **月額コスト** | **API従量課金のみ** | API従量課金のみ | API従量課金 / ローカル無料 | 高額（ライセンス契約） |
| **柔軟性・汎用性** | **★★★★★ (非常に高い)** | ★★★★★ | ★★★★☆ | ★★☆☆☆ (変化に弱い) |
| **実行速度** | ★★☆☆☆ (思考時間あり) | ★★☆☆☆ | ★★★☆☆ | **★★★★★ (爆速)** |

### 比較のポイント
`agent-desktop` は、従来RPAのように「ボタンの座標が変わったら動かなくなる」という弱点がありません。AIが「画面を目で見て判断」するため、画面レイアウトの変更にも柔軟に対応できます。コストも使った分だけの**API従量課金**なので、個人〜小規模チームでも導入しやすいのが魅力です。

## 3. サクラなし！リアルな口コミ・評判（メリット＆デメリット）

X（旧Twitter）、GitHub Issues、海外掲示板（Reddit）から、**広告・サクラ投稿を排除した「ユーザーの本音」**をまとめました。

### ✕ デメリット・注意すべき口コミ
> 💬 **「API代が予想以上にかかる…」**
> スクリーンショットを何枚も送って思考ループを回すため、1つのタスクでClaudeのAPIコストが数ドル飛ぶことがある。実験するときはループ上限を設定しないと危険。（30代 Webエンジニア）

> 💬 **「反応速度はまだ遅い」**
> 人間が操作した方が速いレベル。定常的なバックグラウンド作業や、寝ている間の自動化向き。リアルタイムな作業には不向き。（20代 AIリサーチャー）

> 💬 **「誤操作のリスクがある」**
> ファイル削除や送信ボタンを勝手に押すリスクがあるので、サンドボックス環境（仮想マシン）で動かすのが必須。（40代 インフラエンジニア）

### ◎ メリット・絶賛する口コミ
> 💬 **「APIがないレガシーアプリの自動化に神」**
> Web APIが用意されていない社内システムや古いデスクトップソフトのデータを抽出するのに最高。コードを書く時間が激減した。（30代 システム開発）

> 💬 **「CLIだからシェルスクリプトに組み込める」**
> Cronで夜中に起動して、ブラウザ操作→デスクトップアプリへの入力→メール送信までの一連のワークフローが自動化できた。（40代 フリーランスエンジニア）
