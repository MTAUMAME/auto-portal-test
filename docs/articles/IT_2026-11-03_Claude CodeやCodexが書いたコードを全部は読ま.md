## 1. AI生成コードを「全部読まずに説明できる」4つの手順（AIDB流要約）

AIが生成した数百〜数千行のコードを1行ずつ追うのは非効率です。以下の4ステップを踏むことで、短時間で「コードの構造」と「採用理由」を把握できます。

```
[Step 1] 構造の可視化 (全体像)
       ↓
[Step 2] 核心ロジックと境界値の抽出 (要点)
       ↓
[Step 3] AIへの「逆引き質問」 (根拠)
       ↓
[Step 4] テストコードによる挙動証明 (保証)
```

### Step 1: 全体像（アーキテクチャ）をAIに可視化させる
いきなり実装コードを見ず、AIに**「モジュール間の関係性」や「処理のフローチャート（Mermaid形式）」**を出力させます。
*   **アクション**: 「この変更の全体像をMermaidのシーケンス図で出力して」と指示。
*   **効果**: 視覚的に「どこがどう動くか」を数秒で理解できます。

### Step 2: 「核心ロジック」と「境界値」だけをピンポイントで読む
ボイラープレート（定型文コード）やエラーハンドリングは一旦無視します。
*   **アクション**: データの変換処理、ビジネスロジック、外部API呼び出し部分の「入力と出力」だけを確認。
*   **効果**: 読むべきコード量を全体の**10〜20%に削減**できます。

### Step 3: AIに対して「逆引き質問」を行い、説明の弾仕込みをする
チームメンバーや上司に説明するシーンを想定し、AIに選択理由を問いただします。
*   **プロンプト例**: 「なぜこのライブラリ/アルゴリズムを選んだ？他の選択肢と比べたメリット・デメリットは？」
*   **効果**: 自分が書いていないコードでも「〇〇という理由でこの設計にしました」と自信を持って説明可能に。

### Step 4: テストコードを実行し、挙動を保証する
「動くこと」の証明は、コードを読むことではなく「テストが通ること」です。
*   **アクション**: AIにエッジケース（例外処理）を含めた単体テストを書かせ、通過することを確認。
*   **効果**: 「コードは全行読んでいませんが、仕様を満たすテストがすべてグリーンです」という強力な根拠が作れます。

## 2. 【対決】Claude Code vs GitHub Copilot (Codex) 比較

AIにコードを書かせる（そして説明させる）上で、現在トップを走る2大ツールの性能と価格を比較しました。

| 項目 | Claude Code (Anthropic) | GitHub Copilot / Codex (OpenAI) |
| :--- | :--- | :--- |
| **主な形態** | CLI（ターミナル直打ち型エージェント） | IDE拡張機能 (VS Code等) |
| **ベースモデル** | Claude 3.7 Sonnet (Hybrid Reasoning) | GPT-4o / Codex |
| **価格** | API従量課金 または Maxプラン($100/月〜) | Personal: $10/月<br>Business: $19/月 |
| **複雑なコードの理解力** | **極めて高い**（推論モードが強力） | 高い（一般的な補完は最速） |
| **長文コードの説明力** | **神レベル**（コンテキスト長＆ロジック説明が得意） | 標準的 |
| **手軽さ** | CLI操作に慣れが必要 | インストールするだけで即利用可能 |

### どちらを選ぶべき？
*   **Claude Code**: 「ターミナルから一発でリファクタリングさせたい」「複雑なコードの意図をAIと対話しながら深く理解したい」パワーユーザー向け。
*   **GitHub Copilot**: 「リアルタイムの補完が欲しい」「コスパ良く月額固定で使いたい」すべてのエンジニア向け。
