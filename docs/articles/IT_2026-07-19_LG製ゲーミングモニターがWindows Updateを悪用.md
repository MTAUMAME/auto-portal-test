## 1. 何が起きたのか？LG製モニター「広告アプリ無断導入問題」の概要

海外のRedditやSNS、技術系メディアで報告され、国内でも騒ぎになっている本件。要点は以下の通りです。

```
【問題のメカニズム】
LG製モニターを接続する
　↓
Windows Updateが「モニターの最適化ドライバー/管理ソフト（OnScreen Control等）」を自動検知
　↓
ユーザーの明示的な同意なしに、裏で「McAfee Security」などのサードパーティ製広告アプリが勝手にインストールされる
　↓
PC起動時などにMcAfeeのポップアップ広告が表示されるようになる
```

### なぜこんなことが可能なのか？（技術的背景）
これは**「WPBT（Windows Platform Binary Table）」**という仕組み、またはWindows Updateの**「拡張ドライバー配布機能」**が悪用された形です。
本来はマザーボードの機能や専用デバイスを動かすための仕組みですが、メーカーがここに「自社ソフト（および提携している広告ソフト）」を仕込むことで、OSのアップデートに乗じてユーザーのPCにプログラムを送り込むことが可能になってしまいます。

### ユーザーの反応
「ただのディスプレイだと思って繋いだのに、アドウェア（広告ソフト）を仕込まれるのはスパイウェアに近い」「いくら液晶パネルが優秀でも、OSを汚すメーカーの製品は買いたくない」と、主にセキュリティ意識の高い自作PC派やゲーマーから猛反発を受けています。

## 4. LG製モニターを安全に使うための「自己防衛策」

もし「どうしても画質とコスパが良いからLG製が良い！」という場合は、以下の**セキュリティ対策**を講じることを強くおすすめします。

1. **専用ソフトウェア（OnScreen Controlなど）はインストールしない**
   * 画質調整はモニター本体の物理ボタン（底面のジョイスティック）で行えば、ソフトは不要です。
2. **Windows Updateの「自動デバイス設定」をオフにする**
   * 設定 ＞ システム ＞ バージョン情報 ＞ システムの詳細設定 ＞ 「ハードウェア」タブ ＞ 「デバイスのインストール設定」から「いいえ」を選択。これでメーカー製アドウェアの強制導入を防げます。
3. **サードパーティ製のディスプレイ管理ソフトを使う**
   * Windows上で明るさを変えたい場合、オープンソースの安全なソフト（例：『Twinkle Tray』など）を使用することで、メーカー純正の重いソフトを排除できます。
