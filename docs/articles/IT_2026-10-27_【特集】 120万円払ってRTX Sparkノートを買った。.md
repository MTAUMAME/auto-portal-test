## 2. 性能と価格の徹底比較（スペック比較表）

同価格帯〜ハイエンドの競合環境とスペック・コストを比較しました。

| 項目 | **RTX Spark ノート** | デスクトップ(RTX 4090 2枚刺し) | MacBook Pro M3 Max (フル盛) |
| :--- | :--- | :--- | :--- |
| **価格** | **120万円** | 約110万円 | 約100万円 |
| **VRAM / メモリ** | **96GB (GPU専有)** | 48GB (24GB×2) | 128GB (ユニファイド) |
| **可搬性 (重量)** | ○ (約3.2kg) | × (持ち運び不可) | ◎ (約2.1kg) |
| **70Bモデル推論速度** | **約35 tokens/sec** | 約40 tokens/sec | 約15 tokens/sec |
| **最大消費電力** | 330W | 1000W+ | **80W** |
| **主な用途** | ローカルAIエージェント開発 / 現場デモ | 放置型大型モデル学習 | モバイル開発 / 動画編集 |

### 比較から分かったこと
*   **MacBook Pro:** メモリ容量は凄いが、CUDA非対応のため一部のAIライブラリや画像生成（SDXL/Flux）の速度でRTX Sparkに圧倒的な差をつけられる。
*   **RTX 4090デスクトップ:** 電気代と設置場所がネック。VRAM 48GBでは、将来的な超大型モデルの並列実行に限界がある。
*   **RTX Spark:** ノートPCの形をした「持ち運べるAIサーバー」。価格は高いがVRAM 96GBの威力が絶大。
