## 1. Microsoftの新機能：何ができるようになった？

これまでもサードパーティ製アプリ（Duet DisplayやSpacedeskなど）を使えばスマホのサブ画面化は可能でしたが、今回のアップデートにより**「Windows 11」標準機能（「Windows にリンク」アプリ）**として、よりシームレスかつ高画質に統合されました。

### 主な特徴とメリット
* **完全ワイヤレス接続：** Wi-Fi経由でPCと瞬時に接続。
* **タッチ操作・ペン入力対応：** Android側のタッチパネルやスタイラスペン（Sペンなど）を使ってWindowsを操作可能。
* **カメラ共有機能：** スマホの高品質なメインカメラを、WindowsのWebカメラとして利用可能。
* **設定が極めて簡単：** マイクロソフトアカウントでログインするだけ。

## 2. 比較：「Androidサブ画面」vs「モバイルモニター」vs「iPad(Sidecar)」

「わざわざ専用のモバイルモニターを買うべきか？」迷っている方のために、価格と性能を比較表にまとめました。

| 項目 | **Android ＋ Windows（新機能）** | **専用モバイルモニター** | **iPad ＋ Mac（Sidecar）** |
| :--- | :--- | :--- | :--- |
| **導入コスト** | **0円**（手持ちのスマホを活用） | 15,000円 〜 35,000円 | 50,000円〜 + Mac本体 |
| **画面サイズ** | 6.1〜11インチ（端末による） | 13.3〜15.6インチ | 8.3〜12.9インチ |
| **持ち運びやすさ** | **最高**（荷物が増えない） | 普通（ケース含め約1kg増） | 良い |
| **遅延（レイテンシ）** | わずかにあり（Wi-Fi環境依存） | **ほぼゼロ**（HDMI/Type-C直結） | ほぼゼロ |
| **画面の綺麗さ** | **非常に高い**（有機ELスマホ多数） | 価格相応（安価なものは発色が悪い） | 非常に高い |
| **バッテリー消費** | スマホ側の減りが早い | PCから給電 / 給電不要 | iPad側の減りが早い |

### 結論：どちらを選ぶべき？
* **「サブ画面化」がおすすめな人：** チャットツール（Slack/Discord）やTwitter、YouTubeのコメント欄など「常時表示しておくだけ」のサブ画面が欲しい人。ノマドワーカー。
* **「専用モバイルモニター」がおすすめな人：** 15インチ以上の大画面でExcelをバリバリ編集したい人や、遅延が許されない動画編集・ゲームを行う人。
