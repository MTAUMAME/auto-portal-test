## 1. Claude Codeとは？なぜレガシーシステム刷新に最強なのか

**Claude Code**は、ターミナル上で動作するAIコーディングエージェントです。ブラウザのチャット画面でコードをコピペする従来の手法とは異なり、**AIが直接あなたのローカルファイルを読み込み、コマンドを実行し、テストを走らせてバグを修正**します。

### レガシーシステム刷新でClaude Codeが最強な理由

1. **巨大なコンテキストウィンドウ（1回で読み込める量が多い）**
   Claude 3.5 Sonnetの圧倒的な長文理解力により、スパゲッティ状態の巨大なコードベースを一括で理解できます。
2. **「テスト→修正」の自律ループ**
   「この古いPHPコードを最新のNode.jsに移植して、テストが通るまで修正して」という指示だけで、AIが自律的にコマンドを叩いてエラーを解決します。
3. **仕様書の自動生成**
   コードを解析し、「仕様書が失われたレガシーシステム」の設計書やREADMEを自動で書き出します。

## 2. 実践ドキュメント：Claude Codeでレガシーシステムを刷新した4ステップ

ここでは、**「PHP 5.xで書かれた10年前の社内管理システムを、TypeScript / Next.jsに移行する」**というプロジェクトを例に、具体的な進め方を解説します。

```bash
# Claude Codeの起動（プロジェクトのルートディレクトリで実行）
claude
```

### ステップ1：現状分析と依存関係の可視化
まずは、カオス化したコードの全体像をClaudeに分析させます。

> **プロンプト例：**
> `このプロジェクトにある全ファイルの依存関係を分析し、どのモジュールから移行を進めるべきかロードマップを提案して。`

Claude Codeは自動でディレクトリを探索し、依存度の低い（＝移植しやすい）ユーティリティ関数などから段階的に移行するプランを提示してくれます。

### ステップ2：ユニットテストの自動生成（最も重要！）
レガシーシステムにはテストコードがないケースがほとんどです。動いている現在の挙動（仕様）を担保するため、まず現行コードのテストを書かせます。

> **プロンプト例：**
> `src/utils/legacy_calculator.php の挙動を担保するためのテストケースを、現在の仕様に基づいて生成して。`

### ステップ3：新言語への自律トランスパイル
テストが確保できたら、ターゲット言語（TypeScript）への書き換えを指示します。

> **プロンプト例：**
> `legacy_calculator.php のロジックを TypeScript に書き換え、src/utils/calculator.ts として保存して。その後、Vitestを使って同等のテストがパスすることを確認して。`

ここからがClaude Codeの本領発揮です。エラーが出ると、Claudeは**自動でテストエラーログを読み込み、自らコードを修正して再テスト**を繰り返します。

### ステップ4：ドキュメントの自動生成
移行完了後、未来のチームメンバーのためにドキュメントを残します。

> **プロンプト例：**
> `今回移行したTypeScriptコードのAPI仕様書（Markdown形式）を docs/api_spec.md に出力して。`

これだけで、人間がやれば数週間かかる移行作業が、**わずか数日（体感で10倍以上のスピード）**で完了します。

## 3. 【徹底比較】Claude Code vs 競合AIコーディングツール

レガシー刷新に使う際、どのツールが最もコスパが良いのか？「Cursor」「GitHub Copilot」と比較しました。

| 項目 | **Claude Code** (Anthropic) | **Cursor** (Anysphere) | **GitHub Copilot** (Microsoft) |
| :--- | :--- | :--- | :--- |
| **主なインターフェース** | ターミナル（CLI） | 専用IDE（VS Codeベース） | VS Code / JetBrains 拡張 |
| **レガシー解析力** | ⭐⭐⭐⭐⭐ (最強) | ⭐⭐⭐⭐☆ (優秀) | ⭐⭐⭐☆☆ (部分最適向け) |
| **特徴** | 自律エージェント。コマンド実行やテストもAIが自動で行う。 | GUIでコードを見ながら直感的に編集できる。 | エディタ内での高速なコード補完に特化。 |
