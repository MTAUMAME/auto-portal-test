# ニデックの巨額減損をどう読む？投資家が今知っておくべき「リスク管理」の基本

こんにちは！資産運用をサポートするアドバイザーです。
先日、日本経済新聞で「ニデックが数千億円規模の減損処理を行う」という衝撃的なニュースが報じられました。

### 1. 最新情報：ニデックで何が起きているのか？（自己検証）

今回の報道の要点は以下の通りです。

*   **何が起きた？：** ニデック（旧：日本電産）が、EV（電気自動車）向けトラクションモーター事業などで、数千億円規模の減損損失を計上する見通しとなりました。
*   **なぜ？：** 世界的なEV販売の減速、および過去の買収に関連するのれん代（買収価格と時価の差額）の精査が影響しています。
*   **投資家への影響：** 決算発表直後は株価が大きく変動するリスクがあります。ただし、これは「未来の損失を会計的に先取りして処理する」という側面もあり、企業としての再出発を図る意味も含まれています。

**【教訓】** 個別企業の株は、経営環境の変化で大きなダメージを受けるリスクがあります。だからこそ、特定の1社に集中投資せず、**「分散投資」**が不可欠なのです。

### 3. 手数料・利回りの比較：投資の「土台」を整えよう

個別株の乱高下に振り回されないためには、低コストな「投資信託」でのインデックス運用が最も効率的です。

| 項目 | ネット証券（新NISA） | 銀行窓口での購入 |
| :--- | :--- | :--- |
| **購入時手数料** | **無料（ノーロード）** | 2〜3%かかる場合がある |
| **運用管理費用（信託報酬）** | **年0.1%前後と非常に安い** | 年1%以上かかることが多い |
| **分散の範囲** | 数千社〜数万社（世界全体） | 営業担当のおすすめ数社のみ |
| **期待利回り** | 年率3〜7%（市場平均） | 商品によるが手数料で相殺されがち |

※ネット証券を活用するだけで、長期的に数百万円単位の差がつくこともあります。
