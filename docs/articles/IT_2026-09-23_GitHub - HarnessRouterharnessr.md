## 1. HarnessRouterとは？ 主な機能と特徴

[HarnessRouter (GitHub)](https://github.com/HarnessRouter/harnessrouter)は、様々なAIエージェントの実行環境（ハーネス）を、**1つの統一されたAPIインターフェース**で操作できるようにする、セルフホスト型（自己サーバー運用型）のルーティングツールです。

ライセンスは商用利用も可能な **Apache-2.0**。完全無料で自分のサーバーやローカルPCに構築できます。

### 💡 主な特徴とできること
1. **多様なエージェントへの統一アクセス**
   Claude Code、Codex、Hermes、PI、DSHといった最新のAIエージェント群を、単一のAPIで切り替えて実行可能です。
2. **高度なセッション管理 (Sessions)**
   エージェントとの対話履歴や文脈（コンテキスト）を維持したまま、スムーズな連続対話を実現します。
3. **ストリーミング対応 (Streaming)**
   AIからの回答をリアルタイム（逐次出力）で受け取れるため、開発時のストレスがありません。
4. **ファイルハンドリング (Files)**
   コード解析やデータ処理に必要なファイルのアップロード・操作をAPI経由で安全に行えます。

## 2. 性能・価格・他ツールとの比較

AIルーティングや統合ツールは他にもありますが、HarnessRouterは何が違うのでしょうか？
代表的なツールである「LiteLLM」「Dify」「LangChain」と比較しました。

| 比較項目 | **HarnessRouter** (本作) | **LiteLLM** | **Dify** | **LangChain** |
| :--- | :--- | :--- | :--- | :--- |
| **主なターゲット** | **AIエージェントの統合** | LLM APIの統合 | ノーコードAIアプリ開発 | AIアプリ開発フレームワーク |
| **ライセンス** | **Apache-2.0 (完全無料)** | MIT (一部エンタープライズ有料) | 独自のオープンソース (商用制限有) | MIT |
| **セルフホスト** | **可能 (簡単・完全無料)** | 可能 | 可能 (クラウド版は有料) | 可能 (評価ツールは有料) |
| **得意な処理** | エージェントハーネス、ファイル、セッション管理 | 100種類以上のLLM API接続 | GUIでのフロー構築、RAG | Python/JSによる複雑なロジック構築 |
| **導入難易度** | **中（Docker知識が必要）** | 低（プロキシとして動かすだけ） | 低（直感的なWebUI） | 高（プログラミング必須） |

### 比較の結論：
* **LiteLLM**は「単純なテキスト生成API（GPTやClaudeなど）をまとめたい」時に最適です。
* **HarnessRouter**は、一歩進んで「**Claude Codeなどの『自律型エージェント』をファイル操作やセッションを含めて統合したい**」という開発者にピンポイントで刺さる仕様になっています。
