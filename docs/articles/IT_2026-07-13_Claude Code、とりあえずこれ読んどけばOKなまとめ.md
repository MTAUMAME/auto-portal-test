## 1. 3分でわかる「Claude Code」Qiitaまとめ

Qiitaでブックマークを量産している「これ読んどけばOK」記事の要点を、初心者にもわかりやすく3行でまとめると以下の通りです。

1. **「エージェント型」の究極系：** チャットで指示するだけで、AIがローカルファイルを探し、コードを書き、テストを実行し、エラーが出たら勝手に修正してGitコミットまで完了する。
2. **ターミナル完結の爆速動作：** エディタ（VS Codeなど）を選ばない。`claude` とコマンドを叩くだけで、あなたのMac/PCが「超優秀なシニアエンジニア」に早変わり。
3. **「コードの文脈理解」が化け物級：** 数万行におよぶ巨大なプロジェクトでも、関連するファイルを一瞬で特定し、破綻のないリファクタリング（コードの整理）を実行。

### Qiita著者が推奨する「Claude Code」基本コマンド
これだけ覚えておけば、今日からプロ開発者レベルの自動化が可能です。

```bash
# 起動
$ claude

# 指示（例：テストが通るようにバグを修正して）
Claude > ユーザー登録機能のテストが落ちるので、コードを修正してテストを実行しておいて。
```
