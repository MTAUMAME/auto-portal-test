# AIは「メンタルが強すぎる」？チェスで人間が勝てない本当の理由

まずはナゾロジーで紹介された研究の要点をサクッと解説します。

> **【記事の要点】**
> * **研究内容：** 人間とチェスAI（Stockfishなど）の対局データを分析。
> * **判明したこと：** 人間は盤面が複雑（高エントロピー）になると、精神的負荷（認知負荷）から逃れるために、**「早く局面を単純化させたい」という衝動に駆られ、悪手を指してしまう。**
> * **AIの強み：** 一方、AIには感情や認知負荷がないため、**「ややこしくて混沌とした状態」を維持したまま、何手先までも最適な計算を続けることができる。**

つまり、AIが強いのは単純に「計算が速いから」だけではなく、**「ややこしい状況に耐え続ける力が無限にあるから」**なのです。人間が「もう考えるのが面倒くさい！一か八かこれで解決だ！」と投げ出した瞬間を、AIは見逃さずに仕留めています。
