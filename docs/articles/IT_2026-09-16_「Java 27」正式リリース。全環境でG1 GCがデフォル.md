## 1. Java 27の注目すべき「2大新機能」

### ① 全環境で「G1 GC（Garbage-First Garbage Collector）」がデフォルトに！
これまで、低スペックな環境やコンテナ環境では「Serial GC」が自動選択されることがありましたが、Java 27からは**すべての環境で「G1 GC」がデフォルト**になります。

*   **何が嬉しい？**：コンテナ（Docker/Kubernetes）環境でのメモリ効率が劇的に向上。チューニングなしでも、一時的なメモリバーストによる「OOM（Out of Memory）キル」を防ぎやすくなりました。
*   **AI時代のメリット**：AIモデルの推論エンジンをJavaで動かす際の大規模メモリ管理が、よりスムーズに行えます。

### ② TLS 1.3対応：耐量子暗号（PQC）ハイブリッド鍵交換
「今、暗号化データを盗んでおき、将来量子コンピュータが完成した時に解読する」という脅威（Harvest Now, Decrypt Later）に対抗するため、Java 27は**耐量子暗号（ML-KEMなど）と従来の楕円曲線暗号を組み合わせたハイブリッド鍵交換**を標準搭載しました。

*   **何が嬉しい？**：金融機関や医療系システム、エンタープライズLOBアプリにおいて、将来にわたって安全な通信（TLS 1.3）を担保できます。

## 2. 【比較】主要JDKの「価格・サポート・性能」マップ

Java 27を利用するにあたり、どのJDKディストリビューションを選ぶべきか、コストと特徴を比較しました。

| JDKディストリビューション | 商用利用の価格 | サポート体制 | パフォーマンスの特徴 | おすすめの用途 |
| :--- | :--- | :--- | :--- | :--- |
| **Oracle JDK** | 有料（サブスク形式）※一定条件で無料 | 公式の即時パッチ、超手厚いサポート | 商用環境での最高レベルの最適化 | 大企業・エンタープライズ金融 |
| **Eclipse Temurin** (Adoptium) | **完全無料**（オープンソース） | コミュニティサポート | 標準的かつ非常に安定 | 一般的なWebアプリ、移行お試し |
| **Amazon Corretto** | **完全無料** | AWSによる長期サポート（LTS） | AWS（EC2/ECS等）での動作成績◎ | AWS上のクラウドネイティブアプリ |
| **Azul Zulu** | 無料（サポートプランは有料） | 強力な商用サポートオプションあり | 起動速度や超低遅延（ZGC等）に強み | 高頻度取引、低遅延が求められるシステム |

### 性能比較まとめ：
個人開発や一般的なWebサービスであれば、コストパフォーマンス最強の**「Eclipse Temurin」**または**「Amazon Corretto」**で十分です。ミッションクリティカルな環境では、Oracleの有償サポートやAzul Zuluの超低遅延チューニングが投資価値を持ちます。
