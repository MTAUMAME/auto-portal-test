## 1. なぜセルフレジのUI/UXは「絶望的に統一されない」のか？

現在、流通しているセルフレジは大きく分けて**3つの世代（方式）**が混在しています。これがユーザーを混乱させる最大の原因です。

```
【混乱の構造】
店舗A（旧世代）：バーコードスキャン ＋ 重量センサー（判定が厳しくエラー多発）
店舗B（現行）：全画面タッチパネル ＋ 支払い方法を先に選ばせる（画面が複雑）
店舗C（次世代）：RFID・画像認識AI（カゴを置くだけ・超快適）
```

ユーザーは店を移動するたびに「脳の認知負荷（Cognitive Load）」をリセットされ、異なる操作ロジックを強制されているのです。

## 2. セルフレジ採用技術の「価格・性能・UX」比較

店舗側が導入しているレジシステムを「導入コスト」「処理性能」「ユーザー体験（UX）」で比較しました。

| システム方式 | 主な導入店舗例 | 導入コスト(店舗側) | 処理スピード | UX（使いやすさ）評価 | 主な課題・エラー要因 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **① バーコード＋重量センサー** | イオン、大手スーパー | 中（既存システムの流用） | 🐢 遅い | ⭐☆☆☆☆ (最悪) | 袋の重さズレで即停止。UX設計が最悪。 |
| **② バーコード＋AIカメラ補正** | ローソン、セブン | 高 | 🐇 普通 | ⭐⭐⭐☆☆ (普通) | 年齢確認や決済選択の画面遷移が多すぎる。 |
| **③ RFID（ICタグ）一括読み取り** | ユニクロ、GU | 高（タグ単価がかかる） | ⚡ 爆速 | ⭐⭐⭐⭐⭐ (神) | 商品ごとにタグ貼り付けが必要（食品には不向）。 |

### ★結論：ユニクロ（RFID）以外は、まだ人間の動線を考慮しきれていない
ユニクロのセルフレジが絶賛される理由は「カゴを置くだけ」でAI・ITが裏で処理を完結させているからです。
一方、スーパー等の「重量センサー式」は、**「客を泥棒扱いする（不正防止）」ためのシステムであり、ユーザー体験を無視して設計されている**ため、エラーが多発します。
