## 1. SmartHRが実践した「ハーネス設計手法」とは？

SmartHRのテックブログで紹介された**「ハーネス（Harness）設計手法」**。一言で言えば、**「AI（Claude Code）が迷子にならず、自律的に爆走できるための『安全枠（テスト・環境）』を人間が先回りして作ること」**です。

通常、AIに複雑なコードを書かせると、エラーを吐いたときにAI自身がどう修正していいか分からず「無限修正ループ」に陥りがちです。

### 🚀 期間を半分以下にした3つの骨子
1. **結合テストの「ハーネス（テスト環境）」を先に作る**
   仕様に沿ったテストコード（成功・失敗の基準）を先に人間が完璧に用意します。
2. **Claude Codeに「テストが通るまで自律実行」させる**
   Claude Codeに「このテストをパスするコードを実装して」と命令。Claude Codeは、コード生成 → テスト実行 → エラー確認 → 再修正 をターミナル上で自律的に繰り返します。
3. **境界条件の明文化**
   AIが誤解しやすい仕様（エッジケース）をあらかじめドキュメント（ハーネス）として定義しておくことで、手戻りをゼロにしました。

この「お膳立て（ハーネス）」を最初に行うことで、**実装とデバッグの大部分をClaude Codeに完全自動化**させ、2.5ヶ月の工数を1ヶ月に縮めることに成功したのです。

## 2. Claude Codeとは？ 他のAI開発ツールとの徹底比較

「Claude Code」は、Anthropicが開発した**ターミナル（CUI）上で動作するAI開発エージェント**です。VS Codeの拡張機能（GitHub Copilotなど）やAI特化型エディタ（Cursor）とは何が違うのでしょうか？

### 📊 主要AI開発ツール 比較表

| 項目 | **Claude Code** (Anthropic) | **Cursor** (Anysphere) | **GitHub Copilot** (GitHub) |
| :--- | :--- | :--- | :--- |
| **主な形態** | ターミナル（CLI）ツール | 独自コードエディタ（VS Codeフォーク） | エディタ拡張機能（VS Code/JetBrains等） |
| **料金・コスト** | API利用料に応じた従量課金（$0.20〜/100万トークン等） | 無料枠あり / Pro: $20/月 | 個人: $10/月 / Business: $19/月 |
| **自動実行力** | **極めて高い**（コマンド実行、テスト、Git操作を自律実行） | **高い**（Composer機能での複数ファイル書き換え） | **中**（コード補完、チャットでの提案がメイン） |
| **コンテキスト理解**| **最高峰**（Claude 3.7 Sonnet搭載） | **高い**（各種LLMを選択可能） | **標準〜高**（リポジトリ全体の理解） |
| **導入ハードル** | 中〜高（ターミナル操作、APIキー設定が必要） | 低（エディタをインストールするだけ） | 低（プラグインを入れるだけ） |

### 💡 結論：どれを選ぶべき？
* **Claude Code**：テストの自動実行やリファクタリングなど、**「エージェントとして自律的にタスクを完結させたい」**上級者・爆速重視向け。
* **Cursor**：UIで視覚的にコードを見ながら、**「チャット感覚で手軽に複数ファイルの編集を行いたい」**万人向け。
* **GitHub Copilot**：エディタに馴染ませて、**「日々のコード補完をスムーズに行いたい」**人向け。
