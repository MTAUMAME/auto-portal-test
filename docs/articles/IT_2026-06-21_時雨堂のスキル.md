## 1. 時雨堂（Shiguredo）の「スキル」とは？

時雨堂は、WebRTC（Web Real-Time Communication）と呼ばれる、ブラウザやアプリ間で超低遅延（0.1〜0.5秒以下）の音声・映像通信を行う技術に特化した日本の専門集団です。

彼らが提供する主な「スキル（製品・サービス）」は以下の通りです。

```
【時雨堂の技術エコシステム】
 ├── WebRTC SFU Sora (超高性能・商用サーバー) ── [AIリアルタイム解析 / 大規模配信]
 ├── WebRTC Native Client Momo (オープンソース) ── [Raspberry Pi / IoTカメラ]
 └── Sora Cloud (マネージドサービス) ── [インフラ管理不要のWebRTC]
```

### ① WebRTC SFU 「Sora（ソラ）」
時雨堂のフラグシップ製品。数万人規模の同時接続にも耐えうる、国産の超高性能WebRTC配信サーバーです。
*   **AIとの相性抜群**：映像・音声をリアルタイムでAIサーバーに転送し、1秒未満でAI（物体検出や音声認識）の解析結果をフィードバック可能。
*   **圧倒的な安定性**：日本の商用環境で圧倒的なシェアを誇ります。

### ② WebRTC Native Client 「Momo（モモ）」
GitHubでオープンソース（OSS）として公開されている、IoT向けのWebRTCクライアント。
*   **ガジェット好き必見**：Raspberry Pi（ラズパイ）やNVIDIA Jetsonなどのシングルボードコンピューターで動作し、カメラ映像をブラウザへ超低遅延で直接伝送できます。

## 2. 【徹底比較】時雨堂 Sora vs 他社ソリューション

WebRTCを自社サーバーで構築、またはAIプロダクトに組み込む際、どの選択肢がベストなのか比較しました。

| 項目 | **時雨堂 Sora (Sora Cloud)** | **OSS（Janus / mediasoup）** | **Twilio WebRTC (移行推奨中)** |
| :--- | :--- | :--- | :--- |
| **開発国/サポート** | 🇯🇵 日本（超迅速・日本語） | 🌐 コミュニティ（英語） | 🇺🇸 米国（英語メイン） |
| **遅延速度** | **極小（100〜300ms）** | 極小（200〜500ms） | 中〜極小（300〜600ms） |
| **ライセンス/価格** | 有料ライセンス（評価版あり） | 完全無料（構築コスト大） | 従量課金（サービス終了傾向） |
| **対応コーデック** | H.264, H.265, VP9, **AV1** | H.264, VP8/VP9 | 限定的 |
| **安定性・保守性** | ⭐️⭐️⭐️⭐️⭐️ (神レベル) | ⭐️⭐️⭐️ (アップデート自力) | ⭐️⭐️⭐️ (サービス改変多) |
| **おすすめ対象** | 企業・ガチAI開発者 | 予算ゼロの腕自慢エンジニア | 一般的なWebAPI連携 |

### 時雨堂の強み：最新AIへの対応スピード
時雨堂は、次世代ビデオコーデック「AV1」や、最新のネットワークプロトコルへの追従スピードが異常に早いです。これにより、**高画質なカメラ映像をAI（YOLOv8など）に超低速遅延で送り、解析する**といった処理がスムーズに行えます。
