## 💡 AIネイティブSDLCとは？（従来の開発との違い）

従来の開発（DevOps）とAIネイティブ開発の違いは、**「人間がコードを書き、AIが手伝う」から「AIがコードを生成し、人間がレビュー・指揮する」**への主客逆転です。

| 開発フェーズ | 従来の方法 (DevOps) | AIネイティブSDLC | おすすめツール |
| :--- | :--- | :--- | :--- |
| **1. 要件定義・設計** | 人間がドキュメントを作成 | 対話型AIで仕様書・DB設計を自動生成 | Claude 3.5 Sonnet / v0 |
| **2. 実装 (Coding)** | 手動コーディング | エージェント型AIによる一括コード生成 | Cursor / Replit Agent |
| **3. テスト作成** | 手動で単体テスト作成 | コード変更に伴いAIがテストを自動生成 | Coderabbit / GitHub Copilot |
| **4. コードレビュー** | 先輩エンジニアの目視 | AIによる即時PR（プルリク）レビュー | CodeRabbit |
| **5. エラー調査・保守** | ログを検索してデバッグ | ログを入力しAIが原因特定＆修正PR作成 | Sentry + ChatGPT |
