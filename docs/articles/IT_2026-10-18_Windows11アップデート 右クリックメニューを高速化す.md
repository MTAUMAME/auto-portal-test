## 1. 【無料】コマンドプロンプト1発で右クリックを爆速化する方法

まずは、OSの設定を変更して右クリックメニューを「Windows 10スタイル」に戻す方法です。レジストリを直接触らず、コマンド1行で完結します。

### 設定手順（所要時間：30秒）

1. キーボードの `Win + S` を押し、「`cmd`」と入力。
2. 「コマンドプロンプト」を**管理者として実行**します。
3. 以下のコードをコピー＆ペーストして `Enter` を押します。

```bash
reg add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve
```

4. PCを再起動（またはタスクマネージャーから「エクスプローラー」を再起動）します。

これだけで、あのモッサリした新メニューではなく、**旧型の爆速右クリックメニューが一発で表示**されるようになります！

> **元に戻したい場合：**
> 以下のコマンドを実行して再起動すればデフォルトに戻ります。
> `reg delete "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}" /f`
