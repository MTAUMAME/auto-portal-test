## 1. なぜWindows 11で空き容量が「0バイト」になるのか？

原因は主に、Windows 11のシステムアップデートに起因する**「バグ（不具合）」**や**「一時ファイルの異常増殖」**です。

### 主な原因
*   **Windows Updateのキャッシュバグ：** アップデート時に生成される一時ファイル（「配信最適化ファイル」など）が自動削除されず、数十GB単位で居座り続けるケース。
*   **システムログの無限ループ生成：** Windows Defenderなどのセキュリティソフトやシステムエラーのログファイルが、数KB単位で数百万個も自動生成され、ディスクを埋め尽くすバグ。
*   **OneDriveの同期エラー：** クラウド上のファイルが意図せずローカルに全てダウンロードされ、同期エラーを起こして容量を圧迫。

### 放置するとどうなる？
ストレージ（Cドライブ）の空き容量が完全に0になると、Windowsは一時ファイル（スワップファイル）を作成できなくなります。その結果、**ブルースクリーン（BSoD）の連発、アプリの強制終了、最悪の場合はPCが二度と起動しなくなる**という致命的な事態に陥ります。

## 2. 影響を確認するステップと今すぐできる緊急対策

まずはあなたのPCの状態を確認しましょう。

### 【ステップ1】空き容量の確認
1. 「エクスプローラー」を開き、「PC」をクリック。
2. Cドライブの空き容量を確認。**（空きが10GB以下、または赤色表示になっている場合は危険信号！）**

### 【ステップ2】緊急対策（不要ファイルの削除）
1. スタートボタンから「設定」＞「システム」＞「ストレージ」の順に選択。
2. **「一時ファイル」**をクリックし、不要なファイル（以前のWindowsのインストールなど）にチェックを入れて「ファイルの削除」を実行。

> **⚠️注意！これだけでは根本解決にならない場合も**
> システムバグによる容量減少の場合、一時的に空きを作っても、再び自動で容量が埋まってしまうことがあります。最も安全な対策は、**「重要なデータ（写真・動画・仕事の書類）を外付けSSDに退避させ、Cドライブに十分な物理的余裕（最低50GB以上）を持たせること」**です。
