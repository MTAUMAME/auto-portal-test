## 1. Anthropic「OSS Scanner」概要とClaude Mythosの衝撃

AI研究開発企業Anthropicが公開した「OSS Scanner」は、GitHubなどのパブリックリポジトリに存在する**オープンソースコードの脆弱性を自動で検出・分析するAIセキュリティーアナライザー**です。

### 主な特徴と「Claude Mythos」の役割

1. **Claude Mythosによる深層コード解析**
   従来の静的解析ツール（ルールベース）では見落としがちだった「文脈依存のロジックエラー」や「複雑なゼロデイ脆弱性」を、Anthropicの最上位モデル級AI「Claude Mythos」が推論して発見します。
2. **圧倒的な誤検知（False Positive）の低減**
   AIがコードの意図を理解するため、「実際には攻撃不可能だが警告が出る」ようなノイズを極限まで減らしています。
3. **OSS開発者向けに「完全無料」開放**
   オープンソースエコシステムの安全性を高める社会的貢献として、OSSプロジェクトに対しては無料（※一部制限あり）で提供されています。
4. **修正用Pull Requestの自動生成**
   単に脆弱点を指摘するだけでなく、「どう修正すべきか」のPatchコード（PR）まで自動提案してくれます。

## 2. 既存の脆弱性スキャナーとの価格・性能比較

「OSS Scanner」は、既存のメジャーなセキュリティツール（Snyk、GitHub Advanced Security、SonarQubeなど）と比べてどうなのでしょうか？徹底比較してみました。

| 項目 | **Anthropic OSS Scanner** | **Snyk (Snyk Code)** | **GitHub Advanced Security** | **SonarQube (Developer)** |
| :--- | :--- | :--- | :--- | :--- |
| **スキャン方式** | **AI推論（Claude Mythos）** | 静的解析 + AI(Snyk DeepCode) | 静的解析 (CodeQL) | 静的解析 (ルールベース) |
| **OSS利用価格** | **基本無料** | 無料プランあり（制限強） | パブリックリポジトリ無料 | 無料（Community版） |
| **商用利用価格** | 要問い合わせ（API従量制） | 月額$25〜/Dev | 年額$49/コミッター | 年額$150〜 |
| **文脈の理解力** | **極めて高い（神レベル）** | 中〜高 | 中 | 低（ルール依存） |
| **誤検知率** | **非常に低い** | やや高い | 普通 | やや高い |
| **修正提案** | **修正PRを自動生成** | 修正ヒントの提示 | 修正ヒントの提示 | コードの指摘のみ |
| **導入の容易さ** | CLI / GitHub Actions | GitHub連携 / CLI | GitHub標準機能 | サーバー構築が必要 |

### 結論：何が凄いの？
従来のツールは「決まった危険パターン」を探すだけでしたが、OSS Scannerは**「熟練のホワイトハッカーがコードを熟読してバグを探す」**ような動作をAIが行います。これにより、従来ツールでは見抜けなかった深刻なロジックエラーを瞬時に発見できるようになりました。
