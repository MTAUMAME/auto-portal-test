# 【今週のキーワード】「能動的サイバー防御」とは？

### 従来の「受動的防御」との違い
従来のサイバーセキュリティ（受動的防御）は、「壁（ファイアウォール）を立て、毒（ウイルス）が入ってきたら駆除する」という**リアクション型**でした。しかし、AIを使った高速かつ巧妙な攻撃が増えた現在、これでは防ぎきれません。

**「能動的サイバー防御」**とは、攻撃を受ける前に**「予兆を察知し、未然に防ぎ、被害が広がる前に即座に無効化（孤立化）する」**というアプローチです。

```
【受動的防御】侵入される ➔ 検知する ➔ 駆除する（被害が発生した後）
【能動的防御】挙動をAI解析 ➔ 侵入前にブロック/無効化 ➔ 被害をゼロ～最小限に抑える
```

現在、個人や企業が導入できる「能動的防御」の要となるのが、**AIを活用したリアルタイム検知ツール**と**物理ハードウェアによるゼロトラスト認証**です。
