*   **投資家的視点：** 投資で最も大切なのは「市場から退場しないこと」です。このエッセイが突きつける「別れ（損失確定）への恐怖」を克服する力を身につけることこそが、長期資産運用の成功への鍵です。

### 3. 手数料・利回り比較：初心者が選ぶべき選択肢

メンタルを安定させるためには、「手数料を抑え、自動で運用する」ことが不可欠です。インデックス投資（全世界株式）が推奨される理由を比較表でまとめました。

| 項目 | 全世界株式（オール・カントリー） | 個別株投資 |
| :--- | :--- | :--- |
| **運用難易度** | 低（ほったらかしOK） | 高（分析が必要） |
| **手数料（信託報酬）** | 年率0.05%〜0.1%程度 | 購入手数料・売却手数料 |
| **期待利回り** | 年利3%〜7%（過去実績） | 銘柄により大きく変動 |
| **メンタル負荷** | 低い（分散が効いている） | 高い（暴落時に耐えにくい） |

※上記は一般的な目安です。投資にはリスクが伴います。

### 4. 初心者の方へ：どうやって「耐える力」を養うか

投資における「お別れ（損失）」への耐性を高めるには、以下の3つが重要です。

1.  **「つみたて投資」にする：** 毎月決まった額を買うことで、安い時には多く買い、高い時には少なく買う「ドルコスト平均法」が自動的に実行されます。これだけでメンタルは非常に楽になります。
2.  **長期保有を前提にする：** 10年、20年先を見据えれば、現在の多少の変動は「単なるノイズ」に過ぎないと割り切れます。
3.  **余剰資金でやる：** 生活費に手をつけず、「無くなっても（一時的に減っても）すぐに困らないお金」で運用しましょう。
