## 1. ローカルLLMでのコード生成：基礎知識

そもそも、ローカルLLMでコードを書くとはどういうことなのか、簡単に整理しておきましょう。

### なぜ今、ローカルLLMなのか？（3つのメリット）
1. **完全なプライバシー（機密保持）**：コードが外部サーバーに送信されないため、会社の業務コードや未公開の個人開発プロジェクトでも安心して使えます。
2. **完全無料・無制限**：一度環境を構築すれば、API利用料や月額サブスク（約20ドル/月）を気にせず、24時間いつでも叩き放題です。
3. **オフライン動作**：ネット環境がない飛行機の中や、電波の悪い場所でも爆速でコード生成が可能です。

### ローカルLLMで「できること」と「限界」

現在のローカルLLMのコード生成能力は、**モデルのパラメータ数（サイズ）**によって大きく異なります。

| モデルサイズ | 実用レベル（できること） | 苦手なこと（限界） |
| :--- | :--- | :--- |
| **8B（約80億パラメータ）前後**<br>※超軽量 | ・関数単位のコード生成<br>・コードのデバッグやエラー解説<br>・リファクタリング、コメント追加 | ・大規模な複数ファイルにまたがる設計<br>・超マイナーなライブラリのバグ修正 |

| **70B以上（大規模）**<br>※プロレベル | ・GPT-4に迫る精度でのシステム構築<br>・複雑なロジックの実装 | ・動かすために10万円超〜数十万円のモンスターPCが必要 |

## 2. 性能・コスト比較：おすすめコード生成モデル＆必要スペック

ローカルLLMを動かす上で、最も重要なのは**「GPUのVRAM（ビデオメモリ）容量」**です。通常のメインメモリ（RAM）ではなく、グラフィックボードのメモリ量がAIの動作速度（トークン生成速度）を決定します。

### 代表的なコード生成特化モデル

1. **DeepSeek-Coder-V2**：現在、コード生成において「GPT-4級」と最も評価が高いオープンモデル。
2. **Codestral (by Mistral AI)**：80以上のプログラミング言語に対応した、開発特化型モデル。
3. **Llama 3 (Meta)**：汎用モデルながら、コーディング能力も非常に高い万能型。
