# SNS疲れの救世主？「いいね・コメントなし」文章投稿サービスとは

現代のSNSは、アルゴリズムに気に入られるための「バズワード」や「炎上」、そして「いいね」や「フォロワー数」という承認欲求の数字に支配されています。

これに一石を投じたのが、**「しずかなインターネット」**に代表される、リアクション機能を極限まで削ぎ落とした文章投稿プラットフォームです。

### 主な特徴
*   **「いいね」ボタンがない**（一部、筆者だけに届く匿名レター機能などはあり）
*   **コメント欄がない**（炎上や誹謗中傷から無縁）
*   **フォロワー数が非公開、または存在しない**（数字によるマウンティングがない）
*   **シンプルなエディタ**（書くことだけに集中できる）
