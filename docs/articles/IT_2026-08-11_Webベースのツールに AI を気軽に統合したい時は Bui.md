## 1. Built-in AI APIとは？ブラウザでAIが「ローカルに動く」衝撃

**Built-in AI**とは、ユーザーが使っているブラウザ（主にGoogle Chrome）に最初から組み込まれている軽量AIモデル（Gemini Nano）を、JavaScriptから直接呼び出して利用できる仕組みです。

```javascript
// 実装イメージ：わずかこれだけでAIが動く！
const session = await ai.assistant.create();
const result = await session.prompt("文章を要約して：...");
console.log(result);
```

### 3つの革命的なメリット
1. **APIコストが「完全無料（0円）」**：サーバーを介さずユーザーの端末（ローカル）で処理するため、開発者側のAPIコストは永続的に0円です。
2. **圧倒的な超低遅延（ゼロ・レイテンシ）**：ネットの通信待ちがないため、爆速で回答が返ってきます。
3. **最高峰のプライバシー**：入力データがネットに送信されないため、個人情報や機密データを扱うツールに最適です。

## 2. 【比較表】Built-in AI vs クラウドAI（OpenAI / Gemini Cloud）

「無料なのはいいけど、性能はどうなの？」という疑問にお答えするため、普及しているクラウドAPIと比較しました。

| 項目 | **Built-in AI (Gemini Nano)** | **GPT-4o-mini (OpenAI)** | **Gemini 1.5 Flash** |
| :--- | :--- | :--- | :--- |
| **初期コスト / 月額** | **0円 (完全無料)** | 従量課金 (安価) | 従量課金 (安価) |
| **データ通信** | **不要 (オフライン可)** | 必須 (常時接続) | 必須 (常時接続) |
| **処理速度** | **極めて高速 (端末性能に依存)** | 通信環境により遅延あり | 通信環境により遅延あり |

### 性能評価の総括
Built-in AIは、複雑な推論や長文の創作には不向きですが、**「テキストの校正」「即時の要約」「マークダウンの生成」「シンプルな翻訳」**といった、Webツールのちょっとした機能拡張には十分すぎる性能を持っています。
