## 1. なぜ今、生成AIにおける「HTML/画像出力」の効率化が必要なのか？

現在、AIによるWebデザイン・素材生成は「テキストの出力」から「ビジュアル（視覚）の出力」へと主戦場が移っています。

| ユースケース | 従来のプロセス | 生成AI導入後のプロセス |
| :--- | :--- | :--- |
| **Webサイトのラフ作成** | ワイヤーフレーム作成 → デザイン → コーディング（数日〜数週間） | AIに指示 → **数秒でHTML/CSS出力** |
| **SNS/ブログのアイキャッチ** | デザインツールでテンプレート選択 → 文字入れ（30分） | AIに指示 → **数秒で画像出力＆HTMLカード生成** |

このように、生成AIは「プロトタイピング（試作）」の時間を極限まで削ってくれます。

しかし、**「出力されたコードの確認（プレビュー）環境」が貧弱であること**が、現在の最大のボトルネックです。このボトルネックを解消するために開発されたのが、プレビューと編集、画像化をワンストップで行える**「RHW（Reviewable-HTML-Workbench）」**です。

## 2. 話題の「RHW（Reviewable-HTML-Workbench）」とは？

**RHW（Reviewable-HTML-Workbench）**は、生成AIから出力されたHTML/CSS/JSコードを貼り付けるだけで、**リアルタイムプレビュー、コード微調整、高解像度画像（PNG/SVG）としてのエクスポート**をシームレスに行える統合ワークベンチ環境です。

### RHWの主な神機能
1. **マルチAI対応のリアルタイムプレビュー**
   ChatGPT、Claude、Gemini、Local LLMなど、どのAIから出力されたHTMLでも即座にレンダリング。
2. **AIダミー画像の「実画像自動置換」**
   AIが出力しがちな「`src="placeholder.com"`」のような仮の画像タグを、内蔵されたAI画像生成（DALL-E 3やFlux等）と連携して自動でリアルな画像に置き換えます。
3. **1クリック「高精度画像レンダリング（エクスポート）」**
   生成されたHTML要素を、劣化なしの美しい画像（PNG/WebP/PDF）としてワンクリックで書き出し。SNSのカード画像や、バナー、ランディングページのモックアップを即座に素材化できます。
