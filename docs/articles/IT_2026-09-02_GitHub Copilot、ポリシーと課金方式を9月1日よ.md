## 1. GitHub Copilot 9月1日からの変更点まとめ

今回の変更のキーポイントは**「マルチLLM（大規模言語モデル）の正式サポートに伴うプラン再編」**と**「セキュリティポリシーの厳格化」**です。

| 項目 | 変更前 | 変更後（9月1日以降） |
| :--- | :--- | :--- |
| **対象プラン** | Individual（個人） / Business / Enterprise | 変わらず（ただしIndividualに新オプション追加） |
| **個人プラン料金** | $10/月（または$100/年） | **$14/月（または$140/年）** ※実質約40%の値上げ |
| **利用可能モデル** | GPT-4o / GPT-3.5ベース | **Claude 3.5 Sonnet / Gemini 1.5 Pro も選択可能に** |
| **セキュリティポリシー** | 個人コードの学習利用は設定でオフ可能 | **個人・法人問わず、デフォルトで「一切学習に使用しない」を厳格化** |

### 💡 変更の背景：なぜ値上げ？
これまではOpenAIのモデルが中心でしたが、Anthropicの「Claude 3.5 Sonnet」など、競合の高性能モデルをCopilot内で自由に切り替えて使えるようになります。このマルチモデル化に伴うライセンス費用の上昇が、今回の価格改定の主な要因です。
