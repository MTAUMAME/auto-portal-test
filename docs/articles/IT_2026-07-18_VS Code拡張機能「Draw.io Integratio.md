## 1. ニュース概要：何が変わった？「Draw.io Integration」最新プレリリース版

*元ニュース：[VS Code拡張機能「Draw.io Integration」、Markdownのプレビュー上で図をインライン編集する機能、プレリリース版で提供 | gihyo.jp](https://gihyo.jp/)*

VS Code上で直感的にフローチャートや構成図を描画できる超人気拡張機能**「Draw.io Integration」**。

今回のアップデート（プレリリース版）により、以下のような驚きのワークフローが実現します。

### 💡 主な変更点とメリット
1. **画面遷移がゼロに**：Markdownのプレビュー画面に表示されているDraw.ioの図（`.drawio.svg` や `.drawio.png`）を**ダブルクリックするだけ**で、その場で編集モードに入れます。
2. **直感的なインライン編集**：プレビュー画面のレイアウトを崩すことなく、シームレスに図のテキスト変更やオブジェクトの追加が可能です。
3. **自動保存＆反映**：編集が終わると、Markdownプレビューおよび元データに自動で変更が反映されます。

これまでは「Markdownファイル」と「Draw.ioファイル」を往復していた手間が、**「プレビュー画面だけで完結」**するようになります。ドキュメント作成の生産性が爆上がりすることは間違いありません。
