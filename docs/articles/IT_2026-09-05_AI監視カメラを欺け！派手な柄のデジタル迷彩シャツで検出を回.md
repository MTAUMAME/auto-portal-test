## 1. なぜ派手な柄で消える？AIを騙す「敵対的攻撃（Adversarial Attack）」の仕組み

一見すると、ただのカラフルで奇抜なデザインのシャツ。しかし、これらはAIの「目」を狂わせるために綿密に計算された**「敵対的パッチ（Adversarial Patch）」**という技術で作られています。

```
【通常のカメラ】 👤 人間を発見！ ➔ [追跡開始]
【ステルス衣類】 🦓 謎の物体（犬？キリン？）を発見？ ➔ [人間として認識しない]
```

### AIの誤認識を誘うトリック
現在のAI監視カメラは、**「YOLO（You Only Look Once）」**などの画像認識アルゴリズムを使用し、人間の形（頭、体、手足の比率）を検出しています。

ステルス・アパレルにプリントされた特殊な幾何学模様や動物のようなパターンは、AIに対して**「強いノイズ」**として作用します。AIの目には、着用者が「人間」ではなく「犬」や「ゼブラ（シマウマ）」、あるいは「背景の一部」として映るため、人としての自動検出や追跡を回避できるのです。
