## 1. MCP（Model Context Protocol）とは？

**MCP（Model Context Protocol）**とは、一言で言えば**「AI（Claudeなど）と、外部のデータやツールを繋ぐための『万能プラグ（共通規格）』」**です。

```
[ あなたのPC / 外部API / データベース ]
       ▲
       │ (MCP規格で接続)
       ▼
[ MCPサーバー ] 
       ▲
       │
[ Claude 3.5 Sonnet などのAIクライアント ]
```

これまでは、AIに特定のWebサイトを検索させたり、ローカルファイルを操作させたりするには、専用の複雑なAPI連携コードを毎回書く必要がありました。
しかし、MCPという「共通規格」が登場したことで、**一度MCPサーバーを作ってしまえば、CursorやClaude Desktopなどの対応アプリから一瞬で外部データにアクセスできる**ようになりました。

## 2. 実践：自分専用「毎朝ニュースを読むMCP」を作ってみる

今回は、初心者でも簡単に作れる**「指定したテーマの最新ニュースを毎朝自動収集し、3行で要約して出力するMCP」**の構築手順を解説します。

今回はPythonの軽量フレームワーク「FastMCP」と、無料の「NewsAPI」を使用します。

### 準備するもの
*   **Python 3.10以上**がインストールされたPC
*   **Cursor** または **Claude Desktop**（MCPを実行するクライアント）
*   **NewsAPIのAPIキー**（[NewsAPI公式サイト](https://newsapi.org/)で5分で無料取得できます）

### ステップ1：必要なライブラリのインストール
ターミナル（コマンドプロンプト）を開き、以下を実行します。

```bash
pip install mcp mcp[cli] requests
```

### ステップ2：MCPサーバーコードの作成
`news_mcp.py` という名前で以下のコードを保存します。

```python
import requests
from mcp.server.fastmcp import FastMCP

# FastMCPインスタンスの作成
mcp = FastMCP("NewsReader")

NEWS_API_KEY = "あなたのNEWS_API_KEY" # 取得したキーを入力

@mcp.tool()
def get_latest_news(query: str) -> str:
    """指定されたキーワードに関する最新ニュースを取得します。"""
    url = f"https://newsapi.org/v2/everything?q={query}&sortBy=publishedAt&pageSize=5&apiKey={NEWS_API_KEY}&language=ja"
    
    try:
        response = requests.get(url).json()
        articles = response.get("articles", [])
        if not articles:
            return "ニュースが見つかりませんでした。"
        
        result = []
        for art in articles:
            result.append(f"【タイトル】: {art['title']}\n【URL】: {art['url']}\n【概要】: {art['description']}\n---")
        return "\n".join(result)
    except Exception as e:
        return f"エラーが発生しました: {str(e)}"

if __name__ == "__main__":
    mcp.run()
```

### ステップ3：Claude Desktopへの登録
`Claude Desktop` の設定ファイル（`claude_desktop_config.json`）に以下のようにMCPサーバーを登録します。

**Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
**Mac:** `~/Library/Application Support/Claude/claude_desktop_config.json`

```json
{
  "mcpServers": {
    "my-news-mcp": {
      "command": "python",
      "args": [
        "/path/to/news_mcp.py" 
      ]
    }
  }
}
```
*(※ `/path/to/news_mcp.py` は、実際にファイルを保存したフルパスに置き換えてください)*

### 動作確認
Claude Desktopを再起動すると、右下に「コンセント」のマークが表示されます。
**「今日の『AI半導体』に関する最新ニュースを調べて、重要ポイントを3行で要約して」**とチャットするだけで、自動的に作成したMCPツールが走り、最新情報を要約してくれます！

## 3. MCPを動かす環境の「コスト＆性能」徹底比較

MCPを本格的に運用する場合、どのクライアント（ツール）を使うのがベストでしょうか？
代表的な3つの環境を比較しました。

| 比較項目 | ① Claude Desktop | ② Cursor (有料プラン) | ③ Cline (VS Code拡張) |
| :--- | :--- | :--- | :--- |
| **主な用途** | 日常の会話・情報収集 | コーディング・開発効率化 | 自律型AIエージェント開発 |
| **初期費用** | 無料 | 無料（制限あり） | 無料（API代は実費） |
| **月額コスト** | 無料（Proは$20/月） | **$20/月**（使い放題推奨） | API使用量に応じた従量課金 |
| **MCP設定の易しさ**| ★★★★☆ (json編集のみ) | ★★★★★ (GUIで一発登録) | ★★★☆☆ (少し設定が必要) |
| **レスポンス速度** | 高速 | 極めて高速 | 使用するAPIモデルによる |
| **おすすめ対象** | 一般ビジネスパーソン | **エンジニア・ブロガー** | コア開発者・ギーク |

**【結論】**
ブログ執筆やプログラミングを並行するなら、**「Cursor（有料プラン）」**が圧倒的におすすめです。設定が最も簡単で、開発効率が何倍にも跳ね上がります。
