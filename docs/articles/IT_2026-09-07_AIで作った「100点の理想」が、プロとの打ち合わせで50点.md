# AIで作った「100点の理想」が、プロとの打ち合わせで50点になっていく理由

「AIで生成したデザインが完璧すぎる！ これでHPを作ろう！」
「ChatGPTが出した企画書、100点満点。このまま開発会社に渡そう！」

MidjourneyやChatGPTなどの生成AIが普及した現在、誰もが「プロ顔負けのアイデア」を一瞬で出力できるようになりました。しかし、意気揚々とその「100点の理想」を人間のプロ（Webデザイナー、開発エンジニア、印刷業者など）に持ち込んだ瞬間、待っているのは冷酷な現実です。

**「これ、Webでは実装できません」**
**「このデザイン、印刷すると色が潰れます」**
**「予算が10倍かかりますが、どうしますか？」**

打ち合わせを重ねるたびに、AIが作った100点満点の理想は削ぎ落とされ、気づけば「50点の実用的な妥協案」に。

なぜ、AIで作った完璧な理想は、プロの手によって「50点」にされてしまうのでしょうか？
本記事では、その**残酷な理由**を解き明かし、AIの理想を極力100点に近い状態で現実化するための**「ガジェット＆ツール対策」**を徹底解説します。

---

## 1. AIの「100点」が、プロの手で「50点」に削られる3つの理由

| 原因 | AIの視点（100点の理想） | プロの視点（50点の現実） |
| :--- | :--- | :--- |
| **① 物理・技術的な制約の無視** | 破綻のない美しいグラデーションや、無限に広がるUIデザイン。 | 画面サイズ（レスポンシブ）による崩れ、印刷（CMYK）での色再現性の限界。 |
| **② UI/UX（使いやすさ）の欠如** | 見た目が未来的で美しいボタンやレイアウト。 | 「どこを押していいか分からない」「視線誘導がめちゃくちゃ」という実用性の低さ。 |
| **③ 予算と開発工数の乖離** | 3Dアニメーションが滑らかに動く、超豪華なWebサイト。 | 実装に数百万〜数千万円のコストがかかり、費用対効果（ROI）が見合わない。 |

### ① AIには「物理・規格」という概念がない
例えば、Midjourneyで出力した美しいパッケージデザイン。
AIは「光の反射」や「複雑なグラデーション」を美しく描きますが、実際の印刷機は「CMYK（4色）」でインクを載せるため、AI通りの鮮やかなネオンカラーは表現できません。また、Webデザインでも、AIは「画面スクロール時の挙動」や「スマホ表示（レスポンシブ対応）」を考慮せずに1枚の美しい絵を出力するため、コーダー（実装者）に「再現不可」と一蹴されてしまいます。

### ② 「ユーザー体験（UX）」を無視した審美性
AIは「美しく見えるもの」を作りますが、「使いやすいもの」を作るのは苦手です。
プロのデザイナーは「ユーザーの視線の動き」「ボタンの押しやすさ」を何百パターンも検証しています。AIの作った100点のデザインは、プロから見れば「見た目はいいが、コンバージョン（売上）が生まれない、使いにくいデザイン」であることが多いため、大幅な修正を余儀なくされます。

### ③ 「予算」という最大の壁
AIは、一瞬で「映画のような3D Webサイト」のコンセプトを作ります。
しかし、それを実際にコーディングして滑らかに動かすには、優秀なエンジニアが数ヶ月張り付く必要があり、開発費は一気に跳ね上がります。「予算30万円」のプロジェクトに「300万円規模のAIデザイン」を持ち込んでも、プロは予算内に収めるために機能をそぎ落とすしかありません。これが、100点が50点になる最大の理由です。
