## 1. LM Studioを爆速化する「DFlash / DSpark / MTP」とは？

ローカルLLMの最大の弱点は「生成速度（トークン/秒）の遅さ」でした。これを解決するために導入されたのが、以下の3つの新技術です。

```
【従来の処理】 1トークンずつ順番に生成（遅い）
【MTP導入後】 複数のトークンを同時に予測・並列生成（劇的に速い！）
```

### ① DFlash (DeepSeek-Flash-Attention)
GPUのメモリ帯域幅（ボトルネックになりやすい部分）を最適化し、アテンション計算を高速化する技術。これにより、長文のコンテキスト（過去の会話履歴）を読み込ませても速度が低下しにくくなります。

### ② DSpark
CPUやGPUのマルチスレッド処理を極限まで最適化し、ハードウェアの性能を100%引き出す実行エンジン。特にAMD製GPUやMacのApple Siliconでの動作効率が向上します。

### ③ MTP (Multi-Token Prediction：複数トークン予測)
従来のAIが「1文字（トークン）ずつ」予測して出力していたのに対し、**「一度に複数のトークンを同時に予測・出力」**する画期的な技術。これにより、推論速度が理論上**1.5倍〜2倍**に跳ね上がります。
