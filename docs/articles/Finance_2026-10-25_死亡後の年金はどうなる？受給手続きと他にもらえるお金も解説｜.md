# 死亡後の年金はどうなる？相続のプロが教える「遺族の備え」と資産運用

現在、検索トレンドで「死亡後の年金」が注目されている理由は主に3つです。

1.  **「年金受給世代」の相続:** 団塊の世代が後期高齢者となり、年金を受け取りながら運用している層の相続が発生し始めている。
2.  **新NISAと相続の知識:** 新NISAで資産が増えたことで、「この資産をどうスムーズに家族へ渡すか（または自分がもらうか）」という意識が高まっている。
3.  **手続きの複雑化:** 未支給年金や遺族年金は、故人の加入していた年金種別（国民・厚生・共済）で受給条件が異なり、情報が複雑化しているためプロの解説が求められている。

### 【自己検証：最新情報】

## 3. 資産運用の比較表：遺族を守るための選択肢

もしもの時、家族に残す資産として「新NISA」と「従来の貯蓄」はどのような違いがあるのでしょうか。

| 項目 | 新NISA（投資） | 預金・保険 |
| :--- | :--- | :--- |
| **流動性** | 高（売却に数日） | 最高（即日引き出し可） |
| **期待利回り** | 年利3〜5%（期待値） | ほぼ0% |
| **相続時の評価** | 時価評価（変動あり） | 額面通り |
| **もしもの時** | 相続人が売却して現金化可能 | すぐに使える生活費になる |

**【初心者へのアドバイス】**
投資は「増やす」ためのもの、預金は「すぐ使う」ためのものです。**「生活防衛資金（半年〜1年分の生活費）」を現金で確保した上で、余剰資金を新NISAに回す**のが、相続・資産継承を考える上での鉄則です。
