## 1. そもそも「AIエージェント（Agent）」の基本構成とは？

「ぷらすのブログ」で解説されている通り、AIエージェントを構成する基本要素は、以下の**4つのレイヤー**に分解できます。

```
┌────────────────────────────────────────┐
│               AI Agent                 │
│  ┌──────────┐ ┌──────────┐ ┌────────┐  │
│  │ Planning │ │  Memory  │ │ Tools  │  │
│  └────┬─────┘ └────┬─────┘ └────┬───┘  │
└───────┼────────────┼────────────┼──────┘
        ▼            ▼            ▼
┌────────────────────────────────────────┐
│            LLM (Brain / Core)          │
└────────────────────────────────────────┘
```

1. **LLM（脳）：** 推論や判断を行うコア（GPT-4oやClaude 3.5 Sonnetなど）。
2. **Planning（計画）：** タスクを細分化し、実行順序を決める（ReActフレームワークなど）。
3. **Memory（記憶）：** 短期記憶（会話履歴）と長期記憶（外部データベース/RAG）。
4. **Tools（道具）：** Web検索、コード実行、外部API連携など、実際にアクションを起こす手段。

OpenAIとClaude（Anthropic）は、これらを開発者が簡単に構築できるように**「Agent SDK（アシスタントAPIやMCPなど）」**を提供しています。

## 2. OpenAI vs Claude：Agent SDKの価格・性能比較

エージェント開発において、どちらのプラットフォームを採用すべきか？
スペックとコストから比較します。

| 比較項目 | OpenAI (Assistants API / Swarms) | Claude (Model Context Protocol / Tool Use) |
| :--- | :--- | :--- |
| **代表モデル** | GPT-4o | Claude 3.5 Sonnet |
| **価格 (インプット)** | **$5.00** / 100万トークン | **$3.00** / 100万トークン |
| **価格 (アウトプット)** | **$15.00** / 100万トークン | **$15.00** / 100万トークン |
| **エージェント特徴** | **State（状態）の自動管理**<br>スレッドやファイルの管理をOpenAI側が代行。 | **MCP（Model Context Protocol）**<br>ローカル環境や他ツールとの連携が極めてオープンかつセキュア。 |
| **推論・コーディング力** | スピードと構造化データ（JSON）出力に強み。 | **圧倒的なコード生成力**と高度な論理的推論力。 |
| **ファイル検索コスト** | ベクター検索（ベクトルDB）が組み込まれているが、維持費がかかる。 | 必要なコンテキストのみを投入するため、工夫次第で安価。 |

### どっちを選ぶべき？
* **OpenAIが向いている人：** チャット履歴の保存やファイル管理などの「サーバー側の面倒な処理」を丸投げし、素早くプロトタイプを作りたい場合。
* **Claudeが向いている人：** ローカルPCのツール（IDEやローカルファイル）と密に連携させ、極めて高い精度で自律コーディングやドキュメント作成を行いたい場合。
