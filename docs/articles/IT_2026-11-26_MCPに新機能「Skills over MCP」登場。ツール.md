# 【衝撃】MCPに新機能「Skills over MCP」が登場！単なるツール接続から「プロのノウハウ伝授」へ。性能・コスト比較とリアルな口コミまとめ

最新のAI業界を揺るがすニュースが飛び込んできました。Anthropicが提唱し、急速に標準化が進む**MCP（Model Context Protocol）**に、待望の新概念**「Skills over MCP」**が登場しました！

これまでMCPは「AIと外部ツール（データベースやAPI）を繋ぐパイプ」としての役割が中心でしたが、今回のアップデートにより**「ツールをどう使うかというプロのスキル（ノウハウ・手順）」までAIに直接提供可能**になります。

本記事では、ガジェット＆AIオタクの筆者が「Skills over MCP」の仕組み、従来のMCPやプロンプトエンジニアリングとのコスト・性能比較、そしてSNS上の**「サクラ・ステルスマーケティングを徹底排除したリアルな開発者の口コミ」**を解説します。

最後には、この最新波に乗り遅れないための周辺機器やおすすめサービスも紹介します！

## 1. そもそも「Skills over MCP」とは？何がすごいの？

従来のMCPと「Skills over MCP」の違いをわかりやすく例えると以下の通りです。

*   **従来のMCP（Tools）**
    *   例：「AIに『カメラ（ツール）』を渡す」
    *   状態：使い方はAIの知識頼み。シャッターの押し方は知っているが、プロのような構図や設定は指示しないとできない。
*   **Skills over MCP（Tools + Skills）**
    *   例：「AIに『カメラ』と『プロカメラマンのマニュアル（スキル）』をセットで渡す」
    *   状態：「暗い場所ではISOを上げて絞りをこう調整する」という**最適なワークフローや文脈をMCP経由で自動注入**できる。

### 主なメリット
1.  **指示出し（プロンプト）の簡略化**: 毎回長い指示を書かなくても、MCP側が「正しい使い方」を誘導。
2.  **ハルシネーション（嘘）の激減**: ツールを実行する際のエラーや無駄な試行錯誤が激減。
3.  **高度な自動化**: 「Aを取得して、Bで加工し、Cに保存する」といった複雑なプロの標準手順（SOP）をAIが迷わず実行可能に。

## 2. コスト・性能比較表（従来手法 vs Skills over MCP）

「で、実際使って得するの？」という疑問に答えるため、従来のプロンプト構築、標準MCP、そして「Skills over MCP」を比較しました。

| 評価項目 | 従来のプロンプト構築 | 標準MCP（Toolsのみ） | **Skills over MCP** |
| :--- | :--- | :--- | :--- |
| **導入の難易度** | 簡単（文言を書くだけ） | 中程度（サーバー設定が必要） | 中〜やや高（スキルの定義が必要） |
| **タスク成功率** | 60%（AIの機嫌に左右される） | 80%（ツールの呼び出しミスあり） | **95%以上（手順が固定化される）** |
| **トークン消費（APIコスト）** | 多い（毎回指示文を送信） | 中程度（スキーマ読み込み） | **極めて少ない（最適化された指示のみ）** |
| **実行速度（レイテンシ）** | 遅い（試行錯誤が発生） | 普通 | **爆速（迷いなく一発実行）** |
| **拡張性** | 限界あり | 高い | **最強（ノウハウの共有・売買が可能）** |

### コスト面での最大のアドバンテージ
APIコスト（トークン代）の大幅削減です。従来のプロンプトエンジニアリングでは、AIに正しく動いてもらうために「長文の前提条件」を毎回送る必要があり、これがコストを圧迫していました。

「Skills over MCP」では、必要なスキルのコードやルールだけが動的に適用されるため、**月間のAPI費用を最大30〜50%削減**できる可能性があります。
