## 1. 「mizchi/explainer」とは？ 概要と3つの特徴

**GitHubリポジトリ:** [mizchi/explainer](https://github.com/mizchi/explainer)

`explainer`は、一言で言えば**「コードベース全体をLLM（大規模言語モデル）に最適化した形で要約・解説させるためのCLIツール」**です。

通常、大規模なソースコードをChatGPTやClaudeに読み込ませようとすると、ファイル数が多すぎてトークン制限（文字数制限）に引っかかったり、文脈がバラバラになって正しい理解が得られなかったりします。

`explainer`は、この問題をスマートに解決します。

### 💡 主な3つの特徴

1. **LLMフレンドリーな単一ファイル（Markdown）出力**
   プロジェクト内の複数ファイルをスキャンし、依存関係やコード構造を維持したまま、AIが最も理解しやすい1つのMarkdownファイルに統合・整形します。
2. **トークン節約＆不要ファイルの自動フィルタリング**
   `node_modules`やビルド成果物、画像などの不要なファイルを自動で除外し、APIコストを最小限に抑えます。
3. **Claude 3.5 SonnetやGPT-4oとの抜群の相性**
   出力されたファイルを話題の超高性能AI（Claude 3.5 Sonnetなど）に流し込むだけで、まるで「そのコードを書いた本人」が隣にいるかのような精度でコード解説やバグ修正の提案を受けられます。

## 2. 他のAI開発ツールとの「性能・価格」比較

コード解析ができる主要なAIツール（GitHub Copilot Enterprise、Cursor）と、`explainer`を比較してみました。

| 比較項目 | **mizchi/explainer (本ツール)** | **Cursor (AIエディタ)** | **GitHub Copilot Enterprise** |
| :--- | :--- | :--- | :--- |
| **ツールの位置づけ** | コード抽出・整形CLI（OSS） | AI特化型コードエディタ | 開発統合型AIアシスタント |
| **初期費用/月額** | **無料 (OSS)** | 月額 $20 (Proプラン) | 月額 $39 / ユーザー |
| **AI利用料** | 使用した分のAPI実費のみ | 月額料金に含む (制限あり) | 月額料金に含む |
| **導入の難易度** | 中（CLI操作が必要） | 低（エディタを乗り換えるだけ）| 低（拡張機能を入れるだけ） |
| **ソースコードの秘匿性**| 自分でAPIキーを管理（高セキュリティ）| 設定によるが外部通信あり | 企業向けの高いセキュリティ |
| **最大の強み** | **エディタを選ばず、巨大コードを瞬時に一括ドキュメント化できる** | コードを書きながらシームレスにAIと対話可能 | GitHubのPRやIssueと強力に連携 |

### どっちを選ぶべき？
* **Cursor / Copilot:** 日々のコーディング中に「コードを書きながら」AIの支援を受けたい人向け。
* **explainer:** 「既存の巨大なコードベースを今すぐ理解したい」「ドキュメントが皆無のレガシーコードを解読したい」という**キャッチアップ・分析特化**。また、普段使いのエディタ（VimやVS Code、WebStormなど）を変えたくない人に最適です。
